# 大時代的故事 HD 重製版

從全國局勢到前線戰場，重回北伐與抗戰年代。

北伐軍向北推進，地方勢力各據一方；抗戰烽火燃起，戰局也從勢力角逐轉向對日作戰。你將從北伐與抗戰的三個歷史時期選擇開局，在全國地圖上管理省份、調動將領，為前線籌措糧食與軍需，再親自指揮六角格戰場上的部隊。前線等待增援，後方也需要建設；有限的軍政指令，讓每一次開發、徵兵與出兵都得仔細安排。

本作重製漢堂國際資訊於 1992 年推出的 DOS 策略遊戲《大時代的故事》。延續原作的軍政經營與回合制戰棋，加入 HD 地圖、兵種美術、Modern 滑鼠操作與重新編配的音樂，並保留原版美術及操作介面的切換。

## 故事背景

二十世紀上半葉的中國，歷經軍閥割據、北伐與抗日戰爭。各省的兵力、軍需與將領構成局勢，每一次調動、徵兵與外交，都牽動下一步部署。

遊戲提供三個歷史時期。北伐從各地勢力並立的局面展開；抗戰前期將視線轉向全面戰爭；抗日後期則置身太平洋戰爭爆發後的局勢。

| 歷史時期 | 劇本起點 |
|---|---|
| 北伐時期 | 1926 年 7 月 |
| 抗戰前期 | 1937 年 7 月 |
| 抗日後期 | 1941 年 12 月 |

你需要在全國地圖上安排軍政行動，籌措黃金、糧食與軍需，管理省份並調動將領。進入戰場後，再逐支指揮部隊，選擇移動、攻擊或撤退。人物檔案也讓地圖上的名字有了生平與史料脈絡。

## 怎麼玩

- **經營省份**：徵稅、開發、徵兵與運補，安排有限的軍政指令。
- **調度將領**：查閱人物與部隊資料，進行任用、整編及調動。
- **處理外交**：透過外交與談判介面安排對外行動。
- **指揮戰場**：在六角格上選取部隊、移動及下達攻擊指令，觀察地形與鐵路配置。
- **選擇勢力**：三個劇本共 14 個開局選項，包含原有日軍勢力。
- **軍備＋抗日**：本機完整版可研究步槍、火炮與戰車，安排生產、庫存、換裝及步兵改編裝甲。統一有主的非日軍省份後，日軍宣戰並展開有限增援的入侵戰役。

## 這次 HD 重製了什麼

**Modern 操作介面**參考《鋼鐵雄心 IV》與《大戰略》的布局，以資源列、中央地圖、側欄資料與底部指令集中呈現局勢。徵兵可拖曳滑桿，調動可直接點選省名與將領；固定的返回、地圖與確認按鈕，讓滑鼠操作更清楚。土褐、砂岩、鐵黑與暗紅搭配磨損金屬邊框，延續原作的戰爭年代感。

**全國地圖與戰術戰場**重新繪製地表材質。全國地圖可以縮放、拖曳及切換觀看角度；戰術畫面採俯視六角格，兵種保留原版辨識特徵，加入鋼鐵質感。鐵路沿用原版連接與形狀。

**人物自傳**保留原版 392 篇中文正文，另加入十九位日軍人物，共 411 篇，可從部隊資料閱讀全文與來源，並以滾輪捲動。24 位資料不足的人物保留待考標示；英文與日文自傳保留機器翻譯草稿標示。

**原曲 HD 配樂**以八首 DOS 原曲為基礎，加入銅管、弦樂、軍鼓與定音鼓。本機完整版另收錄《還我河山》《國民革命歌》《歌八百壯士》，可在遊戲內指定播放；公開引擎包提供八首專案原創配樂。所有版本都可即時切換 HD、原版或靜音，美術、介面與音樂分別保存設定。

**雙方戰鬥資料**並列兵種、兵力與將領；整備模式另列實際配裝、缺裝與火力。戰術畫面可暫停返回地圖查閱，再繼續同一場戰鬥；整編取消時還原部隊及裝備帳。

## 下載與開始遊戲

從 [GitHub 最新正式版](https://github.com/wicanr2/great-era-remake/releases/latest)下載適合的平台。公開下載提供引擎、HD 素材、原創配樂與三語資料；玩家須自備合法原版遊戲資料及倚天字庫。

| 平台 | 啟動入口 |
|---|---|
| Windows x64 | `GreatEraRemake/launch.cmd` |
| macOS Apple Silicon | `GreatEraRemake.app/Contents/MacOS/launch` |
| Linux x86_64 | `AppDir/AppRun` |

例如在 Linux 指定自己的資料目錄：

```sh
./AppDir/AppRun -game /路徑/遊戲資料 -eten /路徑/eten
```

資料匯入、系統需求、語系與存檔位置見[執行說明](docs/release/README.md)。

本機完整版可直接雙擊 Windows 的 `dsds.exe`、macOS 的 App，或 Linux 的 AppImage，無需輸入參數。首次啟動預設使用 Modern 介面、HD 美術、滑鼠與 HD 音樂；之後沿用已保存的偏好。

1. 選擇是否開啟「軍備＋抗日」。正式下載仍為軍備整備版本；本機預覽已加入統一後宣戰與完整挑戰。
2. 點選歷史時期與勢力卡片，查看領地、將領與兵力，再按「開始戰役」。原版戰役保留三個劇本的全部 14 個勢力選項，日軍限原版戰役。
3. 已有存檔時，按「繼續進度」或 `C`，接續上次保存的遊戲。

本機預覽可在宣戰前從工具列調整「軍備＋抗日」，宣戰後鎖定。美術、操作介面及音樂仍可分別切換。

## 新版操作（Modern）

以下以預設 Modern 介面說明。先在全國地圖點選省名，右側會顯示該省資源與駐軍；也可點目前省名，從具名列表選省。己方省份可下達軍政指令，其他勢力的省份可查閱資料。

| 想做的事 | 滑鼠操作 |
|---|---|
| 查看地圖 | 滾輪縮放，按住左鍵拖曳；也可點「＋」「－」與「重設視角」 |
| 徵兵 | 點左側「徵兵」，選省份與兵種，用滑桿、加減或常用數量按鈕調整；檢查軍費後按「檢查並確認徵兵」，再確認執行 |
| 調動部隊 | 點「調動部隊」，選目的地、勾選將領並調整隨軍物資；按「檢查並確認」，核對後確認調動 |
| 重新整編 | 點「重新整編」，選兵種與將領並分配兵力；待分配兵力歸零後確認整編 |
| 閱讀人物 | 點「人物檔案」，選將領，再點「完整人物自傳」；滾輪捲動正文 |
| 開發、運補、商業與外交 | 點地圖下方「其他指令」，再選指令；依畫面選項操作，數量表單可先預覽再確認 |
| 研究與生產裝備 | 在整備模式點「軍備局」，依序研究、安排生產、查看庫存及替部隊換裝；也可將現有步兵改編為裝甲部隊 |
| 推進月份 | 回全國地圖，點「結束本月」並確認 |

### 返回與取消

- 點上方「返回」、按 `Esc` 或按滑鼠右鍵，可取消目前選擇或退回上一層。工具列選單開啟時，先關閉選單。
- 點「全國地圖」可回到地圖。徵兵或調動的確認視窗按取消，會保留數量與選取，讓你返回調整；已確認執行的命令不會因返回而撤銷。
- 整編中返回會詢問是否「取消整編並返回」。確認取消會還原整編前的兵力、武裝與裝備，不扣指令；選「繼續編輯」則留在整編頁。舊存檔若缺少整編前配置，畫面會提示繼續分配或保存離開。

### 戰術與雙方資料

進入戰場後，用換部隊圖示或 `Tab` 切換目前指揮的部隊。點「移動」後選相鄰六角格；點「攻擊」後選可攻擊的敵軍。底部另有撤退、駐軍與查閱指令，結束回合圖示會讓對方行動並推進回合。

| 戰術快捷鍵 | 功能 |
|---|---|
| `Tab` | 切換部隊 |
| `1`／`2`／`3`／`4`／`5` | 在戰術指令層選移動／攻擊／撤退／駐軍／查閱 |
| 空白鍵 | 在戰術指令層結束回合 |
| `Esc`／右鍵／返回按鈕 | 先退出目前子頁；在戰術指令層暫停並回地圖 |

「查閱」並列雙方兵力、兵種、將領、戰技、武裝、體力、士氣與機動；整備模式另列實際裝備、缺裝及火力。返回戰場不消耗回合。

戰鬥暫停後可在地圖查閱、切換美術與音樂、保存進度。點「繼續戰鬥」回到同一場戰鬥；暫停期間不能徵兵、調動、開新戰鬥或結束本月。保存並重新啟動後，也能接續這場戰鬥。

### 儲存、載入與離開

點左側「儲存進度」並確認，看到「進度已儲存」即完成保存。點「載入進度」並確認，會以最近保存的進度取代目前遊戲；也可在下次啟動時按「繼續進度」。

進度寫入系統使用者目錄的單一 `campaign.gesave`，每次儲存更新同一份檔案，包含軍備、戰鬥與整編進度。存檔位置及原版 DT1 匯入方式見[執行說明](docs/release/README.md)。

按 `F10` 開啟離開確認，再按 `Y` 或點確認，會先保存再離開。按 `N` 或 `Esc` 返回遊戲；保存失敗時會留在遊戲中並顯示原因。

## 原版介面與純鍵盤

原版介面保留原版色彩、字型與省份資料。以下操作修正已接入本機開發預覽，正式下載包尚未更新。從工具列選「介面 → 原版介面」及「操作 → 純鍵盤」即可使用，仍可獨立切換原版或 HD 美術。

| 操作 | 功能 |
|---|---|
| 指令頁 `2`／`A`、`3`／`S` | 出兵、運補；主鍵盤與數字鍵盤都可使用 |
| 數字輸入 `Backspace`／`Delete` | 刪除最後一位／清空目前未確認的數值 |
| `Enter`／數字鍵盤 `Enter` | 確認輸入；確認頁用 `N`／`Esc` 取消 |
| `Esc` | 取消或返回上一層；有結果訊息時先關閉該訊息，再按一次返回 |
| `0` | 數字輸入時輸入零；政略指令頁選第 10 項停火，其他選項頁選第 10 項解析度；沒有數值欄位或第 10 項的查閱及一般子選單可用來返回 |
| 全國地圖 `←`／`→`、`P` | 選省、查看目前省內地圖；省地圖按 `Esc`／`0` 返回全國地圖 |
| 查閱頁／指令頁 `Home` | 直接返回全國地圖，保留目前選省；未完成交易與整編仍須依原流程取消 |
| 部隊頁 `↑`／`↓`、`PageUp`／`PageDown` | 選將、翻頁；`Enter` 看詳情，`B` 看人物自傳 |
| `F10` | 開啟保存離開確認；`Y` 保存離開，`N`／`Esc` 返回遊戲 |

部隊清單每頁直式顯示兩支部隊，完整列出姓名、兵種、兵力、帶兵能力、忠誠、政治、經驗、攻擊、武裝、戰技、體力、士氣與番號。

## 常駐工具列

常駐工具列放在完整遊戲畫面上方。美術、介面、音樂及輸入設定可隨時調整，不需重新啟動。

| 工具列 | 功能 |
|---|---|
| 美術 | 即時切換原版／HD |
| 介面 | 即時切換原版／Modern 介面，與美術獨立 |
| AI | 查看重製 AI 說明；啟用抗日挑戰後，電腦日軍使用弱點突破與有限追擊 |
| 音樂 | HD／原版／靜音；自動選曲或指定曲目，本機完整版另有三首軍歌 |
| 操作 | 鍵盤加滑鼠／純鍵盤，偏好可保存；工具列始終接受滑鼠操作 |
| 軍備＋抗日（本機預覽） | 開啟軍備與統一後挑戰；停用保留進度，宣戰後鎖定 |

![遊戲中的音樂切換與本機十一首選曲](docs/images/music-toolbar-v.1.1.0-20261017.png)

例如只想保留原版美術、改用滑鼠介面，可選「美術 → 原版」及「介面 → Modern」。這些切換不需重新啟動，也不改動遊戲進度。

播放音樂時，點「音樂」選 HD、原版或靜音，再選自動選曲或指定曲目。自動選曲隨遊戲場景變化；指定曲目持續播放所選音樂，直到再次更換。軍歌只有 HD 音源，切到原版音樂時播放原版情境曲，回到 HD 後恢復指定軍歌。選曲與模式會保存至下次啟動。

### 常用快捷鍵

| 操作 | 功能 |
|---|---|
| `F2` | 即時切換原版／HD 美術 |
| `F4` | 即時切換原版／Modern 介面 |
| `F6` | 將鍵盤焦點移入或移出工具列；左右選欄、上下選項，`Enter` 套用，`Esc` 返回 |
| `F7` | 在整備模式的全國地圖或政略頁開啟軍備局 |
| `Ctrl+S`／macOS `Command+S` | 在 Modern 軍政頁開啟儲存確認 |
| `Ctrl+L`／macOS `Command+L` | 在 Modern 軍政頁開啟載入確認 |
| `Tab`／`Shift+Tab`，再按 `Enter` | 在 Modern 軍政頁選擇下一個／上一個控制項並啟用 |
| `Esc`／滑鼠右鍵 | 取消目前選擇或返回 |
| `F10`，再按 `Y` | 儲存並離開 |

切到原版介面後，可點畫面選單或按對應數字鍵操作，仍保留返回與常駐工具列。若選了純鍵盤操作，可用 `F6` 更改設定；工具列也始終接受滑鼠點擊。
