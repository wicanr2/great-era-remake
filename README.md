# 大時代的故事 remake

漢堂國際資訊《大時代的故事》(1992, MS-DOS) 的逆向、引擎重寫與多語系專案。
在 Go / Ebiten 上重寫一套跨平台引擎，還原原版繁體中文文本，另做英文與日文語系。

專案剛起步。目標、原則與工作方式見 [`CLAUDE.md`](./CLAUDE.md)，
現況與文件索引見 [`CONTEXT.md`](./CONTEXT.md)。

## 關於原作

以民國初年國民革命軍北伐與對日抗戰為背景的回合制戰棋，分北伐時期、抗戰前期、
抗日後期三段。政略採省份命令數制，戰鬥用六角格。這是漢堂的第二部原創作品，
在它之後才有《天外聖劍錄》與《炎龍騎士團》。

## 定位

文化資產保存。核心規則對齊 1992 原版，外殼（解析度、視窗、操作、存檔相容）現代化，
每一項改動都在文件裡標記為 remake 差異。

## 授權與素材

本專案不散布原版執行檔、資料檔、美術或音樂，也不散布倚天字型。
公開產出只有引擎程式碼與翻譯文本，玩家需自備合法原版。
