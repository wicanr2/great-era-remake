# SPEC-64：HD 砂鐵亮底操作介面

狀態：CONFORMED，限定本機 Linux 正常玩家路徑與顯示層驗證，尚未發行。2026-10-18 使用者先要求提供亮底，再要求加深並增加鋼鐵與磨損質感，最後明確採用第二版。配色與材質依[定版地圖圖](../images/hd-light-approved-20261018.png)及[軍備配色圖](../images/hd-light-armory-approved-20261018.png)；原型只用於配色及材質取捨，各正式畫面沿用現有操作位置。

- 介面選單提供「原版介面／Modern 深色／Modern 亮底」。美術、音樂與戰役設定保持獨立。既有偏好與無參數啟動仍預設 Modern 深色，不替使用者改成亮底。
- 新偏好 `ui_appearance` 只接受 `dark`／`light`，舊檔缺欄視為 `dark`。切換先原子保存偏好，失敗保留當前介面。原版介面暫不套亮底；切回 Modern 可恢復記住的配色。
- 背景 `#d3c6ad`、面板 `#b9ac94`、頂列 `#928a7c`、文字 `#211f1a`、次要文字 `#443e35`、黃銅標題 `#68421d`、邊線 `#62594a`、按鈕 `#c0b39b`、選取 `#ad915e`、主操作鏽紅 `#81452f`。鏽紅操作上使用亮色文字。
- 材質採固定座標的細拉絲、少量磨損邊緣與明暗線，不使用遊戲 RNG、不載入大型新圖集。只畫在介面矩形及裝飾上。
- 開局、常駐工具列、Modern 政略與自傳、軍備局、雙方戰鬥資料及戰術操作面板統一配色。地圖、地形、鐵路、單位圖片、宣戰插畫與人物照片逐像素保留，不套全畫面濾鏡。
- 宣戰原型只展示版面，不宣稱入侵完成。戰役規則與保存仍由 [SPEC-63](63-post-unification-invasion.md)負責。
- 驗收需從正常開局，以滑鼠切換亮底／深色／原版，查看軍備與戰鬥資料、返回及保存重啟；比較世界、RNG、軍備帳不變。原圖與照片另做像素對照，原版與深色預設不得被全域狀態污染。

來源、原型、工具與收據集中在[本機工作區](../../workplace/hoi4-ui-prototype/invasion-20261018/README.md)。最終正常操作為 `gui-r6/receipt.json`：seed 1、六項檢查、21 張實錄，程式 SHA-256 `07b4423706d96a60cb30521210b5cc51f6904102c430cedc48062e080d5d5e05`。正常開局、軍備停用恢復、保存重啟、蔣中正照片原色、日軍美術切換、雙方資料及返回地圖通過。單元測試另核對地圖內部、原版 BGI 及照片像素，並驗證預設深色與偏好失敗的原子性。十九套件通過後，修改過的四個套件補測通過。README 十六張圖片於桌面與手機離線驗收通過，既有 42 張圖片雜湊不變。
