# SPEC-05：戰鬥滑鼠／觸控控制外殼

狀態：**READY**（2026-08-09）

本規格只定義 remake 的裝置輸入外殼，不改寫原版戰鬥規則。鍵盤仍是完整可用的
基準；滑鼠與 Android 單指觸控先轉成 `internal/ui/actions.Action`，再走與鍵盤
相同的 `cmd/dsds` 狀態機。

## 1. 已證實命令的點擊入口

戰鬥右側面板的五列命中區依序派送：

| 點擊列 | 動作 | 鍵盤等價 | 原版證據 |
|---:|---|---|---|
| 1 | `battle.command.1` | `1` | `sub_4D3F6 → sub_4B475` |
| 2 | `battle.command.2` | `2` | `sub_4D3F6 → sub_4BF27` |
| 3 | `battle.command.3` | `3` | `sub_4D3F6 → sub_4C2EA` |
| 4 | `battle.command.4` | `4` | `sub_4D3F6 → sub_4C33B` |
| 5 | `battle.command.5` | `5` | `sub_4D3F6 → sub_4D224` |

點擊只進入相同子狀態；攻擊目標、撤退省份、駐軍效果與查閱內容仍遵守各自的
證據邊界。尚未閉合的原版後續流程不得因為有點擊入口就被補猜。

## 2. 三個 remake 大按鍵

面板底部新增三個 56×48 邏輯像素的可見圖形按鍵，順序固定為：

1. 攻擊：派送既有的 `battle.attack`，等同目前已標示為 remake 差異的
   Enter／相鄰第一個敵軍捷徑；不冒充原版 `2` 後第二層六鍵選單的完整攻擊語意。
2. 換部隊：派送 `battle.next-unit`，等同鍵盤 `Tab`。
3. 結束回合：派送 `battle.end-turn`，等同鍵盤 `Space`。

這三鍵不改 `BattleSim` 的規則；它們只呼叫原本鍵盤已走的分支。按下／放開一次
只派送一次，拖曳超過指標門檻或畫面切換時取消。按鍵的視覺圖形由 renderer
程式繪製，不依賴倚天字模新增詞條。

## 3. 版面與輸入契約

- 五列命中區與 `internal/ui/layout.BattleCommandButton` 共用幾何；不另維護座標表。
- 三個大按鍵與 `internal/ui/layout.BattleControlButton` 共用幾何，均為 48×48
  邏輯像素以上；不覆蓋已量測的戰鬥資源欄位。
- `actions.Hit` 的命中順序先處理面板控制，再處理六角格；面板與戰場不重疊。
- 所有動作均可由鍵盤完成，觸控不是第二套規則入口。

## 4. 尚未包含的工作

本規格不宣稱 Android 封裝、旋轉／背景恢復、原版攻擊六方式、撤退省份輸入、
駐軍寫入、`.DT2` 戰損同步或完整多目標選取完成。這些要等各自的 DOSBox／IDA
證據與後續規格。
