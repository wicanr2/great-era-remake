# SPEC-42：Modern 政略指令矩陣 H4／M1

> **狀態：READY（15 項既有政略指令的高解析矩陣重排；不改規則）**  
> 日期：2026-08-12  
> 前置：`SPEC-41` 的軍事衛星作戰室外殼與 1280×720 設計畫布已接。

## 1. 目標與邊界

H3 的 3×5 長條卡雖已可點，仍像舊式清單放大。本切片在 H4 衛星作戰室的工作區內，將
既有 15 項政略指令重排為 5×3 指令矩陣：每格是同一個 `Selection(1..15)` 的視覺與命中區，
只改善掃視與觸控密度。

指令順序維持 row-major 的 `1..15`，格上同時顯示原始編號；不新增分類、快捷鍵、冷卻、成本、
任務、選取狀態或任何新 `Action`。繁中、英文、日文標籤、圖示與返回文字仍由既有 wording／
theme provider 提供。

## 2. 幾何與輸入契約

`NewModernCommandLayout` 只能從 `NewModernPageLayout` 取得 body，不能另複製設計座標。
在目前 1280×720 尺寸，body 是 `(112,98,1144,518)`，使用 5 欄、3 列、12 px gap：

| 項目 | 值 |
|---|---:|
| 卡片數 | 15 |
| 卡片寬／高 | 219×164 px（整數除法留下的邊界空白不拿來當命中區） |
| 最小命中區 | 遠大於 48×48 設計 px |
| 編號映射 | `cards[i]` → `Selection(i+1)`，不改鍵盤數字／規則處理 |

pointer、renderer 與測試必須消費同一份 `Cards`。卡片不重疊、不超出 body；相鄰 gap 不是
可操作區。640×350 原味指令頁不改。

## 3. 視覺契約

每張卡使用深色控制面、勢力色細帶、圖示、固定可見序號、短標籤與非互動訊號短線。
圖示與訊號只輔助辨識，不能替代本地化標籤；所有 15 張圖示仍由完整 `theme.Modern` provider
原子載入。沒有外部圖、原版美術、AI 圖、照片或未授權紋理。

## 4. 驗收

1. layout 測試鎖定 5×3、15 張、不重疊、在 body 內且每張至少 48×48。
2. `cmd/dsds` pointer 測試鎖定第 15 格仍派送 `Select15`；鍵盤路徑不改。
3. renderer 在三語系字型 gate 下能畫序號、圖示、標籤；不因缺圖示靜默使用錯位圖。
4. Docker＋Xvfb 針對性測試、no-cgo、資產拒絕掃描和 diff check 通過。正常玩家路徑截圖
   僅作 H4 視覺抽樣，不冒稱原版介面 parity。

## 5. 2026-08-12 M1 實作紀錄

`NewModernCommandLayout` 已改為 5 欄、3 列、12 px gap 的共享矩陣；renderer 現畫出固定
編號、theme icon、短標籤、色帶與非互動訊號短線，pointer 仍以 `cards[i]` 派送
`Selection(i+1)`。中文、英文、日文以 `cmd/screenshot` 的同一正常資料路徑完成抽樣，三者
均未觸發缺字或截圖錯誤；暫存畫面不進 `docs/images/` 或推廣片。
