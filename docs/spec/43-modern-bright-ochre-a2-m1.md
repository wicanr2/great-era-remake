# SPEC-43：Modern 明亮土黃 A2 介面 M1

> **狀態：READY（使用者已確認 A2、C 字體分工及 Modern 全面無頭像）**  
> 日期：2026-08-12  
> 前置：`SPEC-40` 的肖像權利 gate、`SPEC-41`／`SPEC-42` 的高解析幾何與既有 action。

## 1. 決策與勘誤

使用者在並列可丟棄原型後確認採用 A2：Modern 主畫面改為明亮土黃／米黃紙面、朱紅焦點與
深褐文字，保留原版明亮感與民國時期公文、檔案櫃、印章的視覺聯想。`SPEC-41` 的深藍黑
「軍事衛星作戰室」只保留為歷史原型，不再是 Modern 主視覺；其 1280×720 畫布、既有 action、
14×14 地圖幾何與輸入契約仍有效。本規格不改規則、存檔或語系資料。

## 2. A2 字級與文字安全區

Modern 高解析畫面採下列最小階層；實際 glyph 仍由可再散布的 GEMF atlas 優先提供：

| 角色 | 目標顯示高度 | 用途 |
|---|---:|---|
| 畫面／省份主標題 | 約 30 px | 單行，超出安全寬度時截短，不壓到日期 |
| 司令官姓名、主要按鈕 | 約 24–30 px | 固定單行，依按鈕／身份欄中心對齊 |
| 摘要數值與內文 | 至少 16 px | 不以縮成不可讀小字處理溢位 |
| 次要標籤、日期、署名 | 至少 14–16 px | 與背景保持可辨識對比 |

每個按鈕以同一 `Rect` 推導繪製、文字安全區與 pointer／touch 命中區；文字內縮至少 16 px，
裝飾角不得侵入文字安全區。繁中、英文與日文最長實際詞條都要做 containment 測試或截圖抽樣。

### 2.1 使用者確認的 C 字體分工（2026-08-12）

同畫面 A／B 抗鋸齒原型顯示，既有 16×16、1-bit 字模放大無法提供 Modern 高解析品質。
使用者確認採用 **C：主標題宋體，按鈕／內文／數值黑體**：宋體只負責頁首、畫面名稱與
人物檔案等具歷史公文氣質的標題；所有需要快速掃讀、滑鼠／觸控操作的控制項與長文維持黑體。

- Modern 預設字模改為 32×32、8-bit alpha coverage 的 GEMF v2；不得以模糊現有 1-bit 字模
  假裝增加曲線細節。
- 執行期維持純 Go alpha 合成，不載入 FreeType、不引入 `cgo`；字模由鎖定的 Docker 工具鏈
  離線重生。
- GEMF v1 可作明確 fallback，但不可把 fallback 當成高解析完成證據。
- `retro` 的原版像素字形、畫布與最鄰近縮放不受影響。
- 原版花框與遮罩保留像素銳利；Modern 程式化圓形圖示、人物照片及新作圖片另走高解析取樣，
  不對整張畫面套線性模糊。

## 3. 原版素材衍生裝飾的執行期邊界

使用者允許以原版素材產生 Modern 裝飾。實作只在玩家以 `-game` 提供的唯讀原版資料中，於
執行期解碼 `MENU1.TPC`～`MENU5.TPC` 與 `WARMENU.TPC`，把非背景像素當遮罩，依 A2 色組
重新著色並縮放／平鋪到按鈕和面板邊界。

- 儲存庫、release 與預先產生資產不得夾帶上述原版檔或其點陣衍生物。
- 缺檔或解碼失敗時，Modern UI 仍以可再散布的雙線、折角與印章式角飾 fallback 完整顯示；
  不得留下空框、半載入 theme 或阻塞原味模式。
- runtime ornament 是呈現差異，不是原版逐像素還原聲明。

## 4. Modern 受控人物頭像（2026-08-12 再訂正）

使用者最新指示覆寫先前的全面無頭像決定：Modern 地圖司令欄與人物自傳恢復人物頭像。
只能使用 `SPEC-40` 登錄中通過人物身分、授權、來源與 SHA-256 gate 的離線圖像；未登錄人物
顯示同尺寸中性檔案卡，不能以另一人的照片、AI 人臉、原版頭像或網路即時下載補洞。

- 不因人物是否知名、是否存在歷史照片而產生不同版面；吳佩孚等知名人物有歷史照片，但舊畫面
  的「尚未找到可驗證肖像」只代表當時 `PortraitCatalog` 沒有通過 gate 的登錄，不代表史實上
  沒有照片。
- 玩家路徑與 `cmd/screenshot` 重新載入 `PortraitCatalog`；發行包若含肖像，必須同時包含登錄、
  JPEG、授權 notice 與一致雜湊。目前唯一正式登錄是蔣中正公有領域照片。
- `retro` 640×350 畫面維持不變。

## 5. 裝飾控制項契約

地圖主按鈕、導覽按鈕、15 項政略指令、流程選項、數字鍵盤與戰鬥控制鍵必須共用同一裝飾
primitive：紙面／朱紅底、雙層框、原版遮罩角飾（若可用）及明確焦點色。裝飾不得產生新 action，
不可把純裝飾畫成另一個可點區，也不可改變既有 `Selection` 編號或觸控矩形。

## 6. 驗收

1. layout 固定保留司令官肖像槽；它不得和司令姓名或六張摘要卡重疊。
2. 蔣中正地圖與人物自傳的正常資料截圖必須顯示已驗證照片；未登錄人物顯示檔案卡。
3. 原版裝飾 loader 以合成 BGI fixture 測試完整／缺檔／壞檔；缺裝飾仍畫出可再散布 fallback。
4. 抽樣主地圖、指令頁與人物檔案，人工確認字級、按鈕裝飾及司令官照片；截圖只用正常資料路徑。
5. Docker 內執行受影響 package 測試、`tools/check_no_cgo.sh`、`tools/deny_scan.sh --all` 與
   `git diff --check`；不以本切片宣稱三平台包或推廣影片已重錄。
6. 同一畫面須同時出現宋體主標題與黑體按鈕／內文；灰階字形測試至少覆蓋 alpha 0、半透明與
   255 三種合成結果，並抽查繁中、英文、日文在 1280×720 的安全矩形。
