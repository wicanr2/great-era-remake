## 3. R2：有據檔案卡（全槽覆蓋的關閉條件）

R1 之後仍 `unknown` 的槽位，不留空白頁，改用有據檔案卡：

- 內容只許三類：遊戲內原始資料（所屬省、效忠領袖、兵力、兵種）、已排除的查證
  記載（「某來源查無此人」是事實可寫）、待考標示。句句可溯源，無推定句。
- UI 與有傳人物同版面（肖像欄／檔案卡位置固定，不因缺文跳動），頁首明示
  「史料待考」而非冒充傳記。
- 關閉定義：486 槽中 485 可接合槽皆有「正文或有據檔案卡」＋#274 佔位維持排除；
  `people_test.go` 全綠；英／日 overlay 同步（machine-draft 標示維持，人審另列 gate）。
