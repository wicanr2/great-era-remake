# SPEC-44：Modern 民國測繪風地圖與專屬指令圖示 M2

> **狀態：IMPLEMENTED（2026-08-12；正常資料截圖與全儲存庫回歸已通過）**  
> 前置：`SPEC-43` 的 A2 明亮土黃、C 字體分工、全面無頭像，以及既有 15 項指令／地形索引契約。

## 1. 決策與範圍

使用者在第二版可丟棄原型後選擇 A：地圖與指令頁同時採用明亮民國測繪圖／軍政檔案風。
舊版五種循環圓章與低差異地形不再是 Modern 視覺驗收基準；`retro` 原味模式完全不變。

本切片只替換呈現，不新增或更名玩法，不改命令成本、`Selection(1..15)`、地圖資料、
`TileKind`、鐵路接線、戰鬥規則、存檔、pointer／touch 矩形或語系文字。

## 2. 十五項指令圖示契約

- 正式圖示必須逐一對應目前 `command.01`～`command.15`；prototype 中為展示而出現的「醫療」
  「撤防」等示意名稱不得進正式程式。
- 15 個 index 各有獨立主要輪廓；不可再以 `index % 5` 循環五種符號，再只靠顏色或短線區分。
- 圖示使用純 Go primitive 在目的尺寸的 4 倍 RGBA 畫布繪製後面積降採樣；不得依賴 emoji、
  外部 webfont、執行期 SVG parser、`cgo` 或原版素材衍生檔。
- 顏色只作領域分組，玩家在灰階或色覺差異下仍應能由輪廓辨識；標籤仍以語系資料為準。
- 低解析 16×16 provider 保留相同 index 語意作 original-resolution fallback；高解析完成證據以
  44×44 目的尺寸畫面與測試為準。

## 3. 民國測繪地形契約

Modern 高解析地圖以明亮紙面、深褐墨線、藍綠水系、灰褐山脈、農地黃綠與朱紅軍政記號組成。
下列類別至少同時由輪廓、色彩與紋理中的兩項區分：

| 類別 | 必備辨識點 |
|---|---|
| 平原／農地 | 淺黃綠地表、稀疏田畦或測繪線，不與沙漠共用波紋 |
| 丘陵 | 圓弧等高線／重疊丘線，不使用高山尖峰 |
| 高山／雪峰 | 灰褐三角山脈與亮色雪線 |
| 河流／海域 | 藍綠水色；河流有方向性流線，海域有水平波紋 |
| 森林 | 深綠樹冠／針葉群，不只用隨機綠點 |
| 沙漠／乾地 | 赭黃底與連續沙丘波紋 |
| 城市 | 朱紅城樓／城牆記號，與一般部隊 token 分離 |
| 關口 | 門樓／隘口輪廓，必須不同於城市 |
| 長城 | 深褐牆體與垛口連線 |
| 橋 | 跨水拱橋或橋面／橋墩，方向與圖塊語意一致 |
| 鐵路 | 雙軌或主線加規律枕木，維持 21 種四向接線 |

22 個地形 index、21 個鐵路 index 與 18 個部隊 index 均維持既有資料契約；同類 variant 可共用
視覺家族，但必須有 deterministic variation。高解析路徑直接由語意生成，不取樣低解析 bitmap。

## 4. 受控頭像與版面邊界

地圖軍情欄與人物自傳顯示 `SPEC-40` 通過 gate 的人物照片；缺圖時顯示中性檔案卡，不使用剪影
或錯配照片。其餘右側空間只可放現有省份、司令、省長、資源、圖例或操作提示；不得新增未證實
軍情、任務或規則。人物自傳固定保留肖像欄，避免有圖／無圖造成分頁跳動。

## 5. 驗收

1. 15 個高解析指令圖示逐像素互異，且以 shape signature／人工 contact sheet 證明不是五種循環。
2. 22／21／18 全索引目的尺寸、deterministic、透明與越界 fail-closed 測試通過。
3. 高山、丘陵、平原、森林、沙漠、水域、城市、關口、長城、橋與鐵路須在正常 1280×720
   地圖／戰鬥截圖中抽樣；不能只用孤立 icon fixture 代替實際畫面。
4. 繁中、英文、日文指令標籤仍落在原卡片安全矩形；pointer／touch action mapping 不變。
5. Docker＋Xvfb 全 repo test、`tools/check_no_cgo.sh`、`tools/deny_scan.sh --all`、
   `git diff --check` 與容器清理狀態通過。
6. 本切片完成不等於重錄推廣片或重打三平台包；兩者仍是後續發行 gate。
