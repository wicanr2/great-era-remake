| 項目 | 契約 |
|---|---|
| 幾何 | 1280 寬設計畫布，工具列高 48；四欄依定稿排列「美術、介面、AI、操作」。640 寬模式等比縮為高 24。工具列在原遊戲畫面之外，完整遊戲向下平移，畫布增加相應高度。 |
| 美術 | 原版／HD，沿用 `setThemePreference`，原版鐵路形狀、規則、資料與音樂不變。 |
| 介面 | 原版／指揮，沿用 `setInterfacePreference`，與美術獨立，保留四種組合。 |
| AI | 只顯示現有重製 AI 與說明。沒有強化等級、自動代打或 AI 策略切換，不宣稱原版完整 AI 一致。 |
| 操作 | 預設鍵盤加滑鼠，可切純鍵盤。新增布林偏好 `keyboard_only`，缺欄為 false，保存於既有 `prefs.json`，不加入原版存檔。純鍵盤仍可用滑鼠操作工具列。 |
| 輸入焦點 | 點選開啟下拉選單，先處理工具列，選單開啟時隔離遊戲輸入。點外部只關閉選單，整次按下／放開不穿透。Esc 先關閉工具列選單或焦點，不收合工具列。F6 將鍵盤焦點移入工具列；左右選欄、上下選項、Enter 套用。F10 保留離開確認與自動存檔。 |
| 游標座標 | 滑鼠與觸控先扣工具列高度，再沿既有高解析或原版座標換算。地圖拖曳、縮放、人物頁與命中區共用此入口。選單或工具列範圍不能落入遊戲區。 |
| 滑鼠 | 左鍵沿現有 Action 操作選單、數字鍵盤與戰術。右鍵等價於當頁 Esc 的返回或取消，不離開遊戲。人物／新聞的滾輪對應翻頁，地圖保留拖曳與滾輪縮放。純鍵盤停用遊戲區滑鼠點擊、拖曳、右鍵及滾輪。 |
| 失敗 | 偏好寫入失敗沿既有回報路徑，畫面與輸入模式不部分套用。切換或開啟工具列清除待送遊戲點擊及地圖拖曳。訊息等待、離開確認及存檔失敗維持既有行為。 |
| 呈現 | 沿用土褐、鐵黑與砂岩字色，沒有新綠色或大型素材。工具列使用引擎既有黑體；AI 說明與所有新增標籤來自三語系文字表。選單圖片只快取目前狀態，不每幀解碼素材或配置大畫布。 |

新增標籤需要 `便内変断鼠＋` 六個字模。沿用相同 Noto Sans／Serif CJK TC 來源及既有重生工具，兩包合計增加 12,384 bytes；全部舊字模逐筆位元組核對相同。來源雜湊及字模包入口見[字型授權](../licenses/modern-font-atlas.md)，這項呈現資料增量不改遊戲資產 parser 或規則。

垂直鏈為既有原始資料 → 解碼器 → 原有規則與 Action → 工具列／滑鼠 adapter → 既有 setter 或 UI 狀態 → `prefs.json`。`.DT1`／`.DT2` writer、戰損、命令消耗、AI 決策與音訊保持既有實作。程式入口為 `cmd/dsds/toolbar.go`、共享幾何 `internal/ui/layout/toolbar.go` 及呈現 `internal/ui/render/toolbar.go`。

## 驗收與停止線

- 純幾何測試檢查原版／高解析工具列位移、按鈕與選單邊界、下拉選單說明區不產生指令。
- 偏好測試檢查舊檔預設、純鍵盤保存與錯誤類型拒絕；狀態測試檢查點擊不穿透與右鍵語意。
- 正式 Go 套件回歸、純 Go 閘門、三語系與素材拒絕掃描通過。
- 固定 seed 1，由正常入口以滑鼠切換四種介面／美術組合、開啟人物與翻頁、地圖拖曳／縮放、開發選單、數字輸入及取消；純鍵盤切回、戰術命令與返回、F10 確認／取消、存讀檔與重啟抽樣驗證。
- 同初始狀態比較工具列切換前後存檔，核對切換不消耗命令。保護輸入雜湊見本機 `workplace/hoi4-ui-prototype/toolbar-20261015/baseline.json`。

驗收只宣稱正常玩家路徑的重製操作，沒有新原版 oracle、跨平台真機或人耳驗收。首次整合範圍不含打包；後續發行見 SPEC-51。公開展示圖沿既有截圖白名單，原版資料、字庫與完整本機素材不公開。
