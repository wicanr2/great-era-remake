# SPEC-33：Modern 高解析版面 H1-a／H3（歷史策略儀表板 metrics）

> **狀態：READY（H1-a 幾何；H3 歷史技術基準，非最終視覺驗收）**  
> 日期：2026-08-11  
> 範圍：`internal/ui/layout` 的 1280×720 設計座標、地圖頁共用命中矩形。

> **2026-08-11 勘誤：** H3 的 `ModernMapLayout`、命中矩形與正常輸入路徑仍為已驗證的
> 技術成果；使用者已撤回其作為最終 Modern 視覺方向的驗收。後續 H4「全域指揮室」必須
> 另立 DRAFT→READY 規格，不得藉本份 READY 幾何文件直接擴寫視覺設計。

## 1. 目的與邊界

H0 已能把 640×350 frame 安全放入 1280×720 Surface，但那只是過渡橋接；文字仍以
原版欄距排版。H1 建立可重用 metrics；H3 曾以「任務主導策略儀表板」配置它，地圖
保留為戰略上下文，玩家本回合真正能判斷與採取的行動放在第一層。這些 renderer／滑鼠／
觸控共用矩形的成果可重用，但不構成 H4 的視覺設計核准。

本切片只處理：

- A 方案的 1280×720、16:9、橫向設計座標與 24 px 設計安全區；
- 頂列、左側地圖卡與右側 464 px 策略儀表板；
- 六張本回合摘要卡（指令、軍力、將領、金、糧、忠誠）、後勤摘要，以及兩個已存在的玩家入口；
- 14×14 六角格以 3/2 顯示倍率繪製，保留奇數欄下移半格；
- metrics 的純 Go 邊界測試。

本切片不處理：

- 遊戲規則、AI、戰鬥、`.DT1`／`.DT2`、存檔或亂數；
- 原版 640×350 路徑與既有 `Action` 識別碼；
- 字型清權、Android binding、48 dp 實機量測或三平台封裝；
- 新增未存在的快捷行動、規則、AI、存檔欄位或任務系統。儀表板只呈現既有資料與
  已有的「指令」／「新聞」入口，不以假按鈕營造功能；
- 其他頁面的高解析 renderer。未接入的畫面維持 H0 fallback。

## 2. 設計座標契約

`ModernDesignSurface()` 固定回傳 `1280×720` 與四側 24 px 安全區。實體視窗／手機
Surface 由平台 adapter 等比映射；renderer 不直接把裝置像素當成 Android dp。

`NewModernMapLayout` 產生：

| 區塊 | 尺寸／規則 |
|---|---|
| `Header` | 內容區全寬 64 px；顯示省份與日期，保留戰略上下文 |
| `MapCard` | 內容區左側 744×592 px；只承載地圖，不疊加入口按鈕 |
| `InfoPanel` | `MapCard` 右側、間隔 24 px 的 464×592 px 策略儀表板 |
| `Map` | 448×348 原版戰場以 3/2 成為 672×522 |
| `MetricCards` | 3×2，依序呈現剩餘指令、兵力、將領、黃金、糧食、忠誠；只讀既有 `PanelData`，不自行推導規則 |
| 後勤摘要 | 彈藥、燃料、煤礦、鐵礦採緊湊雙欄，不與摘要卡或按鈕重疊 |
| `CommandButton`／`NarrativeButton` | 416×64／416×56，置於儀表板底部；命中區與繪製區相同 |
| 六角格 | 每格 48×36；奇數欄再向下 18 px |

`Rect.Contains` 是半開區間；所有命中測試以它為準，避免邊界重複派送。尺寸不足或
非 1280×720 的設計畫布必須明確回錯，不得靜默退回另一套 metrics。

## 3. 驗收

- `go test ./internal/ui/layout` 通過；頂列、地圖卡與策略儀表板不重疊。
- 六張摘要卡與兩個既有入口均在策略儀表板內，寬高至少 48 px 設計下限；地圖卡
  不再被工具列遮住。
- `(0,0)` 與 `(1,0)` 格子的水平間距為 48、奇數欄垂直位移為 18；越界格拒絕。
- 這些 metrics 未引用原版圖像、字型或音樂，也不改變現有 640×350 golden。

## 4. H3 歷史技術基準與邊界

2026-08-11 曾採用「任務導向策略儀表板」，排除「僅把原版地圖與側欄放大」。它確實
不變更原版規則、Action、存檔或戰鬥結果，且 `cmd/dsds`、無頭 renderer、滑鼠與觸控
adapter 都消費 `ModernMapLayout`，因此不是只好看但不能操作的第二條 UI 路徑。

同日使用者判定該視覺過於乾燥、仍近似放大舊版，故它僅保留為技術與回歸基準。新根層
架構已確定為 A「全域指揮室」；其導覽列、中央地圖工作區、脈絡檢視器、底部指令／事件列、
戰鬥畫面、人物檔案與 Android 斷點尚未立成 READY 規格。本文件不得被引用為 H4 視覺驗收。
