## 型錄

| 裝備 ID | 裝甲 | 穿甲 |
|---|---:|---:|
| `legacy-rifle`、`rifle-old` | 0 | 5 |
| `rifle-modern` | 0 | 10 |
| `legacy-artillery`、`mountain-basic` | 0 | 20 |
| `mountain-improved` | 0 | 30 |
| `field-howitzer` | 0 | 40 |
| `antitank` | 0 | 80 |
| `legacy-armor` | 20 | 30 |
| `light-tank` | 50 | 50 |
| `armor-improved` | 70 | 70 |

係數無毫米單位。敵我使用相同資料；同一兵種按實際配發數加權，以裝備需求為分母，缺裝算 0。沿用型錄順序及需求上限，不讓超量或不相容裝備增加數值。沒有軍備帳、未知兵種或零兵力時，衍生係數為 0。

有效係數用千分之一固定小數保存於暫時結果，不改存檔 schema。加權結果以四捨五入計算。例：需求 20 組，10 組輕型戰車與 10 組舊裝甲，裝甲為 35、穿甲為 40；只有 10 組輕型戰車時，兩項均為 25。研究解鎖或倉庫庫存不影響尚未換裝的部隊。

## 傷害與邊界

`折減率 = 0.5 × (1 − min(攻方穿甲 ÷ 守方裝甲, 1))`。

- 守方裝甲為 0 或穿甲不小於裝甲時，保留原武器傷害。
- 先完成既有將領、兵力、地形、火力、協同／衝鋒／遠程傷害計算及兵力上限，再套防護，最後一次四捨五入。零傷害仍為零，正傷害不因 50% 上限變成免傷。
- 雙方使用各自開火時的配裝，計算出兩側損失後才寫回；不能先扣一方裝備再計算其反擊穿甲。
- 原傷害 100、裝甲 50、穿甲 5 時為 55；穿甲 80 時為 100；穿甲 0 時為 50。以 64 位整數運算，公開係數入口限制在型錄合法範圍內。
- 正規、協同、騎兵及遠程 handler 共用唯一防護函式。士氣造成的額外兵損保持獨立，不宣稱整場所有耗損都能減半。
- 已配發的裝備在關閉軍備研究時仍保留火力、防護與戰損入帳，遵守 SPEC-63 的保留契約。

## 垂直鏈與驗收

型錄 → 實際配裝帳 → 共用防護 → 快速／玩家戰術 → 雙方資料頁 → 人員與裝備損失 → v2／v3 保存與重啟。雙方資料列出有效裝甲／穿甲，明示為係數；原版未追蹤資料仍顯示未提供。

需要驗證零裝甲、部分／完全穿透、50% 上限、混裝、缺裝、不相容裝備、極值、對稱性、舊規則回歸，以及四種 handler 的實際傷害和損失帳。正常開局啟用軍備後，查看雙方係數、返回、保存重啟並核對數值與 RNG。裝甲改編的既有正常研究／生產／換裝收據沿用 SPEC-55，本輪追加裝甲傷害與保存測試；不把注入裝備的測試當成正常入侵驗收。

完整日軍入侵、補給波次、年代名冊與勝負仍由 SPEC-63 及 #23／#24／#26／#27 負責。正式版、原始資料與舊交付不覆寫。
