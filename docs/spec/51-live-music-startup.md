# SPEC-51：遊戲內音樂切換與零參數啟動

狀態：READY。使用者已授權遊戲中任意切換音樂、雙擊直接遊玩，完成後重新打包與發布。此項為重製版操作外殼，不修改原版規則或宣稱原版音訊逐樣本一致。

## 行為

- 常駐工具列增加音樂欄，提供 HD、原版 AdLib、靜音，以及自動情境選曲與八首指定曲目。美術、介面、輸入偏好及現有 AI 維持獨立。
- 預設為 HD 美術、指揮介面、高解析度、滑鼠及 HD 音樂。舊偏好缺少音樂欄時沿用此預設；明示命令列參數優先。
- 音樂偏好保存於既有 prefs.json，不寫遊戲存檔。切換失敗保留原先播放與偏好。靜音關閉全部音樂及效果播放器。切回音樂不建立第二個 Ebiten Context，使用同一裝置取樣率；Ogg 循環點依取樣率換算。
- 畫面切換時自動選曲仍使用既有對應；指定曲目時維持選擇，選回自動後恢復情境選曲。未提供原版曲目時明示失敗，不猜補旋律。
- 零參數啟動從執行檔旁、macOS Resources 或 Linux usr/share/great-era 尋找包內資源，最後才使用開發工作目錄。明示路徑不被改寫。
- Windows、macOS、Linux 存檔沿用既有平台使用者目錄，包內 data 唯讀。公開引擎仍需要使用者合法匯入原版資料與字庫。
- 啟動器不強制覆蓋已保存的音樂偏好。

## 驗收與交付

以固定 seed 1 正常玩家路徑抽測地圖、政略與戰術中的音樂／美術／介面切換、靜音後恢復、偏好重啟及存讀檔。驗證共用音訊裝置、循環取樣換算與設定寫入失敗回復。Linux 與 Wine 從無關工作目錄零參數啟動；macOS 交叉建置及包內路徑驗證不宣稱真機通過。
