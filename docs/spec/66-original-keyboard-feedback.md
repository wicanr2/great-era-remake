# SPEC-66：原版介面純鍵盤回饋修復

狀態：CONFORMED，限定本機 Linux 正常玩家路徑。使用者於 2026-10-18 明確要求依原版顯示玩家回饋修復。由 [Issue #35](https://github.com/wicanr2/great-era-remake/issues/35)追蹤；此項限定輸入、導覽與資料呈現，不改軍政、戰鬥或保存格式。

## 已核對原因

等級為 `confirmed-remake-code`，沒有新原版 oracle。`cmd/dsds/main.go:screenCommand` 的指令 2 只接 A，指令 3 只接 S；`pointer.go` 與多個數字迴圈只讀主鍵盤數字。`screenViewGenerals` 只傳姓名與兵力；完整 General 及戰力已存在。原版根畫面目前是省內戰場，沒有全國地圖入口。結果訊息在全域 F10／Esc 之前擋掉輸入。

修正前二進位為 `invasion-20261018/dsds-armor`，SHA-256 `884e251c0da74467b1dc612886a3017d236cd84d3bb8694ade53f20ecec79686`。來源與正常重現由[本機工作區](../../workplace/hoi4-ui-prototype/keyboard-feedback-20261018/README.md)進入。

## 輸入與取消

- 主鍵盤 2／3 與數字鍵盤 2／3 對應畫面的出兵／運補，保留 A／S 別名。0 在政略指令頁仍是第 10 項停火，在其他選項仍是第 10 項解析度，不改成全域返回。
- 數字輸入共用主鍵盤與數字鍵盤；0 是數字。Backspace 刪最後一位；Delete 清空當前未提交欄位，不能刪除存檔或已確認交易。Enter／數字鍵盤 Enter 沿用原確認入口，Esc 回上一層。
- 沒有數值欄位或第 10 項的子選單可用 0 返回；確認頁仍以 N／Esc 取消。正在整編的返回仍依 SPEC-58 取消確認與守恆，不把 0 當成丟棄人員。
- 結果訊息仍按原設定時間消失，Esc 可提前關閉當前訊息，該按鍵不再穿透執行下一層命令。F10 可以直接開啟保存離開確認。

## 原版地圖與資料

- 原版根畫面提供全國地圖，使用既有 atlasmap、當期有效省份及目前所有權；左側原版省份面板保留。這是重製版補齊，不宣稱原版地圖像素對拍。
- P 查看目前省內六角地圖；Esc／0 回全國地圖。唯讀查閱頁與指令頁可用 Home 直接回全國地圖，保留選省；不能從未完成整編或未確認交易繞過既有取消機制。Enter 仍開指令，方向鍵選省。戰鬥暫停仍保留戰鬥。
- 原版部隊清單以直式完整資料列顯示姓名、兵種、兵力、帶兵、忠誠、政治、經驗、攻擊、武裝、戰技、體力、士氣與番號。來源沿用目前 General、唯一 Strength 與姓名入口，不補假值。
- 每頁少量完整部隊，↑↓選將、PageUp／PageDown 翻頁，Enter 看既有詳情，B 看自傳，Esc／0 返回。所有文字使用有界矩形，不能用裁切掩蓋溢位。
- 不增加大型美術、改鐵路或套全畫面濾鏡。原版／HD 美術與 Modern 介面仍可獨立切換；Modern 的既有表單與返回維持原契約。
