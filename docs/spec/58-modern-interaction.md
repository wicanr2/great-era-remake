# SPEC-58：Modern 滑鼠操作重規劃

狀態：CONFORMED。使用者於 2026-10-16 回覆「ok 同意」，採用已展示的 Modern 構圖及「取消整次整編、還原開始前兵力與武裝」，授權接回可玩版。工作由 [Issue #30](https://github.com/wicanr2/great-era-remake/issues/30)及返回子項 #31 追蹤；先前局部修正由 SPEC-57／59 保存。

## 已採用範圍

已確認保留原版、Modern 可切換、原版／HD 美術與音樂獨立、常駐工具列不收合、純 Go／Ebiten，以及返回操作可不同於 DOS。既有 command 偏好相容映射為 Modern，不另創第三套重複介面。採用圖保存於 docs/images/modern-*-approved-20261016.png，來源與雜湊在本機 modern-native-20261016/adoption.json；原瀏覽器頁與收據保留。

現有指揮介面已有地圖拖曳、縮放及選單點擊，但調動、運補、徵兵、商業等數量輸入仍分步使用虛擬數字鍵盤。高解析確認頁送錯 Back／Cancel 已依 SPEC-57 修正；接線前整編非零兵力池會阻止離開。這些是接線前的程式事實，不推定朋友卡在特定畫面。

## 操作提案

| 區域 | 提案 |
|---|---|
| 常駐工具列 | 美術、原版／Modern、現有 AI、音樂及操作偏好固定可見；入口與遊戲內容分開，點選不穿透 |
| 導覽 | 每頁固定「返回」、可點的目前位置及「全國地圖」；確認動作與返回分開，表單未提交即可取消 |
| 選省／選將 | 點地圖或具名列表，清楚標示己方、可用目標、選取數與不可用原因，不要求記省份或將領編號 |
| 數量表單 | +/-、滑桿、常用量與上限，所有資源同頁，費用及結果預覽後才確認；鍵盤輸入保留但非必要 |
| 戰術 | 左鍵選單位、顯示合法目的地及目標、點選後沿原規則執行；可見返回及雙方詳情。雙擊、右鍵與快捷鍵均非唯一入口 |
| 整編 | 已採用取消未完成的整次整編並還原開始前配置。顯式確認才結束；返回先詢問取消，不丟棄池中人員。存檔保存可還原的初始快照 |
| 存讀檔 | 明確保存成功／失敗、繼續進度與載入確認；原型只做隔離示範保存，不冒充 .gesave |
| 桌面 | 大地土褐與鋼鐵配色、可辨文字及按鈕、滑鼠懸停提示；觸控板捲動／拖曳／縮放及平台快捷鍵另驗，不能以 Linux 截圖宣稱 macOS／Windows 真機通過 |

原型入口為 `workplace/hoi4-ui-prototype/modern-controls-20261016/README.md`。使用目前引擎地理及正常新局資料，來源、擷取與前後保護雜湊分開保存。原型中的操作回饋只驗互動設計，不新增科技、AI、國策或玩法數值。

## 接線前的返回盤點

下表保留接線前的問題與分派，完成範圍以文末原生驗收為準。它不能當作每頁 GUI 均已重跑。

| 流程 | 目前返回目的地 | Modern 接線重點 |
|---|---|---|
| 政略、開發、政策、外交、練兵 | 政略回地圖；各子頁回政略 | 固定返回與全國地圖；已執行命令不能因返回重複套用 |
| 徵兵 | 確認 → 數量 → 兵種 → 徵兵／整編 → 政略 | 同頁選省、兵種、數量及報價，確認前唯讀 |
| 調動 | 確認 → 最後物資；物資 → 選將 → 選省 → 模式 → 政略 | 具名目標、勾選將領與四項物資同頁，沿用現有合法性及 Apply API |
| 運補、商業 | 數量回目標或商品，目標或模式回政略 | 多資源表單及價格預覽；目前提交時已執行的結果不能默默回滾 |
| 重新整編 | 數量回選將；池為零才能結束，非零時返回沒有回饋 | 提案取消整次還原；需新增初始兵力／武裝快照及舊保存相容政策 |
| 人物、省份與自傳 | 人物詳情 → 將領列表；列表回開啟者；自傳回 `bioBack` | 保留來源、位置、分頁及選取；不回到無關首頁 |
| 產能、自治 | 未執行時回政策；已執行時回政略，產能輸入先回項目選擇 | 清楚區分未提交草稿與已完成動作 |
| 其他選項及存讀檔 | 確認、訊息時間、顯示與解析度回其他選項，再回政略 | 原生新局儲存的 origSave 入口限制依 SPEC-59 修正，兩個入口共用既有 autosave 的能力判定 |
| 軍備、戰鬥詳情及戰術子頁 | 軍備回原入口；雙方詳情回戰術指令；戰術選擇回指令 | 目前戰術指令的 ESC 會清掉 a.battle；進行中戰鬥的安全返回不能直接沿用此路徑。新增出口需保留 BattleSim、交戰旗標及可續戰入口，不暗中撤退或結算 |
| 離開 | 取消回 `quitBack`；確認後保存成功才離開 | F10 維持獨立離開確認；不能拿離開程式代替返回 |

操作提案參考 Microsoft 對左鍵主要動作、捲動及可見縮放按鈕的建議，右鍵返回則沿用本專案已確認的外殼習慣。[來源](https://learn.microsoft.com/en-us/windows/apps/develop/input/mouse-interactions)只作設計參考，不代表使用 WinUI 或取得平台驗收。

## 可試用原型及分界

`modern.html` 已示範具名選省／選將、徵兵報價與滑桿、固定返回／確認、人物正文、整編取消還原與保存草稿。資料為已驗證正常新局的 39 省、106 筆玩家單位，地圖由既有 atlasmap 產生兩張 1000×600 圖；沒有大型新圖集。原版選項在原型中明示為現行遊戲實錄參照圖，正式遊戲既有原版介面仍可玩。

`browser-report.json` 保存原型的實際左鍵點擊、可見命中、取消不改資料、非零兵力池退出、示範保存與毀損拒絕、原版參照返回 Modern、1024×768 及兩倍密度檢查。原型已採用，正式接線仍須下列原生驗收，不能把瀏覽器收據當遊戲完成。

## 工作與驗收順序

正常新局以滑鼠完成選省、選將、徵兵、調動、開發、軍備、戰術、返回、保存退出與重啟，並抽驗原版介面與三語、視窗尺寸及平台輸入。規則／保存不變的分支比較同狀態資料；新的取消整編差異另記錄，不稱原版 parity。

## 原生接線契約

原生桌面維持採用圖的 1280×800 設計畫布：58 像素常駐工具列、76 像素資源列、180 像素側欄、260 像素右欄；上方返回與地圖、下方確認固定，內容區可捲動。軍備與俯視戰術沿用先前已採用的專用 1280×720 構圖，不拉伸其圖格。視窗縮放由 Ebiten 等比映射；所有命中與繪圖共用矩形。字型沿用相同 Noto 內嵌字模，與 Chromium 的柵格化差異不更改構圖或字級。

- 新 Modern 外殼沿用 screen state、world、typed data 及既有 rule API；選單、滑桿、預設量與鍵盤輸入改同一份草稿，確認後才呼叫唯一執行入口。
- 徵兵直接使用 RecruitLimit／RecruitCost。調動沿用 BeginPlayerTransfer／Toggle／ApplyPlayerTransfer。運補四資源及商業價格沿用 SupplyAll／TradePrice／Import／Export；不能複製公式或略過合法性與預算。
- 原版／Modern、美術及音樂切換保留遊戲、草稿、RNG 與指令；command 偏好及命令列別名繼續接受，寫回採 modern。滑鼠選項不攔截未啟用的鍵鼠設定，工具列點擊不能穿透。
- 新整編先同步已發生的軍備變動，記錄每位候選的 Force／F20；擴充另記完整裝備分類帳快照，因原有 Armory.Sync 在保存草稿時會調整裝備。Cancel 先驗證候選、總兵力與快照，再原子還原兵力、武裝及裝備帳，不扣指令、不推進 RNG；完成沿用既有 finishReorganization。
- ReorganizationSnapshot 新增明示 `omitempty` 的初始人員與裝備欄位。v1／v2 外層及 DT1 原始 bytes 保留；JSON shape 僅允許明示可選欄位缺省，原必填欄位仍嚴格拒絕缺漏。舊整編保存缺少初始快照時可繼續分配及 F10 保存，不能猜造原配置或假稱可取消。新程式讀舊保存；舊程式不保證讀帶新欄位的整編保存。
- 戰術返回從子頁回指令，從指令可暫停並查看地圖。保留 BattleSim、交戰旗標與 RNG，提供明確「繼續戰鬥」；暫停期間只能查閱、切換呈現與保存，不下新命令、開新戰鬥或推進月份。`.gesave` 的戰鬥快照增加明示可選的 Paused，舊值缺省為 false。舊 DT1 直接執行入口沒有完整戰鬥保存，不能假稱暫停後可保存續戰；正常 DT1 匯入 `.gesave` 路徑支援。
- 取消整編、讀檔、徵兵等確認與 F10 離開各自處理。保存失敗保留遊戲；不能用清空物件或自動撤退代替返回。

來源是目前引擎與原型，不重開原版 RE。原始輸入、來源 SHA、前版程式及所有舊驗收由本機 modern-native-20261016/baseline.json 固定。驗收須包含新／舊保存、原版及擴充整編取消與保存重啟、草稿與兵力／裝備守恆、戰術暫停／續戰、三語與獨立切換、正常滑鼠主要流程，並留下採用圖對照、素材掃描與 Docker 清理。
