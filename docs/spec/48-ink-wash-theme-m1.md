## 2. 合約邊界（只換呈現，不碰規則）

- 仍是 `retro`／`modern` 雙 mode，`UIStyle`／`Theme`／`HighResolutionTheme`
  介面不變；整套重做 = 再次替換 Modern provider 的實作內容。
- 不改：15 指令語意、`Selection`、命令成本、地圖資料、`TileKind`、鐵路接線、
  戰鬥規則、存檔、pointer／touch 矩形、語系文字、AI、自傳 gate、尺寸／索引／
  透明規則。
- 排版沿用既有度量；新邊框只吃 text-safe 剩餘空間。
- 高解析圖一律目的尺寸 4 倍 RGBA 繪製後降採樣。

## 3. 切片與驗收

- **M1 配色＋部隊**：`modernPalette`／`Style()` 轉水墨 18 色；低／高解析
  18 剪影改焦墨勾勒＋勢力色淡染（形體飽滿，忌細線）。驗收：theme／render
  測試＋戰鬥截圖。
- **M2 地形＋圖標＋頁面**：`terrainColors` 角色重對（索引角色見 §1 表）、
  鐵路改渴墨主線、資源／指令／HUD 圖標隨盤重染、頁框改焦墨外圈＋黛藍內線。
  驗收：政略／自傳截圖＋`internal/ui/...` 全綠＋deny／no-cgo。
- 每一切片：Docker 測試 → Xvfb 1280×720 截圖目檢 → 閘門 → 登記。
  M2 結束後重包 `0.1.4-ink` 並更新 `docs/images/ink-*.png`。

- 正式 Ogg、Android 實機——仍是獨立 gate。
- 原版 oracle／parity 不因換皮重開（SPEC-30 維持）。
