# SPEC-49：老照片套印 Modern 主題 M1–M2

> **狀態：READY（2026-09-27）**
> 前置：SPEC-48（規格格式）、theme 合約（`internal/ui/theme/theme.go`）。
> 使用者決策（2026-09-27，confirmed-user-decision）：水墨風否決、remake
> 成果圖已全刪（commit `1a0b2f0`）；新方向為使用者親選的**老照片套印風**，
> 套印色為**紅攻＋藏青守**；範圍沿用**圖標＋配色全換**。
> `retro` 原味模式完全不變；戰棋／致敬／水墨產物保留為歷史。

## 1. 設計語言：檔案照片上的紅藍鉛筆

黑白老照片基調＋雙色套印：地形以暖灰銀鹽層次（平原淺灰、森林深灰、
水域中灰＋波紋、山地炭灰皴）呈現；攻方朱紅套印、守方藏青套印罩染其上，
如作戰檔案圖上的紅藍鉛筆標記。紙底用暖灰（非死白），視窗底壓深色。
禁 emoji、外部 webfont、執行期 SVG parser、`cgo`、原版素材衍生、紫色系。

## 2. 合約邊界（只換呈現，不碰規則）

- 仍是 `retro`／`modern` 雙 mode，介面不變；整套重做 = 再次替換
  Modern provider 的實作內容。
- 不改：15 指令語意、`Selection`、命令成本、地圖資料、`TileKind`、鐵路接線、
  戰鬥規則、存檔、pointer／touch 矩形、語系文字、AI、自傳 gate、尺寸／索引／
  透明規則。
- 排版沿用既有度量；新邊框只吃 text-safe 剩餘空間。
- 高解析圖一律目的尺寸 4 倍 RGBA 繪製後降採樣。

## 3. 切片與驗收

- **M1 配色＋部隊**：`modernPalette`／`Style()` 轉銀鹽灰階＋紅／藏青；
  18 剪影改灰階照片底＋套印色罩染（形體飽滿，小圖攻守可分）。
  驗收：theme／render 測試＋戰鬥截圖。
- **M2 地形＋圖標＋頁面**：地形轉銀鹽層次＋紋理、鐵路／圖標隨盤重染、
  頁框改墨線外圈＋套印色內線。驗收：政略／自傳截圖＋全綠＋deny／no-cgo。
- 每一切片：Docker 測試 → Xvfb 1280×720 截圖目檢 → 閘門 → 登記。
  M2 結束後重包 `0.1.5-photo` 並更新 `docs/images/photo-*.png`。

## 4. 明確排除

- 新玩法、命令更名、規則／存檔／命中區改動。
- 正式 Ogg、Android 實機——仍是獨立 gate。
- 原版 oracle／parity 不因換皮重開（SPEC-30 維持）。
