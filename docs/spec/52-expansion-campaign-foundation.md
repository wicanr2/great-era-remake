## 日本名表的勘誤與限制

`MAN215`／`MAN315` 各有 106 個姓名，另有 `JAPAN1.15`／`JAPAN2.15` 各 85 個日本將領姓名。先前把第 107–191 筆稱為「沒有姓名的番號部隊」，證據只涵蓋 MAN 名表與 `FactionName == 0`，不足以排除另一份名表。

日本名表存在及其文字是 `confirmed-data`，已由原有字模還原文件記錄。以 `ID - 106` 對接 85 個日軍記錄屬 **strong inference，尚未確認**；必須核對原版的選表與 ID 位移或取得同狀態畫面，才能成為正式姓名映射。現有映射不在本輪猜補。第 192 筆起仍不在第二、三期有效將領範圍。

新增日本史料先與這兩份既有名表及別名去重。原版文字與史料姓名分開，例如 `JAPAN2.15` 第一槽還原為「鈿俊六」，不能直接改寫成史料姓名「畑俊六」後冒稱原字模原文。抗戰劇本本來已有敵方勢力，開局盤點須保留。

使用者於 2026-10-16 確認日軍可玩原版戰役，抗日擴充供中國勢力遊玩。原型在擴充模式保留日軍選項及限制原因；若由已選日軍的原版切到擴充，不偷偷換玩家，先停用開始操作，讓玩家切回原版或改選勢力。這項規則仍須在正式開局與載入驗證落實。

## 保存方案比較

兩種可撤回原型均未接到正式遊戲。`save_prototype.py` 的 33 項檢查涵蓋原始 bytes、版本、錯配、破損、大小、路徑、入侵識別與亂數 metadata，以及替換失敗。這是容器實驗，不是完整存讀檔或通關驗收。

| 方案 | 玩家檔案 | 實驗結果與取捨 |
|---|---|---|
| DT1 加附檔 | DT1 與 JSON 必須成對 | 雜湊可拒絕錯配。兩個檔案中途只換一個時無法讀取；要保住可用舊快照，另需多世代檔案與原子指標。也不能用它解決尚未解出的新局 DT1 初始化 |
| 單一重製容器 | 建議一個 `.gesave` | 狀態、版本、模式與可選原始 DT1 一次替換。實驗確認替換前失敗保留舊檔；新局可不帶原始 DT1，避免猜造未知 bytes。缺點是擴充容器不能由 DOS 原程式讀取 |

使用者於 2026-10-16 確認採單一 `.gesave` 重製存檔並保留 DT1 匯入。原型含 `manifest.json`、`state.json` 與可選 `legacy.dt1`；正式 DTO、容量與遷移政策尚未定案。原型驗證的是程式錯誤與替換前中斷，沒有宣稱斷電後檔案系統持久性。

## 完整狀態契約草案

美術、介面、音樂及滑鼠偏好繼續由既有偏好檔保存，不決定戰役模式。載入時先在目前遊戲之外建立並驗證完整快照，全部成功後才替換現行狀態。

| 狀態 | 必須保存的內容與限制 |
|---|---|
| 身份與來源 | 格式版本、模式、劇本、玩家領袖、目前省份、來源種類與原始資料雜湊；劇本明示，不憑存檔檔名或內容猜測 |
| 世界 | 省份、將領、勢力、外交、停火、戰爭記錄及原始未知 bytes。匯入的原始 DT1 原樣保留；新局不借附帶存檔的殘留區塊 |
| 回合 | 日期、回合階段、已處理省份、剩餘命令、原版 LCG 的完整 32-bit 狀態。現有 `CommandBudget` 的私有 map 不能直接靠預設 JSON 還原 |
| 戰鬥 | 有效戰鬥、參戰名冊、位置、行動階段、資源、傷亡、撤退與結算是否已套用；不能只帶 DT2／MEM_WAR 就宣稱保住整場執行期戰鬥 |
| 擴充 | 入侵唯一識別、是否觸發、戰役階段、當年名冊、新單位 ID、裝備、補給與有限增援；未知規則在對應規格確認後再定欄位 |
| 失敗 | 缺檔、錯配、毀損、未知版本、錯誤模式與索引一律在替換前拒絕；寫入失敗保留舊進度，不部分套用 |

原版 ID 與 0／0xFF／-1 等既有哨兵維持原意；新增人物採穩定的獨立識別，映射到執行期索引的方式尚待審查。不能把擴充人物塞進第二、三期未使用的第 192–274 筆。

## 進入 READY 的邊界

唯讀可選勢力目錄另由 [SPEC-53](53-scenario-faction-catalog.md)定義，該資料 API 不依賴尚未定稿的完整保存 DTO，也不能直接取代開局與玩家控制權驗收。

原版保存容器、完整 DTO、有效勢力及已採用原型的正式接入由 SPEC-54 審查、實作及驗證。裝甲數值、日軍增援、擴充 schema 與勝負規則分別依 #24–#26 確認，不能由這份草案猜定。未接遊戲的入侵原型不升格為可玩完成。

驗證需從原始資料、typed data、開局身份、合法指令、AI、UI、保存到重啟追完整鏈。新容器另驗未知 bytes、RNG／命令不重置、入侵不重刷、雙戰鬥路徑與失敗保留快照。原版規則回歸、素材拒絕掃描及本輪 Docker 清理照既有契約。
