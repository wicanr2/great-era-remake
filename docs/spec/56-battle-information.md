# SPEC-56：交戰雙方資訊

狀態：CONFORMED，限定雙方唯讀資訊與 Linux 正常玩家路徑。使用者於 2026-10-16 要求戰鬥中同時顯示雙方兵力、裝甲、火砲及將領，原版與 HD 均需詳盡。唯一工作為 [Issue #29](https://github.com/wicanr2/great-era-remake/issues/29)。本規格不改交戰規則、回合、情報限制或存檔版本。

## 資料及證據

| 資料 | 來源與限制 |
|---|---|
| 參戰名冊、即時兵力、兵種、機動力、經驗、格位 | 目前 BattleSim 的 Attacker／Defender 及 Combatant；confirmed-code，顯示實際戰鬥副本，不使用過期將領表的兵力 |
| 將領姓名與帶兵能力、士兵戰技、武裝程度、體力、士氣 | MAN／DT1 的已解欄位；confirmed-data，輸入雜湊及原位址沿用 SPEC-02、SPEC-52 與 docs/playtest/08，不重新解釋未命名 bytes |
| 黃金、糧食、彈藥、燃料 | 現行 battlePanelData 取雙方來源省；confirmed-code。明示為來源省資源，不冒稱 DOS 隨軍攜行量 |
| 裝備型號、配裝、缺裝、火力係數 | 擴充 Armory；approved-remake-design，計算及守恆只引用 SPEC-55 |
| 裝甲厚度、穿甲、車輛數、火砲門數 | 原版尚無充分資料；unknown。不拿 Force、F20 或裝備組冒充實際數量，完整裝甲／穿甲仍依 #25 |

不新增原版 oracle 或精確對拍聲明。原始資料與已發布版本保持不變。這次正常玩家截圖證明重製版呈現路徑，不能當作原版原有此頁。

## 呈現與操作

沿用既有「5 查閱」及滑鼠指令，改為持續顯示的雙方並列詳情。保留既有戰場構圖，詳情以覆層呈現。左為攻方、右為守方，身份不依玩家國籍猜測。兩邊各有總兵力、四種兵種的部隊數及兵力、來源省資源、參戰將領資料。包含零兵力參戰記錄，彙總只計存活者。Force 標為原版兵力尺度，不能將混合兵種的總和稱為精確士兵人頭。

原版 640×350 每邊兩隊一頁，HD 1280×720 每邊三隊一頁。左右鍵、上一頁／下一頁支援共同頁碼；最大頁數由兩方較長名冊決定，短名冊的空頁明示無部隊。ESC、右鍵、返回按鈕只關閉詳情；不退出戰鬥。詳情開啟時 Enter、Space、移動鍵與原戰鬥滑鼠操作均不執行攻擊或換回合。F2／F4 及常駐工具列仍可切美術與介面，切換後重新限制頁碼。

每隊顯示將領、兵種、即時兵力、帶兵能力、戰技、武裝程度、體力、士氣、經驗、機動力與位置。擴充另列實際裝備型號及組數、已配／所需、缺裝、地形下已生效火力係數；原版戰役顯示未追蹤型號。長文字以明確文字矩形、換行及末行省略處理，不由畫布裁切決定。

詳情不儲存獨立戰鬥數字，永遠從現行快照重建。原有 battleModeInspect 可保存並於讀取後恢復；翻頁是短暫 UI 狀態，預設回第一頁。讀取、顯示與翻頁不消耗 RNG、資源或回合。兩方實際兵力及配裝變化於重新開啟時更新。

## 驗收

驗證雙方分類與總和、無裝甲／火砲、不同名冊長度、零兵力、未知兵種、資料缺項、擴充混裝／缺裝及戰損更新。從正常新局開戰，以固定 seed 1 擷取原版與 HD 詳情、翻頁、關閉及保存重啟。另驗證查閱前後戰鬥、世界與 RNG 快照相同。只完成本規格的唯讀呈現，不外推完整抗日入侵或 HOI4 戰鬥公式已完成。

## 實錄及適用限制

[HD 配裝詳情](../images/battle-information-hd-20261016.png)與[原版介面詳情](../images/battle-information-original-20261016.png)均由 seed 1 的正常開局、選勢力及指令開戰擷取。這是新增的重製版頁面，不是 DOS 畫面對拍。HD 範例為北伐劇本的吳佩孚勢力，經研發、產線及配發後開戰；原版介面範例為原版規則的同一開局選項，位於詳情第二頁，兩張不宣稱同一裝備狀態。

本機 `workplace/hoi4-ui-prototype/research-native-20261016/gui-r5/receipt.json` 保存完整輸入及畫面雜湊。正常滑鼠完成查閱、兩種介面翻頁及返回；Enter／Space 不會攻擊或推進回合，退出重啟恢復查閱模式，關閉後仍保有戰鬥與同一 RNG。規則測試另驗雙方不串資料、零兵力、配裝及戰損即時更新，主程式回歸避免舊側欄覆蓋攻方。原版放大顯示沿用既有 `basePointerPosition` 反算命中座標。

未取得新的原版 oracle，不宣稱完整戰鬥忠實度、其他平台真機、入侵或穿甲已完成。尚未提交、推送或發布。
