# SPEC-61：HD 自傳與戰場將領照片

狀態：CONFORMED，限下列本機正常操作與已驗證照片。使用者於 2026-10-17 明確要求人物自傳有照片，HD 戰場的敵方部隊資料也顯示將領照片。[Issue #33](https://github.com/wicanr2/great-era-remake/issues/33)追蹤本輪照片及配樂延長。

## 事實與邊界

現有 Modern desk 的人物頁只傳文字，沒有接回 SPEC-40 的離線肖像。原有人物頁與指揮室已使用 portraitForPerson／portraitForGeneral，但新版入口略過它們。BattleInformationData 也只有文字；HD 戰場的資料卡只顯示目前攻方單位。這些是目前程式可重現的呈現缺口，不需重新逆向原版。

沿用 translations/shared/portraits.json 與現有嚴格載入、canonical 身分、期別對應、圖檔雜湊及來源告知。資料庫沒有可信照片時仍顯示「尚未找到可驗證肖像」，不使用別人照片或虛構人臉。不改人物生平、數值、戰鬥、亂數或存檔格式，已發布版本保留。

## 已授權的局部接線

- Modern 人物詳情與自傳恢復照片欄，使用既有照片框、暖色紙面及鋼鐵配色。照片放正文右側固定欄，正文依剩餘寬度換行及捲動；照片不隨正文消失。名稱、短署名與來源可讀，返回及工具列位置保持既有版面。
- HD 戰場沿用右側部隊資料卡。滑鼠移到敵軍格時，資料卡顯示該敵軍的姓名、兵種、兵力、機動及照片；移開後回到目前指揮單位。只是唯讀預覽，不執行攻擊、選取命令或換回合。
- 「5 查閱」雙方詳情各列實際參戰將領照片，不能用省長或勢力領袖替代。HD 每頁三隊、原版每頁兩隊及既有翻頁／返回契約不變。原版低解析畫面保持原呈現。
- 可補入身分與權利可核對的真實照片，逐筆保存官方來源、原檔及 SHA-256，再更新同一登錄及 notice。小尺寸顯示沿用既有裁切與等比例取樣，不製作大型圖集。

## 驗收

驗證同一人物跨期別對應、有照片與缺照片、敵我照片不串人、捲動及長正文、雙方不等長名冊、照片裁切與文字區不重疊。滑鼠懸停、查閱、翻頁及美術切換前後比較遊戲與 RNG 快照；正常開局走人物、自傳、開戰、敵方資料、保存重開。新素材沿用拒絕掃描及 notice 檢查，原版圖檔與已發布封包雜湊不變。
