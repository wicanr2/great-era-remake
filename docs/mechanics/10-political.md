## 3d. 授權自治 — **confirmed**

指令 8「政策」的第一項（`sub_22E25` 720 行、`sub_23FF6` 兩項選單）。
第二項是「產能分配」，不是其他選項的功能。

省份 `+32` 的 **bit 5（`20h`）** 就是自治旗標，而且是個 **toggle**：

```
若 旗標 & 20h == 20h → 旗標 ^= 20h     （取消自治）
否則                 → 旗標 |= 20h     （設為自治）
```

### 自治的代價：一個月只能下一個指令

`sub_10193`（玩家的指令迴圈）每執行完一個指令就：

```
dec  剩餘指令數
若 省份 +32 & 20h == 20h → 剩餘指令數 = 0
```

**省還是你的，但你管不動它**——下完一個指令就跳到下一個省。

remake 已把每省預算接到政略面板最後一行：標籤直接使用原版 `2.15` 詞條 18
「指令」與 `1.15` 詞條 27「數」，右側數值取 `CommandBudget.Remaining`。
像素測試位於 `internal/ui/render/panel_test.go`。

⛔ **`40-economy.md` §7 曾把這條記成「開發會把指令數歸零，讀作開發佔滿
整個月」，那是錯的**：`sub_22E25` 是授權自治不是開發。全檔只有它設 bit 5，
開發的三支一個都不碰（用 `tools/field_writes.py` 掃過）。

自治**帶來什麼好處**還沒讀——只看到代價。

remake 玩家流程已接通：湖北開局由指令 8 進入，唯一合法目標為河南；
原典／白話兩路徑切換後輸出存檔逐位元組相同，只變更河南 `+32`
的 `0x20` 位元。見 `docs/playtest/23-policy-autonomy.md`。

## 4. 輸入確認的規則 — **confirmed**
