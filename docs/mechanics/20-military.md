## 0. 兵種：四個代號全部定名 — **confirmed**

`MAN(N).DAT` 的 `+21` 是兵種，值域 `{1, 4, 5, 6}`。四個兵種的兵力上限
與社群傳的滿員數**一起對上，零例外**（`docs/spec/02` §6）：

| 代號 | 兵種 | 滿員 | 戰力權重 | 特性 |
|---:|---|---:|---:|---|
| 1 | **步兵** | 20,000 | 1 | 唯一的全地形兵種；森林／高山／丘陵防禦 4–5，也是唯一上得了高山的 |
| 4 | **砲兵** | 2,000 | 10 | **遠程**：有攻擊範圍、不吃反擊、森林不能發動、守方彈藥 < 5000 放棄 |
| 5 | **裝甲兵** | 200 | 100（再 ×2）| 全遊戲只有 1 個（第一期 ID 240、第三期 1 個、第二期沒有）|
| 6 | **騎兵** | 10,000 | 4 | 戰力權重被特意調高一倍（人力正規化權重是 2）|

⚠️ 滿員數**不是硬性上限**——第三期的騎兵有一筆 12,000。三期編制不同。

### 為什麼砲兵是 4

四條獨立線索（`docs/re/09` §3）：攻擊範圍檢查、不吃反擊、森林不能發動、
地形表裡森林的攻擊係數是全表最低。配上滿員 2,000 對上「炮兵旅 2,000」，
以及詞表的「砲兵」「炮擊」「炮轟」。

### 地形適應

完整的兩張表在 `docs/re/08` §6。讀得出來的設計：

- **步兵**是唯一能上高山的，森林與丘陵的防禦都很高
- **砲兵／裝甲兵**在開闊地攻擊 ×2.5，一進森林掉到 ×0.5
- **長城上只有步兵打得出傷害**，其餘三個兵種攻擊係數是 0

## 1. 攻打候選 = 鄰省 − 已控制的省 — **confirmed（兩個獨立樣本）**

規格與驗證見 `docs/spec/01-map-and-terrain.md` §2。

未涵蓋：盟省算不算「已控制」、跨海（臺灣、海南島、緬甸）能不能攻打。
省份資料表的鄰省列表**不列**隔海的那一段（`docs/spec/03` §4），
但那是不是「不可進兵」還沒實測。

## 1b. 攻打規則的完整版（讀自程式碼）— **confirmed**

`sub_5B7DC(省編號)` 就是「找可攻打的鄰省」，回傳第一個符合的省編號（0 = 沒有）：

```
var_4 = 記錄[省].+20              ; 本省的司令
for j = 1 to 8:
    n = 記錄[省].鄰省[j]           ; +22 起的 8 格
    if n == 0:                     continue   ; 填充
    if n == 0xFF:                  continue   ; 海洋／境外
    if 記錄[n].+20 == 0:            continue   ; **無主的省**
    if 記錄[n].+20 == var_4:        continue   ; 同一勢力
    → 回傳 n
```

### 比 SPEC-01 的版本多一條

SPEC-01 §2 從實機推出「攻打候選 = 鄰省 − 已控制的省」，兩個樣本都對。
但程式碼的判準是**司令不同且非無主**——**無主的省不能攻打**。

實機樣本剛好碰不到：湖北與河南的鄰省全部有主。
四川(29) 鄰接甘肅(17) 與青海(30)，兩者在第一期都無主，
解出來的攻打候選是 `[18 26 27 28]`，確實把那兩個排除了
（測試 `TestAttackableSkipsUnowned`）。

⚠️ 這一條**沒有實機交叉驗證**，是純粹讀程式碼得到的。

### [雷] 用的是記錄裡的鄰省表，不是 WARPOS

程式走 `記錄[省].+22`，不是 `WARPOS.DAT` 的幾何鄰接。
兩者有 3 筆差異（隔海的那組，`docs/spec/03` §4）——所以
「福建能不能打臺灣」的答案是**不能**，因為福建的鄰省表裡沒有臺灣。

## 2. 派將可多選 — **confirmed**

選定目標省後進入派將選單，輸入將領編號會在該將領前出現紅色 `*`，
**選單不關閉**，可以繼續選。每頁 20 位，超過會分頁。

河南省 25 位將領時只顯示 20 位，這 20 位的兵力加總 114,500，
而省總兵力 140,500，差額 26,000 正好是沒顯示的 5 位——分頁行為得到驗證。

## 3. 省兵力 = 該省將領的兵力加總 — **confirmed**

不是存檔裡的單一欄位。實機湖北 97,500 零誤差，見 `docs/spec/02-generals.md`。
這也解釋了兵力為什麼會超過 u16 上限。

## 5. 兵種 — **強證據（存在）／假說（數值）**

`2.15` 有步兵(127)、**砲兵(128)**、騎兵(130)，`3.15` 有裝甲兵(46)、游擊隊(45)。
另有「軍種」(75)、「番號」(76)、「整編」(126)。

**砲兵確實存在**——`docs/formats/05` 記過 `NEWICON.TPC` 的 18 張圖示裡
「沒有明顯的炮兵」。詞表證明砲兵是一個兵種，所以圖示裡那對戰車
**很可能就是砲兵**，或砲兵沒有專屬圖示。仍未確認。

「游擊隊」是社群資料沒提到的第五個兵種。

### 滿員數 — **假說**

社群資料說有步兵師、騎兵師、炮兵旅、裝甲部隊，滿員數
20,000 / 10,000 / 2,000 / 200。

- 只有 **20,000 驗證通過**（蔣中正／馮玉祥／吳佩孚三人兵力都正好 20000）
- 其餘三個未驗
- **兵種欄位還沒在將領記錄的 33 bytes 裡找到**

`NEWICON.TPC` 的 18 張圖示（`docs/formats/05`）看得到步兵、騎兵、裝甲與飛機，
**沒有明顯的炮兵**。是炮兵用別的圖、還是「戰車」其實是炮兵，未確認。
