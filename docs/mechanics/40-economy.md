## 1. 六種資源 — **confirmed（欄位）／未知（公式）**

黃金、糧食、彈藥、煤礦、燃料、鐵礦，都是省份記錄裡的 u16。
偏移與驗證見 `docs/spec/03-provinces.md` §2。

### [雷] 資料順序 ≠ 畫面順序

畫面依序印「燃料、煤礦」，資料是「煤礦、燃料」。
UI 照畫面排，解碼照資料讀。

### 消耗與生產的公式 — **未知**

實機在 7 月→8 月之間觀察到湖北的變化：

| 資源 | 7 月 | 8 月 | 差 |
|---|---:|---:|---:|
| 黃金 | 4,200 | 4,150 | −50 |
| 糧食 | 18,050 | 17,950 | −100 |
| 彈藥 | 8,787 | 14,787 | **+6,000** |
| 燃料 | 12,048 | 12,048 | 0 |
| 煤礦 | 13,000 | 7,000 | **−6,000** |
| 鐵礦 | 14,031 | 8,031 | **−6,000** |

彈藥 +6,000 而煤礦、鐵礦各 −6,000——**看起來是兵工廠把煤與鐵轉成彈藥**，
比例 1:1:1。但這只有一個月份的一個省，**是假說不是結論**。
黃金 −50、糧食 −100 是每月固定支出還是依兵力算，未知。

河南的存檔（7 月）與實機（8 月）也顯示黃金 −50、糧食 −100，**與湖北相同**——
兩個省相同的話「固定支出」比「依兵力」更可能，但兩個樣本仍不夠。

下一步：多跑幾個月，或反追月結算的程式碼。

## 2. 人口 — **confirmed**

省份記錄 `+12` 的 u32，單位是人；畫面顯示除以 10,000 的「萬」。
湖北 18,250,000 → 畫面「1825 萬」。

數值符合民國初年的實際人口分佈（四川 3,639.8 萬最多、河南 2,794 萬、
山東 2,715 萬、河北 2,410 萬）。

人口會不會成長、影響什麼——**未知**。

猜測與徵稅收入有關，**未驗**。

## 5. 勢力覆滅時資源被清空 — **confirmed（程式碼）／假說（語意）**

`sub_3964E` 會篩出所有司令等於某個 ID 的省，把**黃金與糧食重設為
`Random(10)`**（0–9，等於清空）。詳見 `70-ai.md` §5。

這是目前唯一一條讀到程式碼的資源變動規則。

## 5b. 資源上限是 60000 — **confirmed**

`sub_5A467(上限, 加數, 目標)` 是全遊戲通用的「累加並夾上限」，
被 **56 處**呼叫，每次都傳 `0xEA60 = 60000`：

```
v = *目標 + 加數        ; 32-bit 運算，不會中途溢位
if v > 上限: v = 上限
*目標 = v
```

資源欄位本身是 u16（能裝到 65535），但實際上限是 60000。
五個資料檔的所有資源值都在其下，最大的是彈藥 **53,692**——逼近但未超過。

### [雷] 中間運算是 32-bit

直接用 u16 相加會先溢位再夾，結果完全不同：
`50000 + 20000` 在 u16 是 4464，夾完還是 4464，但原版給 60000。

## 5c. 戰後的省份資源結算 — **confirmed**

`sub_546D1`（九步結算的第三步）：

```
ptr = 省份記錄
ptr[+0] = 0    ; 黃金
ptr[+2] = 0    ; 糧食
ptr[+4] = 0    ; 彈藥
ptr[+8] = 0    ; 燃料
sub_5A467(ptr+0, 攻方黃金 + 守方黃金, 60000)
sub_5A467(ptr+2, 攻方糧食 + 守方糧食, 60000)
sub_5A467(ptr+4, 攻方彈藥 + 守方彈藥, 60000)
sub_5A467(ptr+8, 攻方燃料 + 守方燃料, 60000)
```

也就是**戰後省份的四種資源 = 雙方各自帶的量相加，夾到 60000**。

### 煤礦與鐵礦不參與

原版只歸零了 `+0`／`+2`／`+4`／`+8`，**沒有碰 `+6`（煤礦）與 `+10`（鐵礦）**。
那兩者是省份的礦藏，不隨部隊移動，戰後維持原值。設計上完全說得通。

### 這解掉了 RE-05 的一個觀察

`docs/re/05` §2 記過「四個 u16 的目標位址間隔 4」而不知為何。
現在清楚了：**每個欄位是一對**（`word_64932`／`word_64934` 是攻守雙方的
黃金），所以間隔是 4 不是 2。

## 6. 「產能」是一組可分配的量 — **強證據**

`4.15` 有「**產能分配**」(27)、「鐵礦產能」(28)、「煤礦產能」(29)、
「石油產能」(30)、「糧食產能」(33)、「**礦藏指數**」(31)。

所以資源不是固定產出，而是**玩家分配產能**的結果。
§1 記的「彈藥 +6,000、煤鐵各 −6,000」很可能就是產能分配造成的，
不是每月固定公式——**那條假說要重新檢視**。

### 兩個待釐清的點

1. **「石油」與「燃料」是兩個不同的詞**（`2.15` 139 石油、26 燃料）。
   省份記錄的資源欄位對應「燃料」，而產能用的是「石油」。
   可能石油是產出、燃料是庫存，未確認。
2. **「礦藏指數」**暗示每省有礦藏上限或品質參數，
   但省份記錄的 37 bytes 裡沒找到對應欄位。
