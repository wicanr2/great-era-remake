### 借貸是一整個循環

貸款 → 產生外債 → 償還外債 → 影響信用度 → 影響下次能不能貸。
「各國均拒絕提供貸款」是一條真實的失敗分支，代表**信用度會擋住貸款**。

外援給的是**黃金、糧食、彈藥、燃料**四種——與運補能搬的四種完全相同
（`docs/re/27`），煤礦鐵礦都不在內。

### ✅ 貸款的核貸公式 — **confirmed**

`sub_2164A`（726 行）的判定只有兩行：

```
units = 貸款額 ÷ 500          ; mov cx, 1F4h + @$brdiv
roll  = Random(10)
若 roll + units > 12 → 各國均拒絕提供貸款
否則  信用度 −= units、省份黃金 += 貸款額
```

**借越多越容易被拒**，而且門檻算得出來：

| 額度 | units | 結果 |
|---:|---:|---|
| ≤ 1,999 | ≤ 3 | **必過**（骰最大 9，9+3=12 不超過）|
| 2,000–6,499 | 4–12 | 機率，額度越大越低 |
| 6,000 | 12 | 只有骰到 0 才過（≈10%）|
| ≥ 6,500 | ≥ 13 | **必被拒** |

所以單次貸款的硬上限是 **6,499**。

### ✅ 「信用度」找到位址了

```
sub  [di-4225h], dl      ; dl = 額度 ÷ 500
```

`-4225h` 當 16-bit 是 **`0xBDDB`**——信用度是那裡起的一張 byte 表。
索引來自 `ss:[di-6]`，⚠️ **那個索引是什麼還沒解**
（形狀像列強編號 0–3，沒有證據）。

貸款會**扣**信用度（每 500 黃金扣 1），怎麼回補未知。

### ✅ 償還外債與貸款完全對稱 — **confirmed**

```
額度 ÷ 500 → dl
信用度 += dl
若 信用度 > 100 → 100        ; cmp byte ptr [di-4225h], 64h
```

兩邊用同一個 500 為單位，**借多少還多少就回到原點**。
信用度上限 **100**。

⚠️ **「外債」餘額本身仍未找到位址**——省份記錄裡沒有，是全域狀態。
`sub_223ED` 有「付錢 + 加信用度」，但**扣減外債餘額那一步還沒讀到**。
`internal/game/diplomacy.go` 已標明這個缺口。

### ✅ 外援 — **confirmed（判定）／假說（援助國對應）**

```
Random(10) ≤ 6 → 同意           ; 70%
四種資源各 += Random(基準) ÷ 除數
黃金夾 6000（1770h），其他三種不夾
```

**援助國決定慷慨程度**，除數越小給越多：

| 代碼 | 除數 | 推測 |
|---:|---:|---|
| 99、142 | **1** | 美國？最慷慨 |
| 100 | 3 | 英國？ |
| 其他（101、141…）| 5 | |

那些代碼對得上 `2.15` 的詞條位置（1-based 99／100／101 = 美國／英國／俄國），
而且「美國最慷慨」與 `sub_37A81`「美國援助軍事物資中」的事件呼應——
但**沒有直接證據**，而且 141／142 對不上法國的詞條編號，所以標假說。

非第一期一律變成代碼 99。

#### ⭐ 史實特例：張作霖在民國 17 年 2–6 月拿不到援助

```
省份司令 == 166（張作霖）且 年 == 17 且 月 ∈ [2, 6]  → 一律拒絕
```

民國 17 年 = 1928，北伐軍進逼、列強不再支持奉系，**皇姑屯事件就在那年 6 月**
（同一年的東北易幟見 `docs/re/25` §5）。這是**寫死的劇本**不是通用規則，
是目前找到的第二條史實硬編碼。

⚠️ 四種資源的亂數基準（`var_4`／`var_8`／`var_C`／`var_10`）怎麼來的
**還沒讀**（在函式 200–360 行之間），remake 由呼叫端傳入。

## 1z. ✅ 談判停火的同意判定 — **confirmed**

`sub_211D5` → `sub_20CF0`（148 行）。**這是目前解出來最有設計感的一段 AI 判斷**：

```
roll = Random(10)

; 掃全部將領，用攻擊力公式 sub_5A0B9 分別累加攻守雙方
for 每個將領 g:
    若 g.+4 == 目標省 且 g.+16 bit 2 == 1（已部署）:
        g.+8 == 0 → 守方戰力 += 攻擊力(g)
        否則      → 攻方戰力 += 攻擊力(g)

佔上風 = (請求方是守方 且 守方 ≥ 攻方) 或 (請求方是攻方 且 攻方 ≥ 守方)

佔上風 → roll ≥ 3 才同意    70%
劣勢   → roll ≥ 8 才同意    20%
```

**你強對方才肯停火。** 弱勢方求和只有 1/5 機會。

⭐ 這是「AI 的評估函式就是攻擊力公式」的**第二個獨立例子**
（第一個是調動，`70-ai.md` §6e）。要改 AI 的強弱判斷，改 `sub_5A0B9` 就好。

### 兩張新表的位址

| 表 | 位址 | 形狀 | 已知 |
|---|---|---|---|
| 戰爭記錄 | `ds:B346h` | **60 B/筆**，省編號索引 | `+0`／`+2` 是交戰的兩個勢力 |
| 停火狀態 | `ds:BCA5h` | 每省 1 byte | 值 > 0 = 停火中，同意時 `inc` |

39 省 × 60 = 2,340 B，`B346 + 2340 = BC6A`，正好落在停火表之前——
**兩張表相鄰，佈局自洽**。

⚠️ 停火表是**遞增**而不是設成固定值，形狀像「剩餘停火月數」，但沒有證據。
`internal/game/ceasefire.go` 只回報「談成了沒」，**不改狀態**。

## 2. 秘密行動的兩個子項 — **confirmed（存在）／未知（機率）**

| 項目 | 函式 | 成功／失敗 |
|---|---|---|

| 鼓動學潮 | `sub_20447` | 「發生學潮」／「沒有學潮發生」|

兩者的前置檢查相同：**資金不足**擋一次、**目標省正在戰爭**擋一次。
派遣還會先問「司令派遣要花〈某數〉，確定？」——**要花錢，成本未讀**。

有成功與失敗兩條分支，代表中間有一次亂數判定。
`Random` 呼叫點的盤查（`70-ai.md`）應該優先看這兩支。

## 3. 可外交的列強是四個 — **強證據**

`2.15` 有美國(98)、英國(99)、俄國(100)、法國(145)四個專屬詞條，
另有日本(141)、中國(142)。

日本在這個遊戲裡是敵對勢力不是外交對象（`sub_36494`「日軍海外部隊正逼近」、
`sub_35B19` 的「中國／日軍」對立），所以能談的是那四個。

`sub_37A81`「美國援助軍事物資中」是**事件**不是玩家指令——
美援會自己發生，與 `sub_21D1D` 主動請求外援是兩件事。
