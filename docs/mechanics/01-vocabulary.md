# 機制詞彙表：從原版 UI 詞表反推的機制地圖

來源：`2.15`（231 條二字）、`3.15` 的 39–56（18 條三字，前 39 條是省名）、
`4.15`（51 條四字），全部由 `docs/formats/01-glyph-text.md` 的字模反查還原。

**這些是原版自己的用詞，不是我們取的名字。** 一個詞出現在畫面詞表裡，
代表遊戲裡真的有那個東西——這是機制存在性的**硬證據**，
雖然不告訴我們它怎麼運作。

推論等級的定義見 `00-index.md`。

> **2026-08-01：這份文件的方法已被升級版取代。**
>
> 當初只有「詞表」——知道遊戲裡有「產能」這個詞，但不知道它出現在哪個畫面。
> `docs/re/24` 解出繪字函式家族後，`tools/glyph_calls.py` 可以把
> `WAR.EXE` 裡 **924 個畫字呼叫點**直接還原成中文，**連帶知道它在哪個函式、
> 與哪些詞排在同一行**。
>
> 也就是說：從「這個詞存在」升級成「這一句話長這樣，是這個函式印的」。
> 本文件的推論仍然成立（詞表沒有變），但**新的機制推斷應該優先用呼叫點**，
> 例如 `docs/re/26` 就是靠它一次定出指令 8 的整個畫面。

## 1. 地形：直接對上 NWMAP 的地物編號 — **confirmed**

`2.15` 的 194 是「地形」，195–205 依序是：

| 詞條 | 詞 | NWMAP 編號 |
|---:|---|---:|
| 195 | 平原 | 1 |
| 196 | 丘陵 | 2 |
| 197 | 河海 | 3 |
| 198 | 森林 | 4 |
| 199 | 城市 | 5 |
| 200 | 高山 | 6 |
| 201 | 沙漠 | 7 |
| 202 | 橋樑 | 8 |
| 203 | **橋樑**（重複）| 9 |
| 204 | 高原 | 10 |
| 205 | 關口 | 11 |

順序一一對應，**連橋樑重複兩次（縱、橫）都對上**。

這把 `docs/spec/04` 的地物名稱從「圖塊視覺判讀」升級為 confirmed，
並糾正了一個錯誤：編號 10 我原本看圖判成「岩地／荒地」，**正確是「高原」**。

編號 12–22 沒有對應詞條，視覺上是長城各段；`2.15` 詞條 120 有「長城」，
但沒有逐段名稱。

`4.15` 的 50「所在地形」印證了戰鬥中會顯示格子的地形。

## 2. 戰鬥 — **強證據（存在）／未知（規則）**

| 來源 | 詞 |
|---|---|
| `2.15` | 攻方、守方、移動、撤退、駐軍、炮擊、炮轟、行軍、崩潰、穿越、強渡、攻克、逼近、阻隔、敗逃、衝鋒、增援、損失、陣亡、遭到、襲擊、打敗、戰報、觀戰、方向、停火、介入、戰事 |
| `3.15` | **肉搏戰**、**機動力**、**攻擊力**、單位數、士兵數、游擊隊、裝甲兵 |
| `4.15` | 進入戰場、**協同攻擊**、**正規攻擊**、大軍集結、我軍駐守、被俘虜了、地方可退 |

### 這批詞證實了幾件事

- **機動力確實存在**（`3.15` 51）——`CLAUDE.md` §1.5 記為社群資料，
  現在有原版詞表佐證。怎麼算仍未知。
- **攻擊分兩種**：「協同攻擊」與「正規攻擊」（`4.15` 40、41）。
  這是社群資料完全沒提到的機制。
- **肉搏戰**是獨立的一個詞，可能是近戰結算階段。
- 「強渡」「穿越」「阻隔」對應地形的通行規則——**河海要強渡、某些地形會阻隔**。
- 「地方可退」暗示撤退需要有可退的格子。
- 「單位數」與「士兵數」是兩個不同的量——呼應戰鬥狀態記錄裡
  10 個槽 vs 200 B 單位區的雙層結構（`docs/re/05`）。

## 3. 兵種與部隊屬性 — **強證據**

| 來源 | 詞 |
|---|---|
| 兵種 | 步兵、砲兵、騎兵、裝甲兵、游擊隊、軍種 |
| 屬性 | 能力、經驗、體力、士氣、戰力、戰技、武裝、程度、帶兵 |
| 編制 | 部隊、軍團、番號、整編、重新整編、整編兵力、改編為 |

**`2.15` 的 128 是「砲兵」**——`docs/formats/05` 記過 `NEWICON.TPC` 的 18 張
圖示裡「沒有明顯的炮兵」。詞表證明砲兵存在，所以圖示裡那對戰車
**很可能就是砲兵**，或砲兵沒有專屬圖示。仍未確認。

「游擊隊」與「裝甲兵」在 `3.15`（三字）而非 `2.15`，是完整兵種名。

將領記錄 33 bytes 只解出三個能力值（`docs/spec/02`）。詞表裡的
**能力、經驗、體力、士氣、戰技、武裝**至少六個屬性，
表示未解的 28 bytes 裡裝著這些。

## 4. 經濟 — **強證據**

| 來源 | 詞 |
|---|---|
| 資源 | 黃金、糧食、彈藥、煤礦、燃料、鐵礦、石油、物資 |
| 產能 | 產能、產能分配、鐵礦產能、煤礦產能、石油產能、糧食產能、**礦藏指數** |
| 動作 | 墾地、挖礦、挖金礦、開發、徵稅、已徵過稅、進行掠奪 |
| 貿易 | 購買、拋售、進口、出口、欲買、欲賣、購買軍需、拋售軍需 |
| 財政 | 資金、欠糧、欠餉、負債、貸款、外債、償還、信用度、等級 |

### 兩件事

1. **「產能」是一組可分配的量**（`4.15` 27「產能分配」+ 四種產能）。
   `40-economy.md` 記的「彈藥 +6000、煤鐵各 −6000」很可能就是產能分配的結果，
   不是固定公式。
2. **「石油」與「燃料」是兩個不同的詞**。省份記錄裡的資源欄位是「燃料」，
   而「石油產能」用的是石油——可能石油是產出、燃料是庫存，未確認。
3. 「礦藏指數」暗示每省有礦藏上限或品質參數，**省份記錄 37 bytes 裡沒找到**。

## 5. 外交 — **強證據**

| 詞 |
|---|
| 外交、談判、停火、秘密、外國貸款、請求外援、援助、拒絕、提供、同意 |
| **美國、英國、俄國、法國、日本、中國** |
| 信用度、等級、外債、償還、政治手腕 |

**四個外國列強有專屬詞條**：美國、英國、俄國、法國。
外交不只是勢力之間，還包括向列強借款與求援。

「信用度」與「等級」很可能是借款的門檻參數。

## 6. 政略 — **強證據**

`2.15` 的 0–19 就是指令選單的組件：

```
調動 軍事 運補 徵稅 徵兵 查閱 開發 政策 外交 談判
秘密 商業 練兵 休息 特殊 其他 | 行動 活動 指令 選項
```

前 16 個是指令名，16–19（行動、活動、指令、選項）是組合用的後綴——
畫面上的「調動行動」「商業活動」「秘密行動」「其他選項」就是這樣拼出來的。
`docs/playtest/02` §5 的實機選單完全對得上。

其他政略詞：內政、調整、砲口、長城、授權、任務、圓滿、達成、
鼓動學潮、慰勞軍民、政治手腕、立即出兵、攻打南方、指令圖畫、訊息時間。

**「攻打南方」（`4.15` 21）是個具體指令**，不是泛稱——暗示有方向性的戰略指令。

## 7. 人事 — **強證據**

| 詞 |
|---|
| 將領、司令、省長、任用、指派、派遣、留守、繼任、無人 |
| 投靠、欠餉、太高、槍斃、處置、陣亡、被俘虜了 |
| 忠誠度、信用度、經驗、能力、帶兵 |

- **「投靠」**：將領會倒戈。
- **「欠餉」＋「太高」**：欠餉過高會出事，很可能就是投靠的觸發條件。
- **「槍斃」「處置」**：抓到俘虜或叛將可以處置。
- 「繼任」「無人」：司令陣亡後有繼任機制，無人可繼任時如何未知。

## 10. 這份文件怎麼用

**詞彙證明機制存在，不證明機制怎麼運作。** 每一條要往上升到
confirmed，都要在執行檔或實機找到對應。

已經因此升級的：地形名稱（§1）。
最有價值的新線索：協同攻擊 vs 正規攻擊、產能分配、欠餉→投靠、四個列強。
