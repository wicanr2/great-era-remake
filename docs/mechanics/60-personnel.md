# 機制：人事

推論等級的定義見 `00-index.md`。

---

## 1. 將領記錄 33 bytes — **confirmed（結構）／未知（多數欄位）**

規格見 `docs/spec/02-generals.md`。33 bytes 裡只解出四個欄位：

| 偏移 | 欄位 |
|---:|---|
| +0 / +1 / +2 | 三個 0–100 的能力值 |
| +17 | 兵力 u16 |

**其餘 28 bytes 未解**，包含兵種欄位（如果有的話）。

### 三個能力值分別是什麼 — **未知**

不知道哪個是統率、武力、政治或忠誠。蔣中正三項全 100 可當 sanity check，
但那不足以區分。**刻意不做語意化命名**，免得寫進程式碼之後就沒人再質疑。

## 2. 將領 ID 是 1-based — **confirmed**

指向 `MAN{期}15` 的名表。第一期 `MAN115` 有 274 人，二三期各 106 人。

驗證：省份記錄的司令欄位解出來就是 1926 年的割據圖
（`docs/spec/03` §3），十個勢力全部命中。

## 3. 司令與省長是兩個不同的欄位 — **confirmed**

- **司令**（記錄 `+20`）是勢力領袖
- **省長**（記錄 `+30`）是實際駐守該省的將領

初始檔（`TOWN(N).DAT`）兩者相同，存檔裡才分化。`SAVE(1).DT1` 解出
遼寧省長張學良、山東省長張宗昌、江西省長盧香亭——全部符合史實職務。

## 4. 人民忠誠度 — **confirmed（欄位）／未知（機制）**

省份記錄 `+19`，0–100，實機湖北 79。

初始值域 40–79，看得出設計意圖（軍閥直轄地忠誠度高、邊陲低）。
**怎麼變動、影響什麼，未知。** 指令 14「慰勞軍民」是最可能的影響來源，未驗。

## 5. 欠餉會讓將領投靠別人 — **強證據**

`2.15` 有這一組詞：**欠餉**(72)、**太高**(73)、**投靠**(156)。
另有任用(162)、指派(132)、留守(89)、繼任(223)、無人(224)、
**槍斃**(179)、處置(178)、被俘虜了(`4.15` 43)。

合起來讀：**欠餉太高 → 將領投靠別人**。這是社群資料沒提到的機制。
「槍斃／處置」則是抓到俘虜或叛將之後的選項。

「繼任」「無人」表示司令陣亡後有繼任機制，無人可繼任時如何未知。

**公式與門檻全未知。**

## 6. 將領屬性至少有六個 — **強證據**

詞表裡的將領相關屬性：**能力**(71)、**經驗**(74)、**體力**(80)、
**士氣**(81)、**戰力**(54)、**戰技**(161)、**武裝**(78)、帶兵(70)。

將領記錄 33 bytes 只解出三個能力值（`docs/spec/02`），
但詞表列出至少六到八個屬性——**未解的 28 bytes 裡裝著這些**。

這也說明為什麼不該把 `+0/+1/+2` 貿然命名為「統率／武力／政治」：
候選遠不只三個。

## 7. 將領忠誠度 — **未知**

社群資料提到將領忠誠度，但將領記錄的三個能力值裡是不是有一個是忠誠，
**沒有證據**。也可能在未解的 28 bytes 裡。
