# 機制：人事

推論等級的定義見 `00-index.md`。

---

## 1. 將領記錄 33 bytes — **confirmed（結構）／未知（多數欄位）**

規格見 `docs/spec/02-generals.md`。33 bytes 裡只解出四個欄位：

| 偏移 | 欄位 |
|---:|---|
| +0 / +1 / +2 | 三個 0–100 的能力值 |
| +17 | 兵力 u16 |

**其餘 28 bytes 未解**，包含兵種欄位（如果有的話）。

### 三個能力值分別是什麼 — **未知**

不知道哪個是統率、武力、政治或忠誠。蔣中正三項全 100 可當 sanity check，
但那不足以區分。**刻意不做語意化命名**，免得寫進程式碼之後就沒人再質疑。

## 1b. 將領屬於哪個省：記錄的 `+4` — **confirmed**

`MAN(N).DAT` 的 `+4` 是所屬省編號（1-based），0 = 無所屬。
第一期 274 位裡有 64 位無所屬。

驗證見 `docs/spec/02` 附錄：十大勢力領袖的所屬省全部落在自己轄區內（10/10），
且湖北 15 位／97,500、河南 25 位／140,500 都對上實機，零誤差。

**政略畫面的「兵力」與「將領數」就是從這裡算出來的**——兵力是該省將領的
兵力加總，不是存檔裡的單一欄位，所以會超過 u16。

## 2. 將領 ID 是 1-based — **confirmed**

指向 `MAN{期}15` 的名表。第一期 `MAN115` 有 274 人，二三期各 106 人。

驗證：省份記錄的司令欄位解出來就是 1926 年的割據圖
（`docs/spec/03` §3），十個勢力全部命中。

## 3. 司令與省長是兩個不同的欄位 — **confirmed**

- **司令**（記錄 `+20`）是勢力領袖
- **省長**（記錄 `+30`）是實際駐守該省的將領

初始檔（`TOWN(N).DAT`）兩者相同，存檔裡才分化。`SAVE(1).DT1` 解出
遼寧省長張學良、山東省長張宗昌、江西省長盧香亭——全部符合史實職務。

## 4. 人民忠誠度 — **confirmed（欄位）／未知（機制）**

省份記錄 `+19`，0–100，實機湖北 79。

初始值域 40–79，看得出設計意圖（軍閥直轄地忠誠度高、邊陲低）。
**怎麼變動、影響什麼，未知。** 指令 14「慰勞軍民」是最可能的影響來源，未驗。

## 5. 欠餉會讓將領投靠別人 — **強證據**

`2.15` 有這一組詞：**欠餉**(72)、**太高**(73)、**投靠**(156)。
另有任用(162)、指派(132)、留守(89)、繼任(223)、無人(224)、
**槍斃**(179)、處置(178)、被俘虜了(`4.15` 43)。

合起來讀：**欠餉太高 → 將領投靠別人**。這是社群資料沒提到的機制。
「槍斃／處置」則是抓到俘虜或叛將之後的選項。

「繼任」「無人」表示司令陣亡後有繼任機制，無人可繼任時如何未知。

**公式與門檻全未知。**

## 6. 將領屬性：查閱畫面列出十一項 — **強證據**

> 2026-08-01 升級：不再只是「詞表裡有這些詞」，而是
> **「查閱將領」那一頁實際印出來的清單**（`sub_2B344`，`docs/re/27`）。

畫面依序印：

> 將領狀態／**帶兵能力**／**忠誠度**／**經驗**／**軍種**／**番號**／
> **士兵數**／**士兵攻擊力**／**武裝程度**／**士兵戰技**／**體力**／**士氣**

已定名的三格（`docs/playtest/08` 逐格對照）：

| 偏移 | 名字 |
|---|---|
| `+0` | 帶兵能力 |
| `+1` | 忠誠度 |
| `+2` | 政治手腕 |

⚠️ **「政治手腕」不在上面那份清單裡**——查閱畫面沒印它。
兩份清單是不同的東西：查閱畫面是「玩家看得到的」，`+2` 是「程式用得到的」。
不要因為清單裡沒有就懷疑 `+2` 的定名（那是實機畫面直接讀到的）。

### 四個未定名欄位的候選

`docs/spec/02` 有四格標「戰力公式用得到但不知道叫什麼」
（`F19`／`F20`／`F29`／`F30`）。候選名字就在清單裡：
**經驗、士兵攻擊力、武裝程度、士兵戰技**。

⚠️ **還不能對號入座**——這是名字的**集合**，不是**順序**。
畫面排列未必等於記錄偏移順序。要對上得把 `sub_2B344` 的每個數值呼叫
與其座標逐一對齊，這是 `docs/re/26` §3 同型的坑（`+2` 曾被誤名為「開發能力」）。

### 已知會動這些欄位的指令

| 指令 | 函式 | 改什麼 |
|---|---|---|
| 練兵 | `sub_1C916` | **士兵戰技**提升 |
| 休息 | `sub_1C606` | 士兵**士氣**提升、人民忠誠度提升 |
| 慰勞軍民 | `sub_3412B` | 體力 +10、士氣 +能力÷5（上限 80）、忠誠 +20 |
| 提升武裝 | `sub_1F380` | **武裝程度**，要花錢 |
| 欠餉／欠糧 | `sub_37EAE` | 欠餉 → 士氣降低；欠糧 → 體力降低 |
| 歷史檢查沒過 | `sub_30003` | **帶兵能力減半**（`docs/re/25` §6）|

## 7. 將領忠誠度 — **未知**

社群資料提到將領忠誠度，但將領記錄的三個能力值裡是不是有一個是忠誠，
**沒有證據**。也可能在未解的 28 bytes 裡。
