## ⭐ 純成文壓力測試：只看骨架，夠不夠用？

這是規格 §2 的骨架 schema 第一次在**真正的隔離條件**下被使用——骨架是前一輪建的，
成文在另一個 session 進行，全程沒有開過任何來源網頁。以下是實測結果。

### 夠用的部分

**`posts` 與 `events` 兩個陣列直接對應 S3 與 S4 兩種句型，幾乎是一對一的。**
七篇的 S3 全部是把 `posts[].from` ＋ `posts[].title` 串起來，中間只需要決定
「同年」「其後」這種連接詞；S4 則是 `when` ＋ `where` ＋ `role` ＋ `outcome` 四欄按
§4.1 的順序排開。`life` 與 `ending` 對 S1／S5 同理。**這四個欄位群佔了正文九成以上的字。**

⭐ 更值得記的是一個反向的觀察：**欄位化本身就在擋評價**。
`outcome` 這個欄名逼人寫「結果是什麼」，寫不進去的東西（動機、褒貶、因果推論）
在建骨架那一步就掉了。§21.2 說「不寫評價最難的不是用詞是材料的結構」——
schema 正是在改變材料的結構。

### 不足以支撐一個句子的欄位

| 情形 | 本批的例 | 症狀 |
|---|---|---|
| **`posts[].from` 為 `null`** | #126 `posts[6]` 贛南鎮守使 | S3 是以年份為軸的句型，沒有年份就插不進去。只能寫「另任」，而任何更自然的連接詞（「其後」「隨即」）**都是我在補來源沒說的時序** |
| **`events[].outcome` 為 `null`** | #34 `events[4]` 閩變、#41 `events[6]` 蘭封會戰 | S4 少了結果就只剩「他在那裡」，是空句。兩筆都只能不寫——**而「不寫」在骨架裡看不出來** |
| **`education[].year` 為 `null`** | #34 三筆全 `null`、#126 一筆 | S2 的「<年份>年入…」失去主詞，只能寫「早年入…」。「早年」是我加的，骨架沒有這個詞 |
| **`ending.where` 為 `null`** | #126 | S5「於<地點>」整段消失，只剩「1962年病故」四個字 |

共同形狀：**`null` 在 schema 裡表示「查無」，但在成文階段它表示「這個句型用不了」。**
兩者不是同一件事，而模板（§4.1）沒有給替代句型。

### 多餘的欄位（成文一個字都沒用到）

`identity.disambiguation`、`conflicts`、`gaps`、`supersedes`、`verified_by`、`coverage`、
以及所有欄位級的 `src` 與 `conf`——**正文一個字都不是從它們長出來的**。

但它們不是浪費：**每一項都用在正文之外**。上面每一篇的「衝突處理」「為什麼是 `high`」
「gpost 三個數」「最大缺口」四段，材料全部來自這幾個欄位。
換句話說，schema 事實上分成兩半——**一半餵正文，一半餵交件說明**，而規格 §2 沒有這樣分。

### ⚠ 最值得回報的一件事：`note` 是隔離的破口

`note` 欄位裡混著三種完全不同性質的東西：

1. **只能放在 `note` 的事實**（`posts[].note`「南征回軍後升任」「1916 年 3 月升營長」
   ——這些是 schema 沒有欄位可放的升遷，但它們是**事實**）
2. **裁決紀錄**（「依 §10.4 採 Tier A」「⚠ 見 conflicts[0]」）
3. ⛔ **來源的原話片段**（`conflicts[].statements[].says` 是規格明訂的例外，
   但 `note` 裡也常出現轉述句，甚至整句照抄）

第 1 種**必須看**（不看會漏事實），第 3 種**不該看**（那是原文的表達）。
兩者在同一個欄位裡，成文階段沒有辦法只看前者。

> **§0 說「骨架是欄位，欄位沒有表達」——`note` 是自由文字，這句話對它不成立。**

本批的處置是：`note` 只取其中的事實，敘述一律重寫；但這是靠自律，不是靠機制，
與規格 §0 「不靠自律靠流程」的設計意圖相反。
