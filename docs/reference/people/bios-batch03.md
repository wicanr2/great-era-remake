謝鴻勳（生年不詳—1926年），籍貫不詳。1914年授陸軍步兵上尉，1921年11月任陸軍第二師步兵第八團團長，1922年授陸軍步兵上校，1923年授陸軍少將，1924年晉授陸軍中將。江浙戰爭中陸軍第四師為孫傳芳收編，出身陸軍第二師系統的謝鴻勳受命指揮該師，原師長陳樂山出走日本；同年10月陳樂山回國重掌該師，其後孫傳芳第二次收編第四師，謝鴻勳再度接掌指揮權。1925年，於安徽固鎮一役俘直魯聯軍將領施從濱。1926年9月，第四師在江西與國民革命軍連續作戰，先後有修水、銅鼓、高安、南昌諸役；9月26日至30日箬溪一役，該師為國民革命軍第七軍擊潰，被俘官兵二千餘人，餘部為國民革命軍收編。於箬溪一役負傷，赴上海醫治不治。

- **字數／格數**：310 字，**288.5 格**
- **查證來源**：中華民國政府官職資料庫（Tier A，6 筆）、中文維基百科〈陆军第四镇〉〈箬溪戰鬥〉〈修水戰鬥〉〈銅鼓戰鬥 (北洋政府時期)〉〈高安戰鬥〉〈第四次南昌戰鬥 (北洋政府時期)〉〈国民革命军第七军〉〈施從濱〉〈固鎮戰鬥〉（Tier B）
- **回查**：S1 → `life.death` + `life.birth`／`life.birthplace`（皆 `unknown`）；S3 各項 → `posts[0..7]`；S4 各段 → `events[0]`、`events[1..4]` 併寫、`events[5]`；S5 → `ending`。
- **為什麼是 `high`**：identity 接合是本批**最硬**的一筆——gpost 1921-11-12「任命謝鴻勳陸軍第二師步兵第八團團長」，而維基〈陆军第四镇〉在說明第四師指揮權易手時，把他稱為「**陸軍第二師系統的**謝鴻勳」。兩個來源在**同一個師的番號**上對上，不是靠同名與同時期推的。任職序列 Tier A + Tier B 雙來源，無影響主軸的未解 conflict。
- **⚠ 姓名兩種寫法**：遊戲寫「謝鴻勳」（與 gpost 一致），維基各戰鬥條目 infobox 多作「謝鴻勛」、正文與〈陆军第四镇〉用「勳」。**兩種都要查**——只查「謝鴻勳」會漏掉六個戰鬥條目（同 G-N11）。
- **原來源複核結果**：✅ **升級並補一項關鍵漏失**。原 `bio_zh` 說 1926 年 9 月「在江西省與國民革命軍第一軍、第六軍交戰…全師遭殲滅」，**漏掉了真正殲滅該師的第七軍**（箬溪一役）。原記「負傷後送，終因傷重不治」本輪獲得佐證，維持。
- **衝突處理**：
  - **師的省別冠稱**：多數條目作「蘇四師」，〈国民革命军第七军〉作「浙江陸軍第四師」（同一來源內部）→ 正文只寫「陸軍第四師」。⚠ 這個師本來就是清末陸軍第四鎮的後身，在皖系、直系、孫傳芳之間數度易手，省別冠稱隨隸屬而變，**兩說可能都對過**。
  - **固鎮一役的時序**：〈固鎮戰鬥〉記 1925 年 11 月 2 日，〈施從濱〉記 1925 年 10 月孫傳芳已將施從濱處死——被俘晚於被處死，時序不成立 → 正文只寫「1925 年」。
- **未寫入正文**：施從濱其後被處死的經過。那是另一個人的結局，依 §4.7 第 5 級砍掉，只保留「俘施從濱」這個與本人直接相關的事實。

## 一批 10 篇的成本結構（本批實測）

- **查證約 75%**：每人 1–2 次 gpost（異體字要各查一次）+ 3–10 個維基條目全文。
  比 batch-01 的 70% 略高，多出來的部分全部花在**同名分群**（本批 4 人有混入，batch-01 只有 1 人）。
- **成文 + 回查約 15%**，**品質閘 + 修正約 10%**（含一次超格，零次不可畫字）。
- 工具面：gpost 用 `curl` + HTML 表格剝標籤可直接抓；維基用 MediaWiki API
  （`action=parse&prop=wikitext` 取全文、`list=search` + `insource:` 找散落提及）。
  ⚠ **MediaWiki API 會限速**：連續請求會回「You are making too many requests」純文字（不是 JSON），
  症狀是解析失敗而不是 HTTP 錯誤。加 3 秒間隔與可識別的 User-Agent 之後正常。
- `partial` 剩餘 76 筆約需 **8 批**。
