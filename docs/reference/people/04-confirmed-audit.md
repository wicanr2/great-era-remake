## 1. 一句話結論

**`confirmed` 這個標籤名實相符的比例是 205/230 = 89.1%。**
另外 25 筆（10.9%）的維基專條依 §14.5 判準只到 **Tier C**——
條目存在，但引註不存在、或引註無一可追到已出版品與官方檔案。

這 25 筆裡有 9 筆已在先前批次取得 gpost 任免令（Tier A），評等不受封頂拘束；
其餘 **16 筆是這次稽核建議封頂 `medium` 的核心名單**。

⚠️ 反過來的發現同樣重要：**維基專條的品質不是這批人可信度的上限**。
78 筆 Tier B 的人另有 gpost 一手來源佐證，實際位階是 Tier A；
而建議降級的 16 筆**每一筆在 gpost 都查得到同名任免令**（2–18 筆，見 §4.1）——
也就是說，這 16 筆的問題不是「查不到」，是「當初只查了維基」。

## 2. 怎麼量的（判準寫死在這裡，可重跑）

三個量測全部取自條目原始碼（`action=query&prop=revisions&rvslots=main&rvprop=content`，
`redirects=1`），不看渲染後的頁面，也不看搜尋摘要。

| 量測 | 操作定義 |
|---|---|
| **A. 維護模板** | 掃全文 `{{...}}` 模板名。**硬觸發**只有 `{{unreferenced}}`（宣告全文無引註）；`refimprove`／`more footnotes needed`／`no footnotes`／`onesource`／`primarysources`／`需要二手来源`／`unreferenced section` 與行內 `{{請求來源}}`／`{{citation needed}}` 列為**警示**，不單獨降級 |
| **B. 引註數** | `<ref` 標籤數（含具名重用）；另計「可判讀引註單位」= `<ref>…</ref>` 內容 + 參考文獻／書目／註釋章節的條目。外部連結章節**只採其中符合出版品特徵的條目**，其餘不計（外部連結不是引註，不該被算成「劣質引註」） |
| **C. 引註目標** | 逐筆分類。出版品特徵：`{{cite book/journal/thesis/encyclopedia}}`、ISBN、頁碼／卷期、出版社／書局／研究所／檔案館、辭典／年表／通志／文史資料／訪問紀錄／學報／公報等工具書與期刊字樣。無出版品特徵者改看網域 |

引註目標的六個代碼（逐人表格用）：

| 代碼 | 內容 |
|---|---|
| `P` | 專書／期刊／已出版工具書（含帶頁碼的公報引用）|
| `A` | 政府檔案館、國史館、國圖、中研院、社科院近史所、Google Books、WorldCat 等機構資料庫網域 |
| `N` | 新聞媒體網頁（中時、聯合、中央社、人民網、新華網、鳳凰網、搜狐、網易…）|
| `W` | 個人網頁、部落格、論壇、百科互引、影音（百度百科、知乎、blogspot、YouTube…）|
| `?` | 網域無法歸類 |
| `–` | 無來源的說明性註腳（正文補充，不是引註）|

**Tier 判定**（依 §14.5 + §13.3）：

```
維基專條 Tier C ← 掛 {{unreferenced}}｜零引註零書目｜P+A 全部為 0
維基專條 Tier B ← 其餘（P+A ≥ 1，即至少一筆可追到已出版品或官方檔案）
人物 Tier A    ← 另有官職資料庫（gpost）任免令已被採用為來源
```

⚠️ **`N`（新聞網頁）刻意不計入 Tier B 的門檻。** §3.1 的 Tier C 明列搜狐、網易、每日頭條，
而中時、聯合這類報紙網站與它們在機械上分不開；把新聞一律排除是**偏保守**的選擇，
會讓少數幾筆（如 `#293 郝夢齡` 兩筆皆新聞）被判得比實際嚴。這是已知的方向性偏差，寫在這裡供覆核。

### 6.2 ⛔ 一手來源（gpost）**沒有全量掃描**，這是本報告最大的限制

Tier A 的判準是「政府檔案／官職資料庫有命中」，要逐人查 `gpost.lib.nccu.edu.tw`。
**本次沒有做 230 人的全掃**，理由是操作面的，不是技術面的：

1. **開工時 gpost 回 429**（`Request limit exceeded`）。同一時段有三支 `batchD1/D2/D3` agent
   正在對同一個站台查證。
2. **搶額度會反過來污染它們的結論。** gpost 限流的症狀是空結果，與「真的查無」一模一樣
   （§12.1、§20.1 已經為這件事付過一次代價：`unknown` 91 筆有三分之二是假的）。
   為了補完一張表而讓三個批次拿到假的零命中，代價遠大於收益。

折衷作法：**只查 16 個人**——維基專條判 Tier C 且從未進過自撰批次的那 16 筆，

## 7. 主迴圈的裁決 — **2026-08-02**

我自己重跑了報告內的一致性檢查（205 + 25 = 230 ✔、87 + 127 + 16 = 230 ✔、
逐人表 25 列與 §4.1 相符 ✔），並對一條判準做了修正。

### 7.1 ⛔ `{{unreferenced}}` 不是硬觸發——**模板輸給實際引註**

§2 把「掛 `{{unreferenced}}`」當成直接判 C 的條件。承辦者自己就標出兩個反例
（`#72 夏斗寅` 的引註是 archive.org 上的《申報》1919／《商報》1921 原件影像，
`#378 劉嘉樹` 有一筆國防部後備指揮部公告），建議人工判讀。

**裁決：這不是「人工判讀」的問題，是判準寫錯了。**

> `{{unreferenced}}` 是**別人在某個時間點貼的標記**，而引註是**條目現在的內容**。
> 兩者衝突時以內容為準——這就是 `CLAUDE.md` §7 的
> **「一手資料（原始檔案的內容）永遠贏二手推論（檔名、美術字樣、命名習慣）」**
> 換到維基上的同一條規則。模板沒被人清掉，是維基的維護落差，不是證據。

修正後的判準：

```
掛 {{unreferenced}} 且 P + A == 0   → Tier C
掛 {{unreferenced}} 但 P + A  > 0   → 以引註為準（模板視為過時），不降級
```

我用這條重掃了 §4.1 那 25 列：**受影響的正好是承辦者標出的那兩筆**，沒有第三筆。

### 7.3 ⭐⭐ 這是同一個病因的第三次確認

- `confirmed` 的 Tier C 名單 → **14 筆每一筆在 gpost 都有同名任免令**
- 反向：**78 筆掛 Tier B 的其實有 gpost 佐證，位階比宣稱的高**

三次都指向同一件事：**`02-status.md` 的三段分類量的不是「這個人查不查得到」，
是「當初那一次查得夠不夠仔細」。** 這與我在自傳程式裡犯過的
「把測量誤差當成母體特性」是同一個錯誤，只是這次寫在資料裡而不是我的預測裡。

**所以 `02-status.md` 的三段分類整個作廢，不只是 `unknown` 那一段。**
往後判一個人查不查得到，只認 `facts-*.json` 的 `verified_by` 與本報告，
不認 `02-status.md`。

### 7.4 承辦者做對的一件事，記下來

開工時 gpost 回 429，承辦者判斷是同時段的三支 `batchD1/D2/D3` 在查同一站台，
**主動退讓、只查決定封頂與否的 16 人並間隔 4 秒**，然後把
「Tier A 的 87 筆是下限不是實數、另有 124 筆從未量測」寫進限制。

這正是規格要的行為：**搶額度會讓別人拿到假的零命中**，
而假的零命中會變成「這個人查不到」寫進資料——`unknown` 那 91 筆就是這樣來的。
換成把表格補滿的做法，這份報告會好看很多，也會沒有用。
