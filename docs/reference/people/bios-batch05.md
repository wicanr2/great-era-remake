## 選樣與這一批的特殊性

本批由派工指定，10 人全部是北伐時期、`people.json` 標 `partial` 的人物，其中 **#176–#183 七人同屬直魯聯軍**。
派工預先點出兩個陷阱，實際狀況比預告的更嚴重：

| 預告的陷阱 | 實際狀況 |
|---|---|
| 「直魯聯軍序列表常常互相抄，看起來三個來源其實同源」 | 比同源更麻煩：中文維基百科內部有**三份**直魯聯軍序列表（〈直鲁联军〉〈方面军〉〈张作霖〉），依規格 §3.1 第 1 條算**一個** Tier B 來源，而**這三份彼此不一致**——第八軍軍長就有「柴永升」「柴云升」「祝祥本」三個答案。同源不但不能當多來源，還會自相矛盾 |
| 「#180 柴榮陞的職務欄已標『一說』，代表資料本身就有分歧」 | 分歧是四說不是兩說，而且四說之間還有一層「這四種寫法是不是同一個人」的問題。本篇最後寫成候選清單而非傳記 |

**本批未使用任何 Tier C 來源。** 全部內容出自政大官職資料庫（Tier A）與中文維基百科（Tier B）。

劉志陞，生卒年與籍貫不詳，以此寫法未查得任何記載。中文維基百科的直魯聯軍序列列第十三軍軍長為劉志陸，駐濟寧，轄第六十一、第六十二師。1927年1月5日，張宗昌與孫傳芳商定收編廣西、廣東的馬濟、劉志陸兩部；8月15日率部取道巨野，會合第二十四軍潘鴻鈞部進攻荷澤，19日夜占荷澤；10月任隴海鐵路方面右翼，21日占新舊考城，11月3日自考城撤圍；11月25日所部與潘鴻鈞部在考城為國民革命軍第三軍吉鴻昌、梁冠英兩師包圍，26日潰散。1927年10月6日特任遠威將軍。另據中華民國政府官職資料庫，該劉志陸為廣東人，1921年任將軍府將軍，1927年7月加銜陸軍上將，1930年任軍事參議院參議，1939年任廣東省政府委員兼廣東省第五區行政督察專員；名字與遊戲寫法一字之差，軍職與時期相合，是否同一人待考。

## 作業面的三條

1. **WebSearch 額度在本批開始前就已用罄**（工具回報 200/200）。本批全程只用 MediaWiki API
   （`action=parse&prop=wikitext` 取全文、`list=search` 配 `insource:"…"` 做全站精確檢索）與 `curl` 抓 gpost，
   **證明 §9.6 的建議是對的**——`insource:` 檢索對這批「只出現在編制表裡」的人物特別有效，
   #182 張宗輔全站只有四處提及，就是靠它一次盤點完的。
   ⚠ 兩個 API 都會回 **429 Too Many Requests**，腳本要內建退避重試，否則會誤判成「查無」。

2. **一批 10 篇的實際成本**：查證約 65%（每人 1–3 次 gpost 查詢 + 5–10 個維基條目全文）、
   成文與回查約 25%、品質閘與修正約 10%（兩篇超格）。
   **七人同屬一個軍系反而降低了單位成本**——〈直鲁联军〉〈1927年中国〉〈北洋政府将军府将军列表〉
   三個條目一次抓下來，七個人共用。**建議後續派工優先按軍系／戰場分批，不要按 id 順序分批。**
