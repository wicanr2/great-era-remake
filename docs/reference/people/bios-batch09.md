## 一個要傳給 `unknown` 91 筆的警告

⚠ **91 筆的「查不到」結論，可信度低於它看起來的樣子。** 三個理由：

1. **限流與查無同形**（§12.1）。本輪 gpost 首查回 429、MediaWiki API 也回過 429，
   兩者的下游症狀都是「零筆」。
2. **異寫未必查過**。本批「曾萬鍾／曾萬鐘」在 gpost 是**兩組完全不同的結果**（3 筆／2 筆，且無交集），
   「鐘彬／鍾彬」是 0 筆／10 筆。若當初只查了 `name_ingame` 一種寫法，10 人裡至少 2 人會被判成查無。
3. **名冊型條目大概率沒被掃過**（`G-09-3`）。那七張全表是**反向可用**的——
   拿 91 個姓名去比對，成本是一次批次下載加一次字串比對，不是 91 次查證。

**建議 `unknown` 91 筆的重跑順序**：先把七張名冊全表抓下來做一次批次比對（成本最低、覆蓋最廣），
再對命中者跑 gpost 全異寫，最後才做 `insource:`。**不要照 `unknown` 現有的順序一個一個查。**
