# `modern_scene` 原創 MIDI 草稿

> 狀態：**DRAFT／不可進發行包**  
> 日期：2026-08-11  
> Cue：`modern_scene`（開局與一般敘事）  
> 動機 ID：`dsds-modern-scene-m01`

## 1. 邊界與目的

這是《大時代的故事》remake 的全新作曲草稿，不是 1992 年原聲帶、修復版或重新編曲。
它只參考原版 `SCENE` 已證實的技術／情境條件：民國初年軍政畫面、四拍、約中速、有限
OPL2 聲部造成的清楚音域分工與「具音高的打擊感」。本草稿**沒有**讀取、轉寫、取樣或
逐音引用 `workplace/audio/midi/SCENE.mid`、`.MUS`、`.TIM`，也不保留其旋律、和聲、
低音線、節奏型或段落。

目標是在玩家閱讀地圖、新聞與人物文字時，提供克制的室內樂聲場：像在鋼琴、低弦與
單簧管之間思考下一步，而不是替任何勢力宣布勝利或道德立場。

## 2. 新動機與節奏

動機 `dsds-modern-scene-m01` 是下列五音；音高採科學音高記法：

```text
D4(八分) → G4(八分) → F♯4(四分) → A4(八分) → E4(附點四分)
間距（半音）：+5, -1, +3, -5
```

這個「上四度、收半音、短暫抬升、回五度」的輪廓刻意不是純五聲進行，也避免進行曲
式的上行終止。它的功能是未完的思考，不表示勝敗、勢力、兵力或 AI 狀態。

- 速度：92 BPM。
- 拍號：4/4。
- 寫作網格：96 PPQN；每小節 384 tick。
- 循環：第 1–8 小節，3,072 tick，約 20.87 秒。連續三圈約 62.61 秒，正好是首次
  疲勞測試的最小聽感時長；正式混音前不可假稱已通過人耳驗收。
- 調性重心：D 小調的開放感，穿插 F♯ 作為 Dorian 色彩；第 8 小節停在 A7sus4 質地，
  回到第 1 小節時才解除，不寫英雄式終止。

## 3. 八小節編曲規格

| 小節 | 和聲重心／工作 | 主動機與配器 |
|---:|---|---|
| 1 | Dm(add9) | 鋼琴單線完整奏出動機；低弦保留 D。 |
| 2 | Gm6 | 鋼琴把動機拆成較寬的呼吸；低弦移至 G。 |
| 3 | C(add9) | 只留 `G–F♯–E` 碎片；正式版由單簧管首次回答。 |
| 4 | A7sus4(b9) | 音域收窄，不解決；避免銅管與鼓點。 |
| 5 | Dm(add9) | 動機原形再現，但正式版改由單簧管，鋼琴讓出中音。 |
| 6 | Gm6 | 鋼琴改為分散和聲；低弦維持稀疏長音。 |
| 7 | Eø7／A7 色彩 | 把動機壓縮成 `E–A–G–F♯`，增加輕微壓力。 |
| 8 | A7sus4 | 僅留回環引導音；尾韻預留給正式 Ogg 的 loop tail。 |

提交的 `modern_scene_draft.mid` 只含鋼琴與低弦，沒有鼓、銅管、取樣或音效；它是可審稿
的旋律／和聲草稿，不是最終配器。正式 `music` stem 才加入低音提琴、單簧管與極淡的
室內殘響；`fx` stem 首版保持空白，避免以音樂模擬戰爭。兩個 stem 必須同一取樣率、
相同起點、相同小節網格，且單獨或合併時均不削波。

## 4. OPL2 時代參考如何轉化

- 參考原版 9 聲部／單音聲部的**清楚分工**：正式版每一時刻仍以一條清楚旋律與低音
  重心為主，而不是以現代管弦樂厚疊掩蓋閱讀畫面。
- 參考 OPL2 具瞬態的電子鋼琴／打擊感，改由低力度鋼琴與偶發撥弦承擔；不取樣、不
  模擬原版 `.TIM` 音色，也不重建任何 OPL2 patch。
- 參考 `SCENE` 的中速、非戰鬥情境，**不**取用其音符、速度事件、和聲或段落。92 BPM
  是本草稿獨立選定的速度，不是原版 94 BPM 的微調。

## 5. 排除項

- 不得引用、改寫或反向工程任何原版旋律、和聲、低音、節奏、PCM、`.MUS`、`.TIM` 或
  分析用 MIDI。
- 不得引用國歌、黨歌、軍歌、日本軍歌、抗戰歌曲、傳統曲牌或可辨識的既有歌曲。
- 不使用尺八／都節音階等勢力標籤，也不使用鑼鈸堆疊、合唱、EDM drop、持續 ostinato、
  強烈英雄終止或戰況／AI 資訊驅動的配器變化。
- 這份 MIDI 不是 Ogg、不是 playable asset、未經聽審；不得放進 `assets/music/modern/`、
  manifest 或發行包。

## 6. 相似性自檢與人耳閘門

1. 編曲者先以單一鋼琴音色唱／彈完整八小節，確認動機的間距序列為
   `+5,-1,+3,-5`，沒有把任何既有曲調當作補完提示。
2. 獨立審稿者只看本文件的音名與節奏，不看曲名或原版素材；若能辨識成特定既有歌曲，
   立即退回改寫。這是辨識風險檢查，不是著作權法律意見。
3. 取得可聽 mockup 後，至少兩名人類審稿者盲聽三次循環，檢查是否聽成軍歌、國歌、
   原版旋律或某一勢力的道德標籤；任何一項命中即重新作曲並追加勘誤。
4. 發行前由權利／發行負責人進行外部曲庫與授權清查。自檢通過不等於法律 clearance。

## 7. 可重生性與 provenance

`tools/music/modern_scene_draft.py` 只讀同目錄 `score.json`，使用 Python 標準函式庫寫出
Format 1 Standard MIDI File；不讀 `workplace/`，不需網路或第三方套件。固定輸出位元組
的 SHA-256 寫在 `modern_scene_draft.mid.sha256`。

`*.mid` 受專案 `.gitignore` 排除；工作樹可由下列 Docker 命令重建監聽草稿，版本庫保存
的是 `score.json`、產生器、hash 與 provenance，而不是把任何音樂檔偷偷當成 playable 或
發行資產。若要交付給人類編曲者，請把重建出的檔案放在明確的審稿輸出目錄，完成聽審與
授權後再另行決定是否納入發行包。

```sh
# Docker-only；產生後應與 .sha256 的第一欄相同。
docker run --rm --network none --memory 512m --cpus 1 --pids-limit 64 \
  -u "$(id -u):$(id -g)" -v "$PWD:/work" -w /work dsds-go:1.25 \
  sh -lc 'python3 tools/music/modern_scene_draft.py --output docs/music/modern_scene/modern_scene_draft.mid && \
          python3 tools/music/modern_scene_draft.py --check --output docs/music/modern_scene/modern_scene_draft.mid && \
          sha256sum docs/music/modern_scene/modern_scene_draft.mid'
```

| 欄位 | 值 |
|---|---|
| 草稿責任 | Codex 協作草稿；尚未指定可發行的自然人／法人作者 |
| 產生法 | 受版控 JSON score + 決定性 Python 標準函式庫 writer |
| 原版素材 | 未讀取、未複製、未取樣 |
| 音源／樣本 | 無；MIDI 僅含 General MIDI program 編號作監聽提示 |
| 授權狀態 | 草稿待人類作者、演出／取樣來源及發行授權確認；不可發行 |
| 人耳 QA | 未完成；不得以檔案可解析取代 loop、混音或相似性聽審 |

正式製作時要另建不可變更的 provenance record，登記人類編曲者、演出者／音源、授權、
混音版號、Ogg 雜湊、loop sample、審稿日期與發行用途。沒有完整記錄的 Ogg 不得寫入
Modern manifest。
