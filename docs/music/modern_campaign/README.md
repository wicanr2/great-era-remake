# `modern_campaign` 原創豪情 cue 草稿

> 狀態：**DRAFT／不可進發行包**  
> 日期：2026-08-11  
> 用途：Modern 政略／推廣片的第一支「大時代豪情」試聽 cue  
> 動機 ID：`dsds-modern-campaign-m01`

目前遊戲內已有可重現的純 Go runtime fallback：`internal/ui/audio/procedural.go` 以同一
六音動機、低音進行、脈衝、銅管進場、13–14 小節留白與 15–20 小節高潮產生八條約 24
小節的可播放循環。它讓 Modern 模式在沒有 Ogg manifest 時仍有「大時代豪情」的完整
音樂弧線；這不是把原版音樂轉檔，也不會把本草稿誤標成已清權的正式 Ogg。

本輪另提供離線 WAV 聽審入口（仍非發行資產）：

```sh
tools/go.sh run ./cmd/modern_audio -out /tmp/great-era-modern-audio \
  -report /tmp/great-era-modern-audio/report.json -effects
```

它與遊戲共用同一份純 Go renderer，會產生八條 cue、八類效果音與 `report.json`。
以 48 kHz 重生的 `main-theme.wav` 為 51.43 秒，SHA-256 為
`387f63071f375c091c94fd48cf7119524fe5c7e3f96e52f7e24e9f60a6586e20`；報告會記錄
峰值、RMS、mono RMS、首尾差、clipping、非靜音與每檔 SHA-256。WAV 與 JSON 只供
技術聽審／waveform QA，正式 Ogg／清權／人耳與裝置驗收仍另行記錄。

## 1. 為什麼另作一支

`modern_scene` 的任務是陪伴閱讀與人物敘事，刻意稀疏、內省；它不能單獨承擔推廣片
需要的歷史重量。這支 `modern_campaign` 針對使用者指出的「沒有大時代故事豪情感」
重新設計：先讓玩家聽見電報室、木桌與遠方行軍的空間，再以銅管、低弦與節制軍鼓
把視線推向北方，而不是一開始就用無差別的電影式大爆發。

聲音身份可以濃縮成：

> 玩家在「電報紙張、木製指揮桌、遠方鐵路」構成的民國軍政世界裡做出調度，
> 由一個全新六音動機承載「尚未結束的行動」；OPL2 只作清楚聲部與瞬態的技術參考，
> 勝利帶著代價，高潮之後仍保留未解決的回望。

這不是 1992 年原聲帶、修復版或重新編曲；沒有讀取、轉寫、取樣或引用原版
`.MUS`／`.TIM`、分析 MIDI、國歌、軍歌、黨歌或傳統曲牌。

## 2. 全新動機與弧線

動機 `dsds-modern-campaign-m01`：

```text
D4 → G4 → F4 → B♭4 → A4 → D5
```

半音間距為 `+5, -3, +6, -1, +5`；節奏為 `八分、八分、四分、八分、八分、二分`。
它先向上伸展，再以不規則的三全音／半音折返，最後到達八度 D；這個輪廓是本專案
新作曲的識別，不代表勢力、勝負或任何規則狀態。

- 速度：112 BPM；拍號：4/4；96 PPQN。
- 24 小節、9,216 tick，約 51.43 秒；可作推廣片固定時間軸，也可在 bar 24 的
  A7sus 質地回到 bar 1。
- 低密度前奏：1–4 小節；集結：5–8；推進：9–12；13–14 小節刻意留出兩小節
  「真空」，讓旁白／遊戲音效有位置；15–20 小節是豪情高潮；21–24 小節回望並
  留下循環懸念。

## 3. 配器與段落

| 小節 | 玩家感受 | 配器與功能 |
|---:|---|---|
| 1–4 | 遠景／抉擇前 | 低音弦長音、低力度鋼琴脈衝、單簧管只說動機前半；不放軍鼓 |
| 5–8 | 集結 | 法國號／銅管回答動機，低弦加入五度步行，鋼琴改成八分脈衝 |
| 9–12 | 行動開始 | 短銅管與軍鼓進入，木管反拍保持中頻清楚；不連續轟炸 |
| 13–14 | 真空 | 幾乎靜音，只留低 D、一次低鼓心跳；供推廣片旁白與遊戲音效呼吸 |
| 15–20 | 大時代豪情 | 銅管完整呈示動機，低弦／鋼琴向前推，軍鼓在 2／4 拍支撐；第 18 小節加一次銅管上行，不寫成勝利宣言 |
| 21–24 | 回望／循環 | 木管與銅管交接動機，24 小節停在 A7sus；回到 1 小節才釋放，不把歷史代價抹掉 |

交付 stem：`music`（鋼琴、低弦、木管、銅管）與 `pulse`（軍鼓／低鼓／短打擊）。
兩軌同起點、同 96 PPQN／bar grid；任何一軌單獨播放都不應爆音或失去拍點。推廣片
混音需在 13–14 小節保留對白與實際遊戲音效 headroom；遊戲循環則以 `music` 為主，
`pulse` 可依情境關閉，不把鼓點綁定 AI 或勝負。

## 4. 與原版硬體語彙的關係

- 只借用 OPL2 時代「聲部少但輪廓清楚、瞬態能穿過 DOS 混音」的工程限制；不重建
  `.TIM` patch，不取樣原版，也不聲稱同一音色。
- 銅管與軍鼓用來表達玩家行動的重量，不替任何歷史勢力貼正邪標籤。
- 不使用可辨識的真實軍歌節奏、國歌終止、政治口號或現成電影主題；相似性自檢若
  讓人聯想到特定歌曲，必須改寫動機並追加勘誤。

## 5. 人耳／技術閘門

1. 單鋼琴版先盲聽三圈：動機可辨識、無既有歌曲聯想、bar 24→1 無突跳。
2. 加入 `pulse` 後確認 13–14 小節確實形成可用的低密度空間，而非播放器故障。
3. Ogg 渲染後測試 loop 波形、mono、-18 LUFS 左右整合響度、true peak ≤ -1 dBTP，
   並在 UI／遊戲音效同時播放時確認中頻可讀。
4. provenance 必須記錄作者／工具、音源／樣本授權、MIDI／WAV／Ogg 雜湊、loop sample、
   版本與用途；本草稿沒有自然人發行作者與清權音源，不得放進 `assets/music/modern/`
   或正式 manifest。

## 6. 可重生輸出

`score.json` 與 `tools/music/modern_campaign_draft.py` 只使用受版控的原創音符資料與
Python 標準函式庫；不讀 `workplace/`、原版 MUS／TIM 或任何分析 MIDI。`*.mid` 只是
審稿用草稿；可聽預覽若產生，留在被忽略的 `workplace/promo/modern_audio/`，不進
GitHub 發行包。

本輪已在既有 Docker 音訊映像以 FluidSynth／FluidR3_GM 渲染本機預覽，並在 24 小節
邊界做 0.5 秒 crossfade：

```text
workplace/promo/modern_audio/modern_campaign_loop.ogg
SHA-256: bbbdfb061ba8a175f66c09f9e923a9aea6da443a3873e81ef77ffdc77fa5aa55
48 kHz／立體聲／Vorbis／51.43 秒；-15.8 LUFS、-1.7 dBFS true peak
```

這是「豪情方向」的可聽技術預覽，不是已清權的成品；正式 Ogg 仍需自然人編曲／音源
授權、盲聽相似性與 Android 裝置抽聽。
