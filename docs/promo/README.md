## 已驗證的連續玩家路徑

輸入均經正常 UI／Action 路徑，沒有把展示 PNG、mockup 或靜態成果頁剪進影片：

1. 復古政略地圖；
2. `F2` 切成 Modern 圖形，再以 `F3` 切成 1280×720 的 H4 軍事衛星作戰室；
3. 以滑鼠由「指令」進入 5×3 政略指令矩陣，選「查閱」→「查閱將領」→將領詳情；
4. 開啟蔣中正人物自傳，顯示已登錄的離線肖像與來源可靠度；此示範人物為單頁 `1/1`，
   不假稱有翻頁內容；
5. 由正常返回路徑轉往河南，進入戰鬥，以滑鼠開啟「攻擊」目標選擇、取消選擇，再按
   「結束回合」；畫面可見回合推進至 `第 2/16 回合`。

這證明 H4 高解析主畫面、主題／解析度切換、指令矩陣、人物檔案與肖像、滑鼠命中、戰鬥
指令和回合流程可接在同一條玩家路徑；它不宣稱原版戰鬥 AI、全部攻擊分支或跨平台真機驗收
已完成。

## 音樂與發行邊界

影片配樂是 `cmd/modern_audio` 以純 Go 生成的 `main-theme` 技術預覽，再外部混入影片；
沒有取樣、轉寫或重配原版 `.MUS`／`.TIM`，也沒有把 WAV、Ogg 或原版音源打入任何 release
archive。`modern-audio-qa.json` 記錄其 48 kHz、雙聲道、無削波與非靜音的技術檢查。

它仍是 `draft-not-for-release`：自然人作者身分、權利清查、盲聽相似性、人耳混音與裝置 QA
尚未完成。因此本片是可檢查實機流程與技術串流的候選推廣片，不能描述為正式原聲帶、已清權
音源或可公開發行素材。

公開發布前仍需完成素材／字型／音源權利審查、正式配樂 QA，以及 Windows、macOS、Linux
的正常玩家路徑實機驗收。舊影片位於 `dist-all/promo/` 的歷史子目錄，只保留作開發紀錄，
不再是 Modern H4 的推廣基準。

推廣訊息應聚焦於：以復古與 Modern 雙介面保存民國初年的歷史原味，並用現代資訊層級、
白話用語、人物自傳與可讀肖像降低新一代玩家的進入門檻。

## A2 M2 民國測繪與人物肖像版

新版候選片位於：

`dist-all/2026-08-12-a2-m2-portraits/promo/great-era-remake-a2-m2-portrait-playthrough.mp4`

它是 63.787 秒的同一 Docker＋Xvfb 視窗連續錄影，畫面依序涵蓋復古地圖、Modern 高解析
民國測繪地圖、司令官縮圖、查閱流程、蔣中正人物自傳大幅肖像，以及正常戰鬥操作與第二回合。
沒有插入 mockup 或靜態成果圖。影片為 H.264 1280×720／30 fps、AAC 48 kHz 雙聲道；
SHA-256 為 `6e26e1b560cc8a8ecf547bf470ff5dded23c47703111ff5807de7277fda8f064`。

製作流程參照 `game-promo-video-ffmpeg` 技能：容器限制 2 CPU，x264 使用 `veryfast` 與 2 threads；
配樂先離線生成、檢查非靜音／無削波，再循環後裁成影片全長，避免較短音軌截掉結尾。依專案較新
的權利決定，本片不用原版音樂，而沿用 `cmd/modern_audio` 的純 Go `main-theme` 技術預覽；
這個差異避免散布原版旋律，但仍須自然人作者、盲聽相似性、人耳混音及裝置 QA，故本片不是正式
可公開發行的已清權宣傳素材。
