# 推廣片分鏡：H4 軍事衛星作戰室的連續實機流程

目前的 66.176 秒本機連續實機錄影是「玩家路徑基準」，檔案與權利邊界見
[`README.md`](README.md)。時間點會隨機器啟動有小幅差異；下列正常操作順序才是驗收契約。

| 段落 | 實際畫面／輸入 | 要證明的事 |
|---|---|---|
| 0–8 秒 | 復古政略地圖，`F2` 切至 Modern | 原典與 Modern 圖形可在同一遊戲狀態切換 |
| 8–14 秒 | `F3` 切高解析；H4 全域指揮室地圖、軍情檢視器、操作列 | Modern 不只是放大地圖；既有資料仍是決策脈絡 |
| 14–19 秒 | 滑鼠點「指令」；政略 5×3 指令矩陣 | 15 項既有政略入口以現代矩陣呈現，沒有假快捷鍵 |
| 19–28 秒 | 滑鼠點「查閱」→「查閱將領」→將領詳情 | 人物資料與既有 Action 接在正常路徑 |
| 28–34 秒 | 滑鼠點「人物自傳」；顯示蔣中正單頁人物檔案與離線肖像 | 自傳、可靠度與已登錄肖像可讀；不誤稱這個單頁案例有翻頁 |
| 34–48 秒 | 以實際返回操作離開人物檔案，移至河南並進入戰鬥 | 人物檔案不是展示死路，能回到正常遊戲操作 |
| 48–66 秒 | 高解析戰鬥；滑鼠選「攻擊」、取消目標選擇、按「結束回合」 | 戰鬥 HUD、滑鼠控制與回合推進是真實遊戲狀態，不是靜態合成 |

配樂使用 `modern_audio` 的純 Go `main-theme` 技術預覽作外部影片混音；它不是原版音樂，
也不是正式可發行的 soundtrack。影片畫面不應被當作原版規則全等價、音樂清權完成或跨平台
真機驗收的宣告。
