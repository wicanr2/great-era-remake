### 原典用語

1. `Enter → O`：第 6 項顯示「訊息時間 5」，而且不再標「尚未完成」。
2. `6`：顯示「訊息時間（1-10）」與數字輸入。
3. `1 → 0 → Enter`：回其他選項，底部顯示「訊息時間已設定」。
4. 訊息尚在時送 `9`，4 秒後仍留在其他選項，證明等待期間沒有執行輸入。
5. 到期後再送 `9`，正常進入顯示設定。
