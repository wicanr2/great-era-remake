# 原典／現代白話：秘密行動

日期：2026-08-02  
狀態：**confirmed（指令 11「鼓動學潮」呈現與規則等價）**

## 目的

把原典「司令鼓動何省學潮」的倒裝問句接上現代白話，同時證明用語切換不會
改變目標、省份效果、花費、指令數或存檔。

## 同一組操作

第一期 `SAVE(1).DT1`、湖北、固定種子 1：

```text
Enter → V 秘密行動 → 截取選單 → 2 鼓動學潮
→ 輸入 19 河南 → 截取目標頁 → Enter 執行 → F10 → Y
```

兩次只改 `-wording original`／`-wording plain`。

## 畫面

- 原典：`游擊隊／鼓動學潮`、`司令鼓動何省學潮`。
- 白話：`派遣游擊隊／鼓動學生發起抗議`、`要在哪個省鼓動學生抗議？`。
- 四張 GUI 截圖均經人工檢查，沒有缺字、裁切或上一幀殘留：
  `workplace/screenshots/covert-wording/{original,plain}-{menu,target}.png`。

## 結果

- 兩次日誌完全相同：河南省發生學潮，影響 25 位將領，花費黃金 1,500，
  剩餘指令數 1。
- 原典與白話輸出存檔逐位元組相同，SHA-256 均為
  `72e86ca8e2a1be44fe8d39b5a269f2d975c5c7dca98ad63b22456e468a99b37e`。
- 原始輸入 SHA-256 為
  `9ad9359b436ce2450ff3460df4efede478d871dfe234f60299759e781959ad0d`，
  因此不是未執行指令的假等價。

游擊隊效果雖已解，但原版派遣成本仍缺證據。選單可以顯示，選擇後仍會明確回報
