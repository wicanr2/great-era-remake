# PLAYTEST-38 指標／觸控 M2：戰場相鄰格

日期：2026-08-03  
狀態：**單元與整體回歸已通過；GUI／Android 實機待驗**

## 先校正地圖語意

政略主畫面右側不是可選 39 省的戰略地圖，而是目前省份的 14×14 戰場
`NWMAP`。因此本輪沒有把點格子接成選省；那會創造原版與現有鍵盤流程都沒有的
規則。相同圖面只有在 `screenBattle` 才公告互動目標。

## 操作契約

- `layout.BattlefieldCellAt` 依已證實的原版公式反算格號：每格 32×24，奇數欄
  下移 12 像素，格號為 `row*14+col`。
- 戰鬥中點目前單位的相鄰空格，派送 `battle.move.1` 至
  `battle.move.6`，與數字鍵 1–6 走同一個 `BattleSim.Move` 路徑。
- 點 Enter 原本會選到的第一個相鄰敵軍，派送 `battle.attack`，與 Enter 走同一個
  `BattleSim.Engage` 路徑。其他敵軍或友軍佔用格不公告目標，避免假裝已有多目標
  選擇規則。
- 主畫面格子、非相鄰格、欄位錯位形成的上方空白及戰場外座標一律不派送動作。

## 已知差異與後續

數字鍵 1–6 本身就是重製版操作，不是已還原的原版戰鬥七項選單；點擊只是它的
裝置等價入口，不能反過來當作原版操作證據。Android 尚需驗證橫向安全區、不同
密度、觸控中斷與系統返回鍵；戰鬥也仍缺可見的換部隊、攻擊與結束回合按鈕。
