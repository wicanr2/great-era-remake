## GUI 與存檔閉環

使用真實 `SAVE(1).DT1`、起始省湖北（26），在 Docker Xvfb 中操作：

```text
Enter → 8 政策 → 2 產能分配 → 1 鐵礦 → 20 Enter → ESC → F10 → Y
```

stderr 回報「產能已調整為 20%（剩 1）」。輸出與原存檔只差一個 byte：

```text
cmp -l: 964  31  24       # 八進位：25 → 20
SHA-256: d34c17c57387d60ec0bfe9f4bff5acdc24109ca6eeea700d340fb71c4ab8b996
```

第 964 byte 正是湖北省記錄 `+34`（鐵礦產能）；其他 14,682 bytes 全部不變。
輸出擁有者為目前使用者 `1000:1000`，驗證容器已以 `--rm` 清除。
