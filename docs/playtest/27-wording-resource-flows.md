# 運補與商業活動的原典／現代白話

> 日期：2026-08-02  
> 狀態：**confirmed**

## 覆蓋畫面

- 商業活動：進口／出口、可買賣品項、數量輸入。
- 運補：合法目標省、黃金／糧食／彈藥／燃料四段數量輸入。

白話例如「進口／出口」→「買入物資／賣出物資」、
「司令，欲運補何省？」→「要把補給運到哪個省？」。
候選集合、品項順序、上限、匯率、指令消耗與存檔寫回不變。

## Docker Xvfb 等價驗證

商業活動在兩種用語下執行：

```text
Enter → T → 1 買入 → 1 糧食 → 300 Enter → F10 → Y
```

均回報「購買糧食 300，共用黃金 10（剩 1）」，兩份存檔逐位元組相同：

```text
SHA-256 3ebe797437ca76f2ebe2e11ea4193e4851ed8642a6cdd2c996ac76376a8d8fde
```

運補在兩種用語下執行：

```text
Enter → S → 19 Enter → 100 Enter → 200 Enter → 300 Enter → 400 Enter → F10 → Y
```

均回報「運補至河南省：黃金 100、糧食 200、彈藥 300、燃料 400（剩 1）」，
兩份存檔逐位元組相同：

```text
SHA-256 45d928a38aa5058bdf7eaf90db464f235c2bc90b06e3c43737b0ef491015941a
```

兩條流程的各階段均有 ignored 截圖位於 `workplace/resource-wording/`。
人工檢查確認沒有裁切、重疊與缺字；stderr 無合成失敗或 panic。
