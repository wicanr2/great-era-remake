# 13 — 開新遊戲的設定畫面：「電腦個性：和平／好戰」

> 環境：`fd2-dosbox-screenshot-local`、DOSBox 0.74-3、Xvfb :99、`play.bat`
> 日期：2026-08-01

先前的實測一律走「載入存檔」（`docs/playtest/02`、`06`）。這次走**開新遊戲**，
拿到三個先前沒見過的畫面，其中一個直接回答了一個標成 confirmed 的錯誤結論。

---

## 1. 進入序列

```
Return → 2 → Return → 1 → Return → 1 → Return    片頭與選單
1                                                 玩家人數（1–9）
Return
2 / 3 / 7                                         屬性三選（見 §3）
Return → Return → Return
1                                                 密碼（三選一任選）
```

到這裡就是政略畫面：**民國 15 年 7 月 秋**、江蘇省、司令孫傳芳。

⚠️ 屬性畫面**每一組要各選一個**，勾選符號 `✓` 會停在選中的那一列。
送鍵太快會被吃掉——第一次跑只勾到「3 高」與「7 進階者等級」，
`2` 那一下沒進去。每個 `key` 之間留 2 秒才穩。

## 2. 十大勢力的編號 — **confirmed**

玩家人數之後的畫面把十位領袖連編號一起列出來（頭像 + 姓名）：

| # | 領袖 | # | 領袖 |
|---:|---|---:|---|
| 0 | 蔣中正 | 5 | 閻錫山 |
| 1 | 張作霖 | 6 | 劉　湘 |
| 2 | 孫傳芳 | 7 | 袁祖銘 |
| 3 | 吳佩孚 | 8 | 唐繼堯 |
| 4 | 馮玉祥 | 9 | 趙恆惕 |

**這是 0-based 的勢力編號**，與將領表的 1-based ID 是兩套東西。
`gameover.go` 的「十大勢力」在原版掃的是一張 24 格的 word 表
（`docs/re/06` §3），與這裡的 10 個編號怎麼對應**還沒接上**。

## 3. ⭐ 屬性設定：三組七個選項 — **confirmed**

```
電腦個性        1. 和平    2. 好戰
人工智慧等級    3. 高      4. 低
遊戲難易程度    5. 初學者等級   6. 入門者等級   7. 進階者等級
```

### 「好戰」的存在推翻了「電腦不會攻打」

`docs/re/12` 曾把「**這是玩家主動制的戰棋，戰爭只能由玩家發動**」標成 confirmed。
`docs/re/29` 已用靜態證據推翻（電腦會填參戰部隊表）。

**這個畫面是獨立的第二證據，而且是玩家直接看得到的**：
如果電腦永遠不主動開戰，「和平 vs 好戰」這個設定沒有任何意義。

順帶解掉一個懸案：`docs/re/23` §5 記過 `2.15` 詞 29 是「好戰和平」，
當時不知道用在哪。**就是用在這裡。**

### 三組設定對應 `byte_6FFCA` 的位元

`70-ai.md` §6c 從程式碼讀出 `byte_6FFCA` 的三塊語意，形狀正好對得上：

| 畫面 | 選項數 | `byte_6FFCA` 的候選位元 | 依據 |
|---|---:|---|---|
| 遊戲難易程度 | 3 | **bit 4–6**（三選一的戰力加成 ×2／×1.5／只給蔣中正）| `70-ai.md` §6c |
| 人工智慧等級 | 2 | **bit 2**（啟用決策鏈的最後三步）| `70-ai.md` §6d |
| 電腦個性 | 2 | bit 0？（`docs/re/11` §6：救援調動改用模式 7）| 弱 |

⚠️ **這張對應表是假說**。三組選項數（3／2／2）與三塊位元的形狀吻合，
但**沒有追出寫入點**——`70-ai.md` §6d 早就記著「誰寫這個 byte 未追」。
要坐實就得找出這個畫面把選擇寫到哪裡。**在那之前不要當結論用。**

「電腦個性」若真的是 bit 0，那 `docs/re/11` §6 那條
「救援調動在某條件下用模式 7 而非 5」讀起來就是**好戰時更積極把兵往前線送**——
語意通順，但同樣未驗。

## 4. 政略畫面的地圖是彩色的勢力圖

先前的截圖都在存檔局面下取，這次看到**全彩勢力範圍圖**：
每個勢力一種顏色，省份編號疊在上面（1–36 可見）。

這對驗證「電腦會不會打過來」是理想的觀察量——**顏色分佈變化 = 省份易主**，
不必進去逐省查數值。
