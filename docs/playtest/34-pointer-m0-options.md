# PLAYTEST-34 指標／觸控 M0：其他選項垂直切片

日期：2026-08-02  
狀態：**PASS（M0 第一批；不代表全遊戲已可點擊）**

## 架構

- `internal/ui/actions` 定義穩定動作識別碼，鍵盤、滑鼠與 Android 觸控不直接
  修改遊戲狀態。
- `SurfaceToLogical` 將平台 Surface 反算至 640×350 邏輯畫布，測試涵蓋
  等比縮放、上下黑邊、左右黑邊與邊界外拒絕。Ebiten adapter 的
  `CursorPosition`／`TouchPosition` 已由 `Layout` 提供邏輯座標。
- 滑鼠與觸控都在放開時才派送一次；移動超過 8 邏輯像素、畫面在按下與
  放開之間改變，或結果訊息仍在擋輸入時，一律取消。
- `internal/ui/layout.Grid` 同時產生 renderer 文字基準點與命中區；
  政略選單、其他選項與顯示設定不再各維護一份座標。
- 地圖右上新增 90×48 邏輯像素的「指令」按鈕；文字沿用原版字模，按鈕是
  重製版操作外殼。鍵盤 Enter、滑鼠與 Android 觸控均派送 `command.open`。

## GUI 實跑

建置用 `dsds-go:1.25`；實跑用一次性
`fd2-dosbox-screenshot-local:latest` 的 Xvfb／xdotool／ImageMagick。

第一批驗收曾以 `Enter` 從地圖叫出政略選單；補上可見入口後，第二批回歸改為
從地圖直接點「指令」。進入離開確認仍使用 `F10`，其餘路徑均使用滑鼠：

1. 點政略選單 15，進入其他選項。
2. 點儲存與「確定」，產生存檔與畫面結果訊息。
3. 在第 2 項上按下，移動 20 邏輯像素後放開；畫面留在其他選項，
   沒有誤觸載入。
4. 點第 9 項、現代白話、返回其他選項，再點返回政略選單。
5. F10 後用滑鼠點確定儲存並離開。

人工檢查九張畫面，所有滑鼠命中、返回與原典→白話切換均與畫面位置一致。
驗收組圖為 `workplace/pointer-m0-verify/montage.png`。
另人工檢查 `map-command-button.png` 與 `command-opened-by-mouse-2.png`：前者可見

十五項政略選單。

第二批不使用鍵盤，從地圖一路點「指令」→「徵兵」→「徵兵」→兵種：
