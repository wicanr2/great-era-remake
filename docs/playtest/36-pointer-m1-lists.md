# PLAYTEST-36 指標／觸控 M1：長清單直接點選

日期：2026-08-03  
狀態：**PASS（事件路由與桌面滑鼠；Android 48dp 尚待實機）**

## 實作範圍

- 調動目標與運補目標：點省份列直接採用該省，不必再輸入編號與送出。
- 調動選將：點將領列只切換勾選，不偷改成自動提交；至少選一人後才顯示
  48×48 勾號送出鍵。
- 整編候選：點將領列直接進入兵力分配。
- 查閱他省：39 省表直接以省編號動作選擇。
- 授權自治：點候選省列直接切換；整個政策工作階段仍只扣一次指令。
- `select.16`..`select.99` 延續 M0 的絕對編號契約，第二欄／第二頁不得回捲為
  第一項。

renderer 與 hit target 使用同一組座標公式；返回、拖曳取消、放開派送與畫面
切換取消仍沿用共用 adapter。省編號輸入值與自治首列已移出右上導覽保留區，
避免功能正確但遮住資訊。

## Docker GUI 實跑

建置使用 `dsds-go:1.25`，實跑使用一次性
`fd2-dosbox-screenshot-local:latest` 的 Xvfb／xdotool，全程不用實體鍵盤。

### 查閱河南省

地圖→指令→查閱→查閱他省；在 39 省表直接點第 19 項河南省，立即進入
「河南省／1 概況／2 查閱將領」。沒有輸入 `1`、`9` 或按送出。

證據：`workplace/pointer-m1-lists/01-province-list.png`、
`02-province-19-direct.png`。

### 調動多選

地圖→指令 1→部份調動；直接點候選河南省，進入 15 人名單。點第一列吳佩孚後，
列首出現選取方塊，右上才出現勾號；點勾號後進入「調動多少黃金」與共用數字
鍵盤。這證明單列點擊、選取狀態、條件式送出與下一層路由均可達。

證據：`03-transfer-target-list.png`、`04-transfer-selection.png`、
`05-transfer-selected-submit.png`、`06-transfer-amount-keypad.png`。

## 驗收界線

本輪證明桌面滑鼠和 Ebiten Touch adapter 的邏輯命中正確，但不能據此宣稱密集
清單已符合 Android 48dp：原典 39 省表列高 22 邏輯像素，自治列高 14，實際
密度獨立像素取決於 Android Surface、縮放與裝置密度。M4 必須實機量測；若不足，
應由 modern UI 提供放大／分頁或可捲動列表，不可用互相重疊的 48px 隱形區域
假裝達標。
