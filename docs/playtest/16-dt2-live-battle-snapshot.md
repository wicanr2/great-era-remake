# 16 — 戰鬥已成立，但 `.DT2` 尚未寫回磁碟

> 日期：2026-08-02  
> 環境：`fd2-dosbox-screenshot-local`、DOSBox 0.74-3、Xvfb :99、`play.bat`  
> 設定：1 位玩家、玩家＝孫傳芳、好戰、高 AI、進階者

## 1. 可重現操作

新局路徑如下；玩家人數之後的 `2` 是先前文件漏掉的「選孫傳芳」。

```text
Return → 2 → Return → 1 → Return → 1 → Return
1 → Return
2 → Return
2 → 3 → 7 → Return → Return → Return → Return
1 → Return
```

進入政略後，以 `1 → 3 → Return → y` 練兵，每組之間等待 5 秒，重複十次。
原版於民國 15 年 8 月 1 日進入江西戰鬥，畫面顯示：

```text
蔣中正 攻擊 孫傳芳
放置蔣鎮臣的軍隊
```

這與 `docs/playtest/14-computer-attacks-confirmed.md` 的既有結果一致，表示路徑
可重播，不是偶發截圖。

`tools/dosbox_runner.sh` 現已把這個有動畫節奏要求的序列收成 `train:10`；它仍是
正常玩家按鍵，沒有改記憶體、跳日期或強制觸發戰鬥。

### 1a. `train:10` 不是固定戰鬥觸發器

後續重播也抓到反例：相同的新局選項與十次練兵，有一輪在等待 30 秒後已輪到
安徽省，沒有停在江西部署。這表示「約十次用完一個月命令」可重播，但「第十次後
必定出現蔣中正攻江西」不可升格為 deterministic gate；AI 選擇或亂數狀態仍會讓
結果分岔。

另一次成功停在部署的逐時點實驗曾把單按方向 `2` 判成「完成一支部署」。
⛔ **2026-08-02 已由 IDA 推翻**：玩家部署函式 `sub_42566` 接受字元集合
`"0123456"`；`1..6` 交給游標處理，`0` 才進入放置確認，隨後
`sub_42056` 另讀 `(Y/N)`，只有 `0`／`y`／`Y` 會提交。實機連按九次 `2`
仍停在「放置蔣鎮臣的軍隊」，與這條控制流一致。先前的 9→8／兵力變化不是
「單鍵已部署」的可靠證據，保留作勘誤，不再沿用。

砲兵還多一層：提交格子後 `sub_42056+23B` 再只接受 `1..6`，將數字減去
`'0'` 直接寫入執行期單位 `+31`，因此該欄已 confirmed 是**砲兵射擊朝向**。

曾試作以固定畫面像素自動追蹤部署，但在 480 秒外層界限內無法完成可靠驗證，已從
正式 runner 移除；不能把未通過的偵測器留成看似可用的 oracle 工具。

## 3. 結論與證據等級

- **已證實**：戰鬥已在遊戲記憶體中成立時，原版不會自動把即時戰鬥狀態寫入
  `SAVE(1).DT2` 或 `MEM_WAR.DAT`。
- **已證實**：只在主機端複製工作目錄，無法取得可供 `.DT2` 欄位差分的戰中樣本。
- **已證實（IDA Pro 9.4 `.i64`）**：`sub_3964E` 只有
  `sub_39B6E+6F4` 一個直接呼叫端；它位於戰鬥主函式尾段，寫回
  `MEM_WAR.DAT` 後才更新省份記錄。它不是部署階段可隨時呼叫的通用存檔入口。
- **未知**：完成或退出戰鬥後寫出的 469-byte 記錄，兩個 100 × u16 區會保留
  哪一刻的單位狀態。

因此 `docs/re/05-mem-war-record.md` 原先要求的「進入實戰後存檔再 diff」要訂正為
「**完成或退出戰鬥，等 `sub_3964E` 寫回後再 diff `MEM_WAR.DAT`**」。不能拿部署
階段未改變的磁碟檔宣稱戰鬥欄位也是零，也暫時不需要先做主機程序記憶體傾印。

### 4c. 為何決勝戰報也沒有改檔：寫回門檻已由 IDA 閉合

`sub_39B6E` 在 `3A237–3A262` 的控制流不是「只要戰鬥結束就寫回」：它先呼叫
`sub_41D20`，只有該函式把 `byte_6A40A` 從 0 立成 1，且 `byte_64901` 仍為 0
（未分勝負，例如打滿回合上限）時，才呼叫 `sub_3964E`。`sub_4136B` 的補給見底
與 `sub_4123D` 的雙方名單耗盡，都直接把 `byte_64901` 設成 1／2，因此決勝戰報
會跳過這個寫回分支。

這使本節的三種觀察一致：立即撤退不寫、勝負戰報不寫，只有「回合上限平局」目前
已知會經過 `sub_3964E`。下一輪應以正常玩家駐軍／待命流程打滿 16 回合（2 月為
15 回合），再取得寫回後的兩份以上樣本；在此之前，不得替 +68／+268 指派欄位語意。

### 4f. 2026-08-09 攻擊選單後的 `1..6` 輸入

沿用 4a 的陝西省路徑，部署確認後按戰鬥選單 `2`。IDA Pro 9.4 的

本輪未能以合法鄰位目標取得可核對的傷亡或回合結算；`before-attack-input` 與

> **2026-08-11 IDA 勘誤：** 上述實機紀錄把 `"123456"` 寫成由
