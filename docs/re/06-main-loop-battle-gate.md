## 1. 主迴圈的形狀

`PROGRAM`（`0x10BA?`–`0x11371`）是主程式，開頭是 `SystemInit` / `CRTInit` /
`GraphInit`，接著 `Randomize`，然後進一個以 `loc_10C18` 為頭的大迴圈。

`byte_6FE89` 是迴圈變數，**代表當前處理到第幾個省**。迴圈體裡一連串
gate 決定這個省要走哪條路，其中一條就是進入戰鬥。

---

## 2. 進入戰鬥的三個條件（`loc_11002`）

```asm
loc_11002:
        mov     al, byte_6FE89          ; 當前省
        xor     ah, ah
        mov     dx, 25h                 ; ×37
        mul     dx
        mov     di, ax
        push    word ptr [di-6221h]     ; 省份記錄裡的一個 word
        call    sub_5C7FE
        or      al, al
        jnz     short loc_1102C         ; 條件 1 成立 → 打
        cmp     byte_7003A, 0
        jnz     short loc_1102C         ; 條件 2 成立 → 打
        cmp     byte_7003B, 0
        jnz     short loc_1102C         ; 條件 3 成立 → 打
        jmp     loc_11143               ; 都不成立 → 這個省不進戰鬥
loc_1102C:
        mov     al, byte_6FE89
        mov     byte_6FFC4, al          ; 設定「戰鬥發生在哪個省」
        ... 七次 FreeMem 釋放政略階段的緩衝 ...
        call    sub_39B6E               ; 戰鬥主函式
```

### `mul 25h` 印證了省份記錄是 37 bytes

`25h = 37`，正是 `docs/spec/03-provinces.md` 的記錄大小。這是**獨立的第二個
證據**——SPEC-03 是從資料與實機畫面推的，這裡是程式自己的定址算式。

`byte_6FFC4`（戰鬥發生在哪個省）就是 `NWMAP.DAT` 與 `MEM_WAR.DAT` 用來
`Seek` 的那個變數（`docs/spec/04` §1、`docs/re/05` §1）。三處一致。

### 進戰鬥前會先 FreeMem 七塊緩衝

`0xB08`、`0x520`、`0xA38`、`0x520`、`0xA98`、`0x298`、`0x718` bytes。
政略階段的資料在進戰鬥前整批釋放，戰鬥結束再重配——**這是模組化的記憶體
管理，不是狀態交接**。remake 不需要重現，但它說明政略與戰鬥的狀態是分開的。

## 3. `sub_5C7FE`：司令是不是十大勢力之一

```
sub_5C7FE(arg: word) -> boolean

    if byte_7003A != 0:  return false
    if arg == 0:         return false
    for i = 1 to 10:
        if arg == 表[i]: return true        ; 表在 ds:[i*2 - 418Ch]
    return false
```

**一個 10 個元素的 word 表**，從 index 1 數到 10。

第一期正好有 10 個勢力——張作霖、孫傳芳、吳佩孚、蔣中正、劉湘、唐繼堯、
袁祖銘、趙恆惕、閰錫山、馮玉祥（`docs/spec/03` §3，已有測試驗證）。
傳進去的 word 來自省份記錄，而司令欄位（`+20`）存的正是將領 ID。

所以這支的語意是：**這個省的司令，是不是十大勢力的領袖之一。**

### 傳入的確實是司令欄位 — confirmed

`sub_3964E` 用**同一個基址** `[di-6221h]` 讀省份記錄，接著用 `di + 9DCBh`
寫同一筆記錄的 `+0`／`+2`（黃金／糧食）。兩個基址相差 `0x14 = 20`，
而 `+20` 正是省份記錄的**司令**欄位（`docs/spec/03` §2）。

所以陣列基址是 `0x9DCB`，`[di-6221h]` = 基址 + 省×37 + 20 = **司令 ID**。
詳見 `docs/mechanics/70-ai.md` §5。

⚠️ 但十大勢力表本身是執行期填的，**靜態看不到內容**。
「表裡裝的就是那十位領袖」仍是強證據，要完全確認得動態 dump。

## 4. 對「出兵沒成立」的意義

`docs/playtest/02` §5A.4 記的卡點是：選完目標省與將領後，按 Return 回主選單
但指令數沒減少（等於取消），按 Escape 跳到別省。

這一節找到的是**戰鬥的觸發點在主迴圈**，不在指令處理裡——
指令 2 應該只是「登記」某個狀態，真正開打是主迴圈輪到該省時才發生。

所以出兵沒成立的原因很可能不是「按錯鍵」，而是**那道登記沒有完成**。
下一步要找的是指令 2 的處理程式碼寫了哪個變數，以及主迴圈的哪個 gate
會讀它。`sub_1060A`（也呼叫 `sub_5C7FE`，而且呼叫了兩次以上）是候選。

**在找到之前不要再試按鍵**——按鍵試錯已經連續兩次得到誤導性的結果。
