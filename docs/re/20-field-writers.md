# 用「掃欄位的寫入點」一次解四個問題

> ⛔ **[2026-08-01 訂正]** 本文用的 pattern 只涵蓋**絕對定址**，
> 漏掉相對形式（`docs/re/22` §1）。§2「慰勞也不改將領忠誠度」作廢，
> §4「城市數零寫入」**需要重驗**。

輸入檔：`WAR.EXE`（375,568 B，未打包）
日期：2026-08-01

`docs/re/19` 掃忠誠度的寫入點時發現：**一次 grep 換來完整的因果圖，
而且能直接否證錯誤假設**（慰勞軍民不改省的民心）。這一輪把同一招
套到四個欄位上。

---

## 1. 方法

```sh
grep -E '(mov|add|sub|inc|dec)\s+(byte|word) ptr \[di-6235h\],'   # 省份 +0 黃金
```

省份記錄基址 `-6235h`、將領記錄基址 `+7A7Dh`，加上欄位偏移就是 pattern。

比「從指令名稱猜哪支函式管它」快一個數量級，
而且**零寫入就是零寫入**——那是很硬的否證。

---

## 2. 將領忠誠度（`MAN` `+1`）：只有三處

| 函式 | 動作 |
|---|---|
| `sub_115BD` | `mov [di+7A7Eh], cl` |
| `sub_18903` | **`add byte ptr [di+7A7Eh], 14h`（+20）** |
| `sub_34D5D` | `mov byte ptr [di+7A7Eh], 64h`（設 100）|

`sub_18903` 由 `sub_1ACCC` 呼叫三次（電腦回合的內政），
與省的 `sub_1A100`（`docs/re/19` §2）**完全對稱**：都是 +20。

### ⛔ 慰勞軍民也不改將領的忠誠度

`docs/re/19` §3 排除了「慰勞改省的民心」。現在連將領那條也排除了
——`sub_1C606` 不在上面三支裡。

**慰勞軍民動的是別的欄位**，候選是體力（`+29`）或士氣（`+30`）。
⚠️ 還沒掃那兩格。

## 3. 兵工廠數（省份 `+18`）：只有一處，而且它就是「建兵工廠」

`sub_248A8`（473 行，由 `sub_24D59` = 指令 7 開發呼叫）：

```asm
cmp     word ptr [di-6235h], 1388h      ; 黃金 < 5,000 → 不能建
cmp     byte ptr [di-6223h], 5          ; 已有 >= 5 座 → 不能建
...
mov     cx, 1388h
call    @$brmul$q7Longintt1             ; 花費 = n × 5,000
sub     [di-6235h], cx                  ; 扣黃金
add     [di-6223h], cl                  ; 加座數
```

| 規則 | 值 |
|---|---|
| 每座造價 | **5,000 黃金** |
| 一省上限 | **5 座** |

### 與實機量到的產出配成一套

`docs/playtest/06` §3 量到湖北（3 座）每月：
煤 −6,000、鐵 −6,000、彈藥 +6,000 → **每座每月 2,000 煤 + 2,000 鐵 → 2,000 彈藥**。

加上這裡的造價與上限，**兵工廠這條經濟線完整了**：
花 5,000 金蓋一座，之後每月把 2,000 煤 + 2,000 鐵變成 2,000 彈藥，
一省最多 5 座。

⚠️ 產出那條仍是**實機單一樣本**，沒從反組譯確認，所以規則層只實作造價與上限。

## 4. 城市數（省份 `+16`）：**零寫入**

全檔沒有任何指令寫它。

**城市數是靜態的**——開發的「墾地」不會增加城市，
攻下省份也不會改。它只是各省的固定屬性（進 `sub_5B983` 之類的計算）。

> 這是「零寫入」型的結論：**掃不到就是真的沒有**，
> 前提是 pattern 涵蓋所有寫法（`mov`／`add`／`sub`／`inc`／`dec`）。
> 與 `CONTEXT.md` §5.17「用不存在的工具去量得到 0」不同——
> 那次是量測器有洞，這次 pattern 在其他欄位上都命中了，工具是好的。

---

## 5. 黃金（省份 `+0`）：34 支函式，太多了

黃金是全遊戲的通貨，34 個寫入點掃出來反而沒有直接結論。
但有幾個立即可讀的常數：

| 函式 | 動作 | 讀作 |
|---|---|---|
| `sub_197DB` | `sub 2710h`（10,000）| 某個固定支出 |
| `sub_19CD4` | `sub 1388h`（5,000）| 同上 |
| `sub_20447` | `sub 5DCh`（1,500）| 秘密行動的花費 |
| `sub_1AA28` | `mov 1770h`（6,000）| 直接設值 |
| `sub_126D5` | `mov 0EA60h`（60,000）| 設到上限 |

**這一格要換方法**：從指令函式往下追，而不是從欄位往上掃。
