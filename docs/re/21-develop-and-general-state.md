## 1. 開發（指令 7）的三項，一次全部對上

`sub_24D59`（指令 7）底下三支，各對應子選單的一項：

| 子選單 | 函式 | 動的欄位 |
|---|---|---|
| 1 墾地 | `sub_241D0` | 省份 `+17` 地價 ↑、將領 `+29` 體力 −5 |
| 2 建兵工廠 | `sub_248A8` | 省份 `+18` 座數 ↑、`+0` 黃金 −5,000（`docs/re/20` §3）|
| 3 挖金礦 | `sub_24535` | 省份 `+0` 黃金 ↑、將領 `+29` 體力 −5 |

### 1a. 墾地 — confirmed

```asm
cmp     byte ptr [di+7A9Ah], 5      ; 體力 < 5 → 不能做
...
mov     al, [di+7A7Fh]              ; 將領 +2 = 政治手腕
mov     cx, 0Ah
div     cx                          ; ÷ 10
add     [di-6224h], cl              ; 地價 += 政治手腕 ÷ 10
cmp     byte ptr [di-6224h], 0C8h   ; > 200?
mov     byte ptr [di-6224h], 0C8h   ; 夾到 200
...
sub     byte ptr [di+7A9Ah], 5      ; 體力 −5
```

**地價上限 200**，成效 = **政治手腕 ÷ 10**。

### 1b. 挖金礦 — 結構 confirmed，數值待補

```asm
cmp     byte ptr [di+7A9Ah], 14h    ; 體力 < 20 → 不能做（門檻是墾地的四倍）
mov     al, [di+7A7Fh]              ; 政治手腕
mov     cx, 0Ah
div     cx                          ; ÷ 10
call    @Random$q4Word              ; ← 帶亂數
add     [di-6235h], cx              ; 黃金 +=
sub     byte ptr [di+7A9Ah], 5      ; 體力 −5
cmp     word ptr [di-6235h], 0EA60h ; 夾到 60,000
```

⚠️ `Random` 的**參數**與最終算式還沒讀完，所以**不寫進規則層**。
但確定的是：**兩項都用「政治手腕 ÷ 10」**。

> 這印證了 `docs/playtest/07` 的觀察（開發派將時列的是 `+2`）
> ——當時把它定名為「開發能力」是錯的（`docs/playtest/08` 訂正為
> 「政治手腕」），但**觀察本身是對的**：開發的成效確實由 `+2` 決定。

## 2. `MAN` `+16` 只有三個值被寫入 — confirmed

`docs/spec/02` 記過「`+16` 在存檔裡只有 `{0, 1, 32}` 三個值」，
語意一直未解。掃寫入點：

| 寫入的值 | 函式 | 位址段 |
|---|---|---|
| **1** | `sub_12AAD`、`sub_13484`、`sub_5375E`、`sub_53B1E` | 政略 + 戰鬥 |
| **20h（32）** | `sub_11380`、`sub_52222`、`sub_524FC`、`sub_5CEAE` | 政略 + 戰鬥 |
| `cl`（`or al, 4`）| `sub_41513`、`sub_4166E`、`sub_4E239` | **只在戰鬥中** |

- **`1` = 可用**（`sub_5A881`／`sub_28259`／`sub_13B44` 全部檢查 `== 1`）
- **`32` = 另一種狀態**——四支裡三支在戰鬥模組（`0x52`／`0x5C` 段），
  讀起來像**陣亡／退場**
- **bit 2（4）只在戰鬥中設**（把部隊放上戰場），所以存檔裡看不到
  ——這解釋了為什麼靜態掃描只看到三個值

⚠️ `32` 的確切語意仍未證實。要證實得讀 `sub_52222`／`sub_524FC`
的上下文，或在 DOSBox 裡打一場看陣亡的將領變成什麼。

## 3. 人口（省份 `+12`）：**只減不增**

全檔只有 `sub_194F4` 一處寫，而且是 `sub [di-6229h], cx`。

**人口沒有任何成長機制。** 這對經濟模型是硬結論：
人口只會因為戰爭或事件減少，玩家做什麼都不會讓它回來。
