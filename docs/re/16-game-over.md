# 勝負判定與分期時限：`sub_1060A`

輸入檔：`WAR.EXE`（375,568 B，未打包）
位址：IDA linear address
日期：2026-08-01

`CLAUDE.md` §8 把「勝負判定」列在 M3，`docs/playtest/09` §3 說
「`-until-unified` 是我們定的結束條件，不是原版的」。現在是原版的了。

`sub_1060A` 是 300 行，兩條路徑。

## 2. 觀戰模式（`byte_7003A != 0`）：只看統一

```
上一個司令 = 0；統一 = 1
for p = 1 .. 39:
    if 省份[p].+20 == 上一個司令:  continue
    if 省份[p].+20 == 0:           continue
    if 上一個司令 != 0:  統一 = 0
    上一個司令 = 省份[p].+20

if 統一:
    印 "Over !!"                    ; ← 英文字串，不是字模
    ReadLn                          ; 等一個 Enter
    回 1
```

`byte_7003A` 就是設定選單第 7 項「觀戰」（`docs/playtest/06` §6）。
**觀戰模式下沒有玩家，所以只有「天下統一」一個終點**，
而且不寫結局代碼——直接印 `Over !!` 收工。

## 3. 正常遊戲：三個終點

### 3a. 玩家覆滅

```
覆滅 = 1
for p = 1 .. 39:
    if sub_5C7FE(省份[p].+20)                  ; 是十大勢力之一
       且 將領[省份[p].+20].+16 & 1 == 1:      ; 那個領袖還可用
        覆滅 = 0
```

### 3b. 第一期的時限：民國 26 年 7 月 — **confirmed**

```asm
cmp     byte_6FE88, 1           ; 第一期
jnz     short loc_1076C
cmp     byte_6FE7D, 1Ah         ; 年 == 26
jnz     short loc_1076C
cmp     byte_6FE7E, 7           ; 月 >= 7
jb      short loc_1076C
mov     [bp+var_5], 1           ; ← 強制「覆滅」
```

**民國 26 年 7 月 = 1937 年 7 月 = 盧溝橋事變。**

北伐那一期到此**強制結束**，走的是「覆滅」那條路（旗標直接設 1）。
這與 `CLAUDE.md` §1.5 記的三期分法（北伐／抗戰前期／抗日後期）
完全吻合，而且給了第一期一個**明確的時間上限**。

> 這也解釋了 `docs/playtest/09` 的長跑為什麼「不會統一」——
> 原版根本不指望第一期打完統一，**時間到就換期**。

### 3c. 統一

```
可用數 = 0
for i = 1 .. 24（18h）:
    if 表[i] != 0 且 將領[表[i]].+16 & 1:
        可用數++
if 可用數 == 1 且 !覆滅:  統一 = 1

if 統一:
    for p = 1 .. 39:
        if 省份[p].+20 != 0 且 !sub_5C7FE(省份[p].+20):  統一 = 0
```

兩道：**十大勢力裡只剩一個還可用**，而且**所有有主省都歸十大勢力**
（第二道排除「還有雜牌軍佔著省」的情況）。

## 4. 結局代碼寫進 `Config.dat` — confirmed

```
if 覆滅:  回 1；sub_10541(第一期 ? 20h : 40h)
if 統一:  回 1；sub_10541(第一期 ? 1  : 2)
```

`sub_10541` 開 `Config.dat`（找不到就試 `b:config.dat`）並寫入那個 byte。

| 代碼 | 意思 |
|---:|---|
| 1 | 第一期統一 |
| 2 | 其他期統一 |
| `20h` (32) | 第一期覆滅 |
| `40h` (64) | 其他期覆滅 |

**`GRTE.EXE` 讀它播對應的結局。** 這印證了 `CLAUDE.md` §3.7 的假說：

> 這條交接鏈解開之前，不要假設任何模組可以獨立執行。

`play.bat` 的 `war → sr → grte` 就是這麼串的。
