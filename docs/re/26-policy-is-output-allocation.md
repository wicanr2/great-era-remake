## 2. 四個欄位 + 一個算出來的剩餘 `[confirmed]`

省份表 37 B/筆、基址 `9DCBh`。畫面依 `+22h, +23h, +24h, +21h` 的順序印出前四個：

| 欄位 | 十進位偏移 | 畫面位置 |

| `+22h` | +34 | 第 1 個 ％ |
| `+23h` | +35 | 第 2 個 ％ |
| `+24h` | +36 | 第 3 個 ％ |
| `+21h` | +33 | 第 4 個 ％ |

第五個不是欄位，是當場算的：

```
bx = es:[di+21h]
cx = es:[di+24h]
dx = es:[di+23h]
ax = es:[di+22h]
ax = ax + dx + cx + bx
ax = 64h - ax                   ; 100 - 四欄之和
```

**剩餘 = 100 − (`+21h` + `+22h` + `+23h` + `+24h`)** `[confirmed]`。

初始值 `25 25 25 25` 相加正好 100，所以開局的「剩餘」是 0。
