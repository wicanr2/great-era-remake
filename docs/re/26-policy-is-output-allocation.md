## 2. 四個欄位 + 一個算出來的剩餘 `[confirmed]`

省份表 37 B/筆、基址 `9DCBh`。畫面依 `+22h, +23h, +24h, +21h` 的順序印出前四個：

| 欄位 | 十進位偏移 | 畫面位置 |
|---|---:|---|
| `+22h` | +34 | 第 1 個 ％ |
| `+23h` | +35 | 第 2 個 ％ |
| `+24h` | +36 | 第 3 個 ％ |
| `+21h` | +33 | 第 4 個 ％ |

第五個不是欄位，是當場算的：

```
bx = es:[di+21h]
cx = es:[di+24h]
dx = es:[di+23h]
ax = es:[di+22h]
ax = ax + dx + cx + bx
ax = 64h - ax                   ; 100 - 四欄之和
```

**剩餘 = 100 − (`+21h` + `+22h` + `+23h` + `+24h`)** `[confirmed]`。

初始值 `25 25 25 25` 相加正好 100，所以開局的「剩餘」是 0。

## 3. 欄位與資源對應 `[confirmed]`

IDA 線性位址 `2358Eh..235D9h` 先把四個可調項目畫在
`y=38h, 3Ah, 4Eh, 62h`；`23651h..236C4h` 又在同一組縱座標依序畫出
`+22h, +23h, +24h, +21h` 的數值。字形表詞條 29、30、31、34 分別是
「鐵礦產能」、「煤礦產能」、「石油產能」、「糧食產能」。因此：

| 選項 | 資源 | 記錄偏移 | IDA 讀取／寫回證據 |
|---:|---|---:|---|
| 1 | 鐵礦 | `+22h` (+34) | `23A8Dh`, `23EDBh` |
| 2 | 煤礦 | `+23h` (+35) | `23AB6h`, `23EECh` |
| 3 | 石油 | `+24h` (+36) | `23ADFh`, `23EFDh` |
| 4 | 糧食 | `+21h` (+33) | `23B08h`, `23F0Eh` |
| — | 黃金 | 無獨立欄位 | `100 - 上述四欄總和` |

黃金不是可直接選擇的第五欄，而是未分配給鐵、煤、油、糧的剩餘產能。
`23C93h..23D13h` 將新值限制在 `0..當前黃金剩餘+該欄舊值`；這代表
降低某欄會釋出黃金產能，提高某欄則只能吃掉當前剩餘，不會自動擠壓其他欄位。
