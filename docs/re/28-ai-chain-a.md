### ⛔ 開頭的特判是**省份**不是勢力，而且有附加條件

```asm
cmp     byte ptr ss:[di+0Ah], 25h      ; 37
jz      loc_17B07
cmp     byte ptr ss:[di+0Ah], 26h      ; 38
jz      loc_17B07
cmp     byte ptr ss:[di+0Ah], 27h      ; 39
jnz     loc_17B13                       ; 都不是 → 照跑
loc_17B07:
mov     al, byte_6FFCA
and     al, 2                           ; ← **還要 bit 1 設起來**
jz      loc_17B13                       ; 沒設 → 照跑
jmp     loc_1802B                       ; 跳過整條決策鏈 A
```

原文寫「`ss:[di+0Ah]`（**勢力編號**）……那三個**勢力**不跑決策鏈 A，語意未解」，
**兩處都錯**：

1. `ss:[di+0Ah]` 是**當前省編號**。它被原封不動傳給 `sub_16E77(狀態, 省)`
   與 `sub_5A9F6(省)`，兩支的參數都是省；`sub_17236` 更拿它 `mul 25h`
   去索引省份記錄。勢力是另一格 `ss:[di-2]`。
2. **不是「直接跳出」**，還要 `byte_6FFCA & 2`。bit 1 沒設就照跑。

**語意也解出來了**：37／38／39 是**臺灣省／海南島／緬甸**（`3.15` 省名表），
三個都**只有一個鄰省**（臺灣→24 福建、海南島→36 廣東、緬甸→34 雲南），
初始全部無主。整條決策鏈的核心是挑鄰省，對只有一個鄰省的省沒有意義；
`sub_5A9F6` 更會因為「唯一的鄰省是敵人」而永遠判成被包圍，誤觸發突圍。

⚠️ 步驟 6 另外有一份**不一樣**的排除清單：只有 37 與 38，**不含 39 緬甸**。
緬甸與雲南陸路相連，離島打不出去——兩份清單的差別是有道理的。

## 3. `sub_174C9` 遠不只是「扣命令數」`[強證據]`

`docs/re/13` 把它記成「命令數遞減」。它確實有那一行——

```
dec     word ptr ss:[di-232h]        ; 命令數 −1
```

——但那只是 **627 行裡的一行**。它同時做這些事：

```
省份 +0  黃金 -= cx        (sub [di-6235h], cx)
省份 +2  糧食 -= cx        (sub [di-6233h], cx)
省份 +4  彈藥 -= cx        (sub [di-6231h], cx)
省份 +8  燃料 -= cx        (sub [di-622Dh], cx)
省份 +20 司令 := ax        (mov [di-6221h], ax)
省份 +30        := ax      (mov [di-6217h], ax)
```

**被扣的正好是「可流動的四種資源」**（黃金／糧食／彈藥／燃料），
與運補能搬的、外援會給的完全同一組（`docs/re/27`、`40-economy.md` §9）。
煤礦與鐵礦一個都沒碰，這個二分再一次成立。

### 扣多少：一張 60 B/筆的表

```
di = 3Ch × ss:[di-2]          ; 60 bytes 一筆
cx = [di - 5CA4h]             ; 第 0 個 word → 扣黃金
cx = [di - 5CA2h]             ; 第 1 個 word → 扣糧食
...
```

表的基址是 `ds:A358h`（`A35Ch` 是它的 `+4`），索引來自 `ss:[di-2]`。

⛔ 這裡原本寫「這張表的語意未解，形狀符合每個部隊的補給消耗」。
**已解**：它就是**參戰部隊表**，與玩家派將 `sub_2D812` 填的是同一張
（`docs/re/29`）。而且讀寫的是同一批格子，不是「另一張消耗量表」。

### 同時把省份資源複製進另一個結構

```
es:[di+4]  := 省份黃金      (5 處)
es:[di+6]  := 省份糧食      (5 處)
es:[di+0Ch] := 省份彈藥     (4 處)
es:[di+10h] := 省份燃料     (4 處)
```

`es:di` 來自區域變數 `var_A`。**間隔 4 的四個欄位**與 `docs/re/05` §2
記過的「四個 u16 目標位址間隔 4，因為攻守成對」形狀相同，
也與戰後結算 `sub_546D1` 動的那四格一致（`40-economy.md` §5c）。
