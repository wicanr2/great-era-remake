## 3. `sub_174C9` 遠不只是「扣命令數」`[強證據]`

`docs/re/13` 把它記成「命令數遞減」。它確實有那一行——

```
dec     word ptr ss:[di-232h]        ; 命令數 −1
```

——但那只是 **627 行裡的一行**。它同時做這些事：

```
省份 +0  黃金 -= cx        (sub [di-6235h], cx)
省份 +2  糧食 -= cx        (sub [di-6233h], cx)
省份 +4  彈藥 -= cx        (sub [di-6231h], cx)
省份 +8  燃料 -= cx        (sub [di-622Dh], cx)
省份 +20 司令 := ax        (mov [di-6221h], ax)
省份 +30        := ax      (mov [di-6217h], ax)
```

**被扣的正好是「可流動的四種資源」**（黃金／糧食／彈藥／燃料），
與運補能搬的、外援會給的完全同一組（`docs/re/27`、`40-economy.md` §9）。
煤礦與鐵礦一個都沒碰，這個二分再一次成立。

### 扣多少：一張 60 B/筆的表

```
di = 3Ch × ss:[di-2]          ; 60 bytes 一筆
cx = [di - 5CA4h]             ; 第 0 個 word → 扣黃金
cx = [di - 5CA2h]             ; 第 1 個 word → 扣糧食
...
```

表的基址是 `ds:A35Ch`，索引來自 `ss:[di-2]`。前四個 word 依序是
黃金／糧食／彈藥／燃料的消耗量。**這張表的語意未解**——
形狀符合「每個部隊類型／編制的補給消耗」，但沒有直接證據。

### 同時把省份資源複製進另一個結構

```
es:[di+4]  := 省份黃金      (5 處)
es:[di+6]  := 省份糧食      (5 處)
es:[di+0Ch] := 省份彈藥     (4 處)
```

`es:di` 來自區域變數 `var_A`。**間隔 4 的四個欄位**與 `docs/re/05` §2

## 4. 這是不是「出兵」— **假說，不要當結論**

支持的線索：

- 扣的是可流動的四種資源，像**帶著補給出發**
- 改省份 `+20` 司令，就是**易主**（`docs/re/10` 的「調動即佔領」同一手法）
- 把省份資源搬進一個間隔 4 的結構，形狀像**戰鬥記錄的攻守欄位**

反對／存疑的：

- 閉包掃描證明這條路徑**不呼叫戰鬥主函式**（`docs/re/12`），
  所以就算是出兵，也是**不經戰鬥畫面的那種**
- 60 B/筆那張表沒有獨立證據
- `es:di` 指向什麼還沒追出來

⚠️ **在追出 `var_A` 指向哪張表之前，不要把「`sub_174C9` = 電腦出兵」寫成結論。**
`docs/re/12` 的「電腦不會攻打」目前仍然成立——它證明的是「不走戰鬥流程」，
與「會不會用別的方式改變省份歸屬」是兩個問題。
