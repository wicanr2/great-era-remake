> 位址：IDA linear address

## 1. 這次勘誤

早期筆記把 `Random(10) <= 6` 寫成「70% 核准」，並把張作霖／民國 17 年
2–6 月的分支命名為「禁運拒絕」。重新沿著字模索引與寫入端核對後，這兩項都
與原始控制流相反；舊結論保留在交接紀錄，從本文件起不再當作目前規則。

## 2. `loc_21E9D` 的控制流（confirmed）

`sub_21D1D` 的援助判定在 `21E9Dh`：

1. 呼叫 `Random(10)`，結果存入 `var_14`；接著立 `byte_6FE81=1` 與
   `byte_6FE80=1`。
2. `21EBCh` 比較 `var_14` 與 `6`：
   - `var_14 <= 6` 跳到 `21EC5h`；
   - `var_14 > 6` 直接跳到 `21FCAh`。
3. `21EC5h` 檢查司令 `0xA6`、年份 `0x11`、月份 `2..6`。條件不全符合時
   跳 `21EF5h`；全符合時跳 `21FCAh`。

## 3. 為何 `21EF5h` 是拒絕

`21EF5h..21FAEh` 的畫字呼叫以 1-based 詞條索引逐段輸出：

| 索引 | 詞條 |
|---:|---|
| `105` | 各國 |
| `45` | 均 |
| `106` | 拒絕 |
| `107` | 提供 |
| `104` | 援助 |

這條路徑設定訊息顏色後直接回到 `223E1h`，沒有呼叫資源累加函式。因此一般
情況下 `0..6` 是 70% 拒絕；`7..9` 才是 30% 核准。

## 4. 為何 `21FCAh` 是核准／入帳

`21FCAh..223E0h` 先依 `[di-5319h]` 的勢力代碼改寫 `var_14`，再以
`22088h` 的 1／3／5 除數分流。後續四次呼叫 `sub_5A467` 寫入目前省份的
黃金、糧食、彈藥、燃料，並在 `sub_5C441` 傳入援助詞條代碼；這是實際入帳
路徑，不是拒絕畫面。

## 5. 日期／司令特殊分支（confirmed control flow；歷史動機 unknown）

司令 ID `166`（`0xA6`，詞表可解為張作霖）、民國 `17` 年、月份 `2..6` 時，
`21EC5h` 會跳過拒絕畫面，直接進 `21FCAh`。因此它是**特殊核准覆寫**；
本證據不把它命名為「禁運」，也不替原版推定設計者的歷史動機。

- `internal/game.RequestAid` 以 `AidRefusalMax=6` 表示拒絕上限，
  `AidApprovalMin=7` 表示一般核准起點。

- `CommandCompleted` 仍在第一次 `Random(10)` 前設為真；核准、拒絕與特殊核准
