## 1. 開頭就分兩條路 — **confirmed**

```asm
cmp     [bp+arg_2], 1
jnz     short loc_174E0
jmp     loc_175BB              ; ← 模式 1 走完全不同的一整條分支
```

**模式 1（突圍）不走湊兵迴圈**，直接跳到 `loc_175BB`——
那裡掃的是 `ss:[X+4]` 指向的 `[-22Eh]` 陣列（各省將領數），與模式 2／3
的邏輯無關。突圍是「有什麼派什麼」，不比較兵力。

模式 2／3 才進下面的流程。

## 2. 難度決定用哪一支湊兵 — **confirmed**

```asm
loc_174E0:
mov     al, byte_6FFCA
and     al, 1
cmp     al, 1
jnz     short loc_1751F
;   高難度：
call    sub_1655C              ; 138 行，**多收一個「模式」參數**
jmp     short loc_1754F
loc_1751F:
;   低難度：
call    sub_16A9E              ; 83 行，**不收模式參數**
```

這是 `byte_6FFCA` bit 0 的**第五個用途**（前四個見 `70-ai.md` §3w）。

兩支的參數列差一個：`sub_1655C` 收模式，`sub_16A9E` 不收。
所以**低難度的電腦不分模式 2／3，一視同仁**——
模式差異只在高難度下生效。

### `sub_1655C` 的參數（Pascal 慣例，由左至右壓棧）

```
sub_1655C(X, &狀態[-5], &狀態[-0EEh], 10, &狀態[-12h], 目標省, 模式)
          ↑  ↑          ↑             ↑   ↑            ↑       ↑
      bp+4  bp+6     bp+10        bp+14 bp+16       bp+20   bp+22
```

`X = ss:[bp_17ADA+4]` 是外層狀態，`目標省 = ss:[bp_17ADA-2]`
（步驟 4／5 挑出來存在 `var_2` 的那個省）。

> ⚠️ IDA 的 `arg_C = dword ptr 10h` 這種標法**名字與偏移不一致**
> （`arg_C` 在 `bp+16` 不是 `bp+12`）。照偏移讀，別照名字。

## 4. 湊兵迴圈 — **confirmed（結構）**

```asm
loc_165F6:
inc     [bp+var_A]             ; 計數
push    bp
call    sub_1629E              ; ← 挑一個進名單？**未讀**
push    bp
call    sub_163BE              ; ← 夠了沒？177 行
or      al, al
jz      short loc_165F6        ; 回 0 → 繼續湊
```

**`sub_163BE` 回非 0 就停**。它裡面依模式分兩套停止條件，
兩套都用 Turbo Pascal 的 48-bit Real 常數：

| 模式 | 暫存器 | 常數 | 條件 |
|---:|---|---:|---|
| 1 | `CX=82h SI=0 DI=4000h` | **3** | `Round([-14h] × 2 ÷ 3) ≥ [-18h]` → 停 |
| 2／3 | `CX=82h SI=0 DI=2000h` | **2.5** | `Round([-1Ch] × 2.5) ≤ [-10h]` → 停 |

Real 解碼照 `docs/re/10` 的規則（`byte0` 是 exponent、`bytes1-5` 是
mantissa 低位在前、最高位隱含 1）：

```
exp 82h → 2^(82h-81h) = 2
40h → 補隱含位 C0h → C0h/80h = 1.5   → 1.5 × 2 = 3
20h → 補隱含位 A0h → A0h/80h = 1.25  → 1.25 × 2 = 2.5
```

讀作（**假說，見 §6**）：模式 2／3 湊到**目標省戰力的 2.5 倍**就收手。

## 5. 湊完之後：模式 2 要再過一關 — **confirmed**

```asm
cmp     [bp+arg_12], 2         ; 模式 == 2？
jnz     short loc_16630        ; 模式 3 → 無條件放行
mov     ax, [bp+var_18]        ; 湊到的量
...
call    @$brmul                ; × 2
cmp     dx, [bp+var_12]        ; vs 最強敵對鄰省的戰力
jg      short loc_16627        ; 大於 → 放行
jl      short loc_1662E        ; 小於 → **不出兵**
cmp     ax, [bp+var_14]
jbe     short loc_1662E
loc_16627:
les     di, [bp+arg_C]
mov     byte ptr es:[di], 1    ; 放行旗標
```

**模式 2 要求湊到的兵力 × 2 > 最強敵對鄰省的戰力**，模式 3 不要求。

「最強敵對鄰省」怎麼來的：`sub_5A907` 收集敵對鄰省 →
`sub_16047(mode 2)` 降序排 → 取第一個（`70-ai.md` §3r）。
若第一個正好就是要打的目標省而且候選不只一個，改取**第二強**的
——也就是**不把要打的那個算進威脅評估**，只看背後還有誰。

這是很細緻的判斷：**打之前先看側翼**。

### ⚠️ 一處疑似無效的比較

`sub_1655C` 的 `loc_165DA` 比「本省戰力」與「最強敵省戰力」：

```asm

jl      short loc_165EC        ; 高位小於 → 結束，不出兵
```

沒有任何作用。實務上戰力值遠小於 65,536，高位恆為 0 恆相等，
**這道檢查等於永遠放行**。

是寫了但不生效的碼。照抄行為即可，不要在 remake 補上「本意」——
