## 1. `sub_5BD7B`：建 39×39 成本矩陣 + 初始化 Dijkstra — confirmed

```
; 第一段：填成本矩陣（狀態[-0A6h] 指到的 buffer，每列 39 格）
for i = 1 .. 39（27h）:
    for j = 1 .. 39:
        if i == j:                              矩陣[i][j] = 0
        elif 省份[j].+20 == 狀態[+8]            ; 目標勢力
             且 全域鄰接[i][j] == 3:             矩陣[i][j] = 1
        else:                                    矩陣[i][j] = 0FFh

; 第二段：初始化單源搜尋
for k = 1 .. 39:
    狀態[-9Fh + k]  = 0                 ; visited
    狀態[-50h + 2k] = 矩陣[起點][k]      ; 距離
    if 0 < 矩陣[起點][k] < 0FFh:
        狀態[-77h + k] = 起點            ; 前驅
    else:
        狀態[-77h + k] = 0FFh
```

`27h` = 39 = 省份數，`0FFh` = 不可通行。

### 三個要點

1. **成本一律 1** —— 通得過的邊全部是 1，所以模式 11 是
   **無權最短路（＝ BFS）**，不是帶權 Dijkstra。
2. **只走目標勢力的省** —— `省份[j].+20 == 狀態[+8]` 是硬條件。
3. `dword_6FFC0` 是一張**全域的 39×39 鄰接矩陣**，值 **3** 表示相鄰。
   它從哪裡建的還沒追（候選：`WARPOS.DAT` 幾何或省份記錄的鄰省表）。

### 同分時挑哪一條仍未對齊

即使邊成本相同，**走訪順序不同就會挑到不同的等長路徑**。
原版依省編號由小到大掃（`for j = 1..39`），我們的 BFS 依鄰省表順序。
兩者在有多條最短路時會分歧。**要對齊得改成按省編號掃鄰居**——
這一條標為已知差異，等有實機路徑可比對再處理。
