## 1. 修好的掃法：追基址，不是追偏移

相對定址的偏移會與**每一種結構**撞號（`+16` 在將領記錄是狀態、
在省份記錄是城市數）。所以不能只 grep 偏移，要**追基址的來源**：

```python
# 看到 `add di, 9DCBh`（省份）或 `add di, 7A7Dh`（將領）就記住，
# 之後 40 行內的 es:[di+N] 寫入才歸給那個結構
```

這樣掃出來的每一筆都有明確歸屬。

---

## 2. ✅ 城市數（省份 `+16`）：兩種形式都零命中

絕對定址（`[di-6225h]`）與相對定址（基址 `9DCBh` + `es:[di+10h]`）
**都是零**。

`docs/re/20` §4 那條「城市數是靜態的」**結論成立**，
而且現在是用涵蓋兩種形式的 pattern 驗的。

## 3. ⛔ 訂正：人口**會成長**

`docs/re/21` §3 說「人口只減不增，全檔只有 `sub_194F4` 一處寫」。
**漏了 `sub_30003`**（相對定址）：

```asm
cmp     word ptr es:[di+0Eh], 0Fh       ; 人口高位
cmp     word ptr es:[di+0Ch], 4240h     ; 人口低位（0xF4240 = 1,000,000）
mov     ax, es:[di+0Ch]
mov     dx, es:[di+0Eh]
mov     cx, 84h                          ; Real 常數
call    @$brdiv$q4Realt1
...
mov     es:[di+0Ch], ax                  ; ← 寫回人口
mov     es:[di+0Eh], dx
```

`sub_30003` 由 `sub_38444+97` 呼叫——**回合／月份的自動更新**。
人口有成長機制，`docs/re/21` §3 的硬結論作廢。

⚠️ 成長率（`0x84` 那個 Real 常數配上除法）還沒算出來。

⚠️ 這三個年份**做什麼**還沒讀（都在動將領的效忠勢力，

## 5. 🆕 省份 `+33..+36` 是「政策」的四個數值

## 6. 方法論：怎麼驗證過濾器

`docs/re/22` §1 寫過：

> 驗證過濾器的方法不是「它在別處有命中」，
> 而是**主動找一個已知該命中的案例試它**。

這一輪照做了：修好 pattern 之後先確認它抓得到 `sub_3412B`
（已知會寫將領 `+29`／`+30`／`+1`），再去掃未知的欄位。
結果表裡 `將領 +29` 那一列確實有 `sub_3412B` ✓

**先驗過濾器，再信結果。**
